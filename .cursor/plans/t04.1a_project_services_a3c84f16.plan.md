# T04.1a: Project Command/Query Services

## Context

The Project entity was designed as an aggregate root for resource lifecycle management. Task T04.1 created the entity structure (api.proto, spec.proto, status.proto, enum.proto, io.proto), but the API contract is incomplete without the gRPC service definitions that enable persistence and retrieval.

**Current State**: 5 proto files exist in `apis/ai/stigmer/agentic/project/v1/`

## Implementation

### Step 1: Create command.proto

**File**: [apis/ai/stigmer/agentic/project/v1/command.proto](apis/ai/stigmer/agentic/project/v1/command.proto)

Following the exact pattern from [agent/v1/command.proto](apis/ai/stigmer/agentic/agent/v1/command.proto):

```protobuf
syntax = "proto3";

package ai.stigmer.agentic.project.v1;

import "ai/stigmer/agentic/project/v1/api.proto";
import "ai/stigmer/agentic/project/v1/io.proto";
import "ai/stigmer/commons/apiresource/rpc_service_options.proto";
import "ai/stigmer/iam/iampolicy/v1/rpcauthorization/method_options.proto";

// ProjectCommandController handles write operations for projects.
service ProjectCommandController {
  option (ai.stigmer.commons.apiresource.api_resource_kind) = project;

  // Create or update a project.
  rpc apply(Project) returns (Project);

  // Create a new project.
  rpc create(Project) returns (Project) {
    option (...).resource_kind = organization;
    option (...).permission = can_create_project;
    option (...).field_path = "metadata.org";
    option (...).error_msg = "unauthorized to create project in this organization";
  }

  // Update an existing project.
  rpc update(Project) returns (Project) {
    option (...).resource_kind = project;
    option (...).permission = can_edit;
    option (...).field_path = "metadata.id";
    option (...).error_msg = "unauthorized to update project";
  }

  // Delete a project.
  rpc delete(ProjectId) returns (Project) {
    option (...).resource_kind = project;
    option (...).permission = can_delete;
    option (...).field_path = "value";
    option (...).error_msg = "unauthorized to delete project";
  }
}
```

**Key Decisions**:

- Permission `can_create_project` follows `can_create_agent`/`can_create_workflow` pattern
- All error messages include actionable context
- `apply` RPC has no explicit auth (determined at execution time)

### Step 2: Create query.proto

**File**: [apis/ai/stigmer/agentic/project/v1/query.proto](apis/ai/stigmer/agentic/project/v1/query.proto)

Following the exact pattern from [agent/v1/query.proto](apis/ai/stigmer/agentic/agent/v1/query.proto):

```protobuf
syntax = "proto3";

package ai.stigmer.agentic.project.v1;

import "ai/stigmer/agentic/project/v1/api.proto";
import "ai/stigmer/agentic/project/v1/io.proto";
import "ai/stigmer/commons/apiresource/io.proto";
import "ai/stigmer/commons/apiresource/rpc_service_options.proto";
import "ai/stigmer/iam/iampolicy/v1/rpcauthorization/method_options.proto";

// ProjectQueryController handles read operations for projects.
service ProjectQueryController {
  option (ai.stigmer.commons.apiresource.api_resource_kind) = project;

  // Get a single project by ID.
  rpc get(ProjectId) returns (Project) {
    option (...).resource_kind = project;
    option (...).permission = can_view;
    option (...).field_path = "value";
    option (...).error_msg = "unauthorized to get project";
  }

  // Get a project by reference (org/name).
  rpc getByReference(ai.stigmer.commons.apiresource.ApiResourceReference) returns (Project);
}
```

**Key Decisions**:

- `getByReference` has no explicit auth options (custom authorization in handler)
- Uses `commons/apiresource/io.proto` for `ApiResourceReference`
