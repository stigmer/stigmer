# Phase 2.4: Add UsageMetrics for Token/Cost Tracking

## Objective

Create an `UsageMetrics` proto message that aggregates token consumption and LLM resource usage at both the execution level and per-sub-agent, enabling cost tracking, billing, and performance analytics.

---

## Design Decisions

### 1. UsageMetrics Scope

**Decision**: Create a single `UsageMetrics` message reusable in multiple contexts:

- `AgentExecutionStatus.usage` - Main agent's direct LLM usage (excludes sub-agent tokens)
- `SubAgentExecution.usage` - Per-sub-agent token breakdown

**Rationale**:

- Consumers can calculate total execution cost by summing main + sub-agents
- Avoids double-counting ambiguity
- Clear semantic: each UsageMetrics represents its own context's direct usage

### 2. Field Design

| Field | Type | Purpose |

|-------|------|---------|

| `prompt_tokens` | int32 | Input tokens (consistent with AgentMessage.token_count type) |

| `completion_tokens` | int32 | Output tokens |

| `total_tokens` | int32 | Convenience sum (prompt + completion) |

| `llm_call_count` | int32 | Number of LLM API calls (enables avg tokens/call analysis) |

| `primary_model` | string | Configured/requested model (matches ExecutionConfig.model_name) |

**Why NOT included**:

- `estimated_cost_usd`: Pricing varies by provider, region, tier; better calculated downstream
- `models` repeated field: Future enhancement if multi-model tracking needed

### 3. Update Strategy

**Decision**: Progressive updates during streaming (not just at execution end)

- Users see token count increasing in real-time via status subscriptions
- Consistent with existing `messages` and `tool_calls` progressive updates

## Proto Changes

### New Message: `UsageMetrics`

Add to [`apis/ai/stigmer/agentic/agentexecution/v1/api.proto`](apis/ai/stigmer/agentic/agentexecution/v1/api.proto):

```protobuf
// UsageMetrics tracks token consumption and LLM resource usage.
// Provides execution-level aggregation for cost tracking, billing, and analytics.
//
// ## Scope
//
// Each UsageMetrics instance represents direct LLM usage within its context:
// - AgentExecutionStatus.usage: Main agent's LLM calls (excludes sub-agents)
// - SubAgentExecution.usage: That sub-agent's LLM calls
//
// To calculate total execution cost, sum: status.usage + sum(sub_agent.usage)
//
// ## Token Counting
//
// - prompt_tokens: Input tokens sent to the LLM (context, system prompt, user message)
// - completion_tokens: Output tokens generated by the LLM (response)
// - Extracted from on_chat_model_end events via LangChain usage_metadata
//
// ## Model Tracking
//
// primary_model reflects the configured model from ExecutionConfig.model_name.
// When model is auto-selected or varies per call, this captures the first/main model used.
message UsageMetrics {
  // Total input tokens (prompts) consumed across all LLM calls in this context.
  // Accumulated from each on_chat_model_end event's usage_metadata.input_tokens.
  int32 prompt_tokens = 1;

  // Total output tokens (completions) generated across all LLM calls in this context.
  // Accumulated from each on_chat_model_end event's usage_metadata.output_tokens.
  int32 completion_tokens = 2;

  // Total tokens (prompt + completion). Convenience field for quick reference.
  // Equals: prompt_tokens + completion_tokens
  int32 total_tokens = 3;

  // Number of LLM API calls made in this context.
  // Incremented for each on_chat_model_end event.
  // Useful for: average tokens per call, call frequency analysis.
  int32 llm_call_count = 4;

  // Primary model used for this execution.
  // Typically matches ExecutionConfig.model_name or the first model detected.
  // Examples: "claude-sonnet-4-20250514", "gpt-4o", "gemini-1.5-pro"
  string primary_model = 5;
}
```

## StatusBuilder Implementation

### New Fields in `__init__`

```python
# LLM call counter for usage metrics
self._llm_call_count: int = 0

# Primary model name (captured from first LLM response)
self._primary_model: str = ""

# Per-sub-agent LLM call tracking
self._sub_agent_llm_call_count: Dict[str, int] = {}
self._sub_agent_prompt_tokens: Dict[str, int] = {}
self._sub_agent_completion_tokens: Dict[str, int] = {}
self._sub_agent_primary_model: Dict[str, str] = {}
```

### Update `_handle_chat_model_end_event`

Key changes:

1. Increment `_llm_call_count` (or sub-agent equivalent)
2. Capture model name (first one becomes primary)
3. Build and assign `UsageMetrics` proto to appropriate status
```python
# After extracting tokens and model_name...

if sub_agent:
    # Track sub-agent usage
    self._sub_agent_llm_call_count[sub_agent.id] = \
        self._sub_agent_llm_call_count.get(sub_agent.id, 0) + 1
    self._sub_agent_prompt_tokens[sub_agent.id] = \
        self._sub_agent_prompt_tokens.get(sub_agent.id, 0) + prompt_tokens
    self._sub_agent_completion_tokens[sub_agent.id] = \
        self._sub_agent_completion_tokens.get(sub_agent.id, 0) + completion_tokens
    
    if not self._sub_agent_primary_model.get(sub_agent.id) and model_name:
        self._sub_agent_primary_model[sub_agent.id] = model_name
    
    # Update sub-agent's usage proto
    sub_agent.usage.CopyFrom(self._build_sub_agent_usage(sub_agent.id))
else:
    # Track main agent usage
    self._llm_call_count += 1
    if not self._primary_model and model_name:
        self._primary_model = model_name
    
    # Update main agent's usage proto
    self.current_status.usage.CopyFrom(self._build_usage_metrics())
```


### New Helper Methods

```python
def _build_usage_metrics(self) -> UsageMetrics:
    """Build UsageMetrics proto for main agent."""
    return UsageMetrics(
        prompt_tokens=self._total_prompt_tokens,
        completion_tokens=self._total_completion_tokens,
        total_tokens=self._total_prompt_tokens + self._total_completion_tokens,
        llm_call_count=self._llm_call_count,
        primary_model=self._primary_model,
    )

def _build_sub_agent_usage(self, sub_agent_id: str) -> UsageMetrics:
    """Build UsageMetrics proto for a sub-agent."""
    prompt = self._sub_agent_prompt_tokens.get(sub_agent_id, 0)
    completion = self._sub_agent_completion_tokens.get(sub_agent_id, 0)
    return UsageMetrics(
        prompt_tokens=prompt,
        completion_tokens=completion,
        total_tokens=prompt + completion,
        llm_call_count=self._sub_agent_llm_call_count.get(sub_agent_id, 0),
        primary_model=self._sub_agent_primary_model.get(sub_agent_id, ""),
    )
```

## Semantic Clarity

**Main Agent Usage** (`status.usage`):

- Only tokens from main agent's direct LLM calls
- Does NOT include sub-agent tokens

**Sub-Agent Usage** (`sub_agent_executions[i].usage`):

- Only tokens from that sub-agent's LLM calls
- Isolated from other sub-agents and main agent

**Total Execution Usage** (calculated by consumer):

```python
total = status.usage.total_tokens
for sub in status.sub_agent_executions:
    total += sub.usage.total_tokens
```
