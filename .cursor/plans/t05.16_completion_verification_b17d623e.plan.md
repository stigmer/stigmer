## Key Implementation Details

### Slug-Based Keying

Resources are keyed by `metadata.name` (slug) for O(1) lookup during diff operations:

```java
Map<String, Agent> agents = spec.getAgentsList().stream()
    .filter(a -> a.getMetadata() != null && !a.getMetadata().getName().isEmpty())
    .collect(Collectors.toMap(
        a -> a.getMetadata().getName(),
        Function.identity(),
        (existing, duplicate) -> {
            log.warn("Duplicate agent slug '{}', using first occurrence",
                    existing.getMetadata().getName());
            return existing;
        }
    ));
```

### Edge Case Handling

- **Null spec**: Returns `DesiredState.empty()` with debug logging
- **Duplicate slugs**: Keeps first occurrence, logs warning for visibility
- **Missing names**: Filters out with predicate checking both null metadata and empty name
