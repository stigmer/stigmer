# Phase 2.3: Capture Sub-Agent Internals

## Problem Statement

Currently, `SubAgentExecution` is a black box - it captures only input/output but provides no visibility into internal execution. If a sub-agent fails on its 8th tool call, there's no way to know what happened before the failure.

**Current proto** (`SubAgentExecution` lines 232-270):

- Has: `id`, `name`, `input`, `output`, `status`, `started_at`, `completed_at`, `error`, `metadata`
- Missing: `tool_calls`, `messages` - cannot see what happened inside

**Current StatusBuilder** ([status_builder.py](backend/services/agent-runner/worker/activities/graphton/status_builder.py)):

- Namespace extraction exists (lines 97-106) but is unused
- `namespace_mapping` dict declared (line 74) but never populated
- All events route to main agent regardless of namespace

## Architecture Decision: Flat Fields (Option A)

Adding `tool_calls` and `messages` directly to `SubAgentExecution` rather than a recursive `AgentExecutionStatus`:

**Why Option A wins:**

- Consistent with existing patterns (`AgentMessage` has nested `tool_calls`)
- Simpler to implement, test, and query
- Avoids infinite recursion risks with deeply nested sub-agents
- Sufficient for observability needs - we don't need full status fields in nested context

```python
def _get_execution_context(self, namespace: str) -> Tuple[Any, Optional[SubAgentExecution]]:
    """
    Determine execution context based on namespace.
    
    Returns:
        Tuple of (status_container, sub_agent_or_none)
        - Root events: (self.current_status, None)
        - Sub-agent events: (sub_agent_execution, sub_agent_execution)
    """
    if not namespace or namespace not in self._namespace_to_sub_agent_id:
        return self.current_status, None
    
    sub_agent_id = self._namespace_to_sub_agent_id[namespace]
    sub_agent = self._active_sub_agents.get(namespace)
    return sub_agent, sub_agent
```

```python
def _handle_sub_agent_start(self, event: Dict[str, Any], namespace: str) -> None:
    """
    Handle task tool invocation - creates SubAgentExecution.
    
    The "task" tool is the mechanism for invoking sub-agents in LangGraph.
    We extract sub-agent metadata and create a tracking entry.
    """
    run_id = event.get("run_id", "")
    tool_args = self._unwrap_tool_args(event.get("data", {}).get("input", {}))
    
    sub_agent_name = tool_args.get("subagent_type", "unknown")
    sub_agent_input = tool_args.get("input", "") or tool_args.get("task", "")
    
    now = datetime.utcnow()
    sub_agent = SubAgentExecution(
        id=run_id,
        name=sub_agent_name,
        input=sub_agent_input,
        status=SubAgentStatus.SUB_AGENT_IN_PROGRESS,  # Skip PENDING - already executing
        started_at=now.isoformat(),
    )
    
    # Track for namespace routing (sub-agent namespace will be set on first child event)
    self._active_sub_agents[run_id] = sub_agent
    self.current_status.sub_agent_executions.append(sub_agent)
    
    self.logger.debug(
        f"[SUBAGENT] execution={self.execution_id} "
        f"sub_agent={sub_agent_name} id={run_id} status=IN_PROGRESS"
    )
```

```python
def _handle_sub_agent_end(self, event: Dict[str, Any], namespace: str) -> None:
    """Handle task tool completion - finalize SubAgentExecution."""
    run_id = event.get("run_id", "")
    output = self._extract_tool_result_content(event.get("data", {}).get("output", ""))
    
    # Find and update sub-agent
    for sub_agent in self.current_status.sub_agent_executions:
        if sub_agent.id == run_id:
            sub_agent.output = output
            sub_agent.status = SubAgentStatus.SUB_AGENT_COMPLETED
            sub_agent.completed_at = datetime.utcnow().isoformat()
            break
    
    # Cleanup tracking
    if run_id in self._active_sub_agents:
        del self._active_sub_agents[run_id]
    
    self.logger.debug(
        f"[SUBAGENT] execution={self.execution_id} "
        f"id={run_id} status=COMPLETED"
    )
```

### Step 6: Namespace Discovery on First Child Event

Sub-agent namespace is discovered when first child event arrives:

```python
def _register_sub_agent_namespace(self, namespace: str, run_id: str) -> None:
    """
    Register namespace -> sub-agent mapping when first child event arrives.
    
    LangGraph namespace format: "node_id:uuid" where uuid matches run_id
    """
    if namespace and run_id and namespace not in self._namespace_to_sub_agent_id:
        # Check if this namespace matches an active sub-agent
        for sub_agent_id, sub_agent in self._active_sub_agents.items():
            if sub_agent_id in namespace:
                self._namespace_to_sub_agent_id[namespace] = sub_agent_id
                self.logger.debug(
                    f"[SUBAGENT] Registered namespace={namespace} -> sub_agent={sub_agent_id}"
                )
                break
```
