# Vendor aliases

Some vendors bill under more than one name. Treat each group below as one
vendor when you match invoices, and name it by the first spelling.

- Northwind Traders: Northwind, Northwind Trading Co.
- Contoso Supplies: Contoso, Contoso Supply Ltd
- Fabrikam: Fabrikam Inc., Fabrikam Industrial
