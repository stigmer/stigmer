## What you'll build

A working Agent you can call from your code — in 5 minutes. You will connect to
Stigmer Cloud, send a message, and get a response through the SDK.

**Time**: ~5 minutes **Prerequisites**: A browser and one of:
[Node.js](https://nodejs.org/) 20+, [Go](https://go.dev/) 1.21+,
[Python](https://python.org/) 3.11+, or [Java](https://jdk.java.net/) 17+

<Callout type="info">
  Want to run locally without a cloud account? See the [Local
  Quickstart](/docs/getting-started/local).
</Callout>

## Sign up and get your API key

1. Go to [`app.stigmer.ai`](https://app.stigmer.ai) and create an account.
2. Open **Settings → API Keys** and click **Create API Key**.
3. Copy the key.

<Callout type="info">
  Your API key starts with `sk_`. Keep it secret. Never commit it to source
  control.

## Create a Session and send a message

A Session is a conversation with your Agent. Create one, then send a message to
start an execution. You don't specify which Agent to use — Stigmer's built-in
assistant handles the request automatically.

Add the following to the same file you created in the previous step.

<Tabs items={["TypeScript", "Go", "Python", "Java"]} groupId="sdk-language" persist>

```typescript
  const session = await stigmer.session.create({
    name: `session-${Date.now()}`,

    name: `run-${Date.now()}`,
    org: "my-org",
```

## Stream the response

Subscribe to the execution to receive the Agent's response as it arrives.

Add the following to the same file, right after the code from the previous step.

<Tabs items={["TypeScript", "Go", "Python", "Java"]} groupId="sdk-language" persist>
<Tab value="TypeScript">

Add to `ask-agent.ts`:

```typescript
  for await (const snapshot of stigmer.agentExecution.subscribe(
    execution.metadata!.id,
  )) {
    const messages = snapshot.status?.messages ?? [];
    const last = messages[messages.length - 1];
    if (last?.content) {
      console.log(last.content);
      break;
    }
  }
}

main();
```

</Tab>
<Tab value="Go">

Add to `main.go`:

```go
	stream, err := client.AgentExecution.Subscribe(ctx, exec.GetMetadata().GetId())
	if err != nil {
		log.Fatal(err)
	}

	for {
		snapshot, err := stream.Recv()
		if err == io.EOF {
			break
		}
		if err != nil {
			log.Fatal(err)
		}
		msgs := snapshot.GetStatus().GetMessages()
		if len(msgs) > 0 {
			last := msgs[len(msgs)-1]
			if last.GetContent() != "" {

		}
	}
}
```

`main.go`

```go
package main

import (
	"context"
	"fmt"
	"io"
	"log"
	"os"
	"time"

	stigmer "github.com/stigmer/stigmer/sdk/go"
)

func main() {
	client, err := stigmer.NewClient(os.Getenv("STIGMER_API_KEY"))
	if err != nil {
		log.Fatal(err)
	}
	defer client.Close()

	ctx := context.Background()
	ts := fmt.Sprintf("%d", time.Now().UnixMilli())

	session, err := client.Session.Create(ctx, &stigmer.SessionInput{
		Name: "session-" + ts,
		Org:  "my-org",
	})
	if err != nil {
		log.Fatal(err)
	}

	exec, err := client.AgentExecution.Create(ctx, &stigmer.AgentExecutionInput{
		Name:      "run-" + ts,
		Org:       "my-org",
		SessionId: session.GetMetadata().GetId(),
		Message:   "What are some best practices for handling customer complaints?",
	})
	if err != nil {
		log.Fatal(err)
	}

	stream, err := client.AgentExecution.Subscribe(ctx, exec.GetMetadata().GetId())
	if err != nil {
		log.Fatal(err)
	}

	for {
		snapshot, err := stream.Recv()
		if err == io.EOF {
			break
		}
		if err != nil {
			log.Fatal(err)
		}
		msgs := snapshot.GetStatus().GetMessages()
		if len(msgs) > 0 {
			last := msgs[len(msgs)-1]
			if last.GetContent() != "" {
				fmt.Println(last.GetContent())
				break
			}
		}
	}
}
```

`src/main/java/AskAgent.java`

```java
import ai.stigmer.sdk.StigmerClient;
import ai.stigmer.sdk.gen.SessionInput;
import ai.stigmer.sdk.gen.AgentExecutionInput;

public class AskAgent {
    public static void main(String[] args) {
        var client = StigmerClient.builder(
            System.getenv("STIGMER_API_KEY")
        ).build();

        var ts = String.valueOf(System.currentTimeMillis());

        var session = client.sessions().create(
            SessionInput.builder()
                .name("session-" + ts)
                .org("my-org")
                .build()
        );

        var execution = client.agentExecutions().create(
            AgentExecutionInput.builder()
                .name("run-" + ts)
                .org("my-org")
                .sessionId(session.getMetadata().getId())
                .message("What are some best practices for handling customer complaints?")
                .build()
        );

        var stream = client.agentExecutions().subscribe(
            execution.getMetadata().getId()
        );

        while (stream.hasNext()) {
            var snapshot = stream.next();
            var messages = snapshot.getStatus().getMessagesList();
            if (!messages.isEmpty()) {
                var last = messages.get(messages.size() - 1);
                if (!last.getContent().isEmpty()) {
                    System.out.println(last.getContent());
                    break;
                }
            }
        }
    }
}
```

## What just happened

You called an Agent from your own code through a real API. No Agent
configuration. No infrastructure setup. The built-in assistant handled your
request automatically.

The Agent is good at general knowledge — ask about best practices for handling
complaints, and it gives a solid answer. But change the question to "What is
your return policy for defective items?" and it can only guess. It doesn't know
your return policy, your product catalog, or your escalation process.

In the next guide, you will teach your Agent domain knowledge through the
Stigmer web app. Same question, completely different answer.
