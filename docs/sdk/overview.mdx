The Stigmer SDK provides official client libraries for the Stigmer API in four
languages. Each library offers typed resource clients, structured error
handling, and server-streaming support.

If you are new to Stigmer, start with the
[Quickstart](/docs/getting-started/quickstart) to build a working integration
in 5 minutes, then return here for the full reference.

## Installation

<SDKTabs>
<Tab value="TypeScript">
```bash
npm install @stigmer/sdk
```
</Tab>
<Tab value="Go">
```bash
go get github.com/stigmer/stigmer/sdk/go/v3
```
</Tab>
<Tab value="Python">
```bash
pip install stigmer
```
</Tab>
<Tab value="Java">

Add the dependency to your `pom.xml`:

```xml
<dependency>
  <groupId>ai.stigmer</groupId>
  <artifactId>stigmer-java</artifactId>
</dependency>
```

## Authentication

The SDK supports three authentication methods:

- **API key** (`apiKey`) — A static secret credential for server-side use
  (backends, CLI tools, SSR, CI/CD). Create one in the Stigmer Console under
  **Settings > API Keys**.
- **Identity federation** (`getAccessToken`) — Your users authenticate through
  their existing OIDC provider (Auth0, Okta, Cognito, Entra ID). The SDK sends
  their JWT directly.
  [Set up identity federation](/docs/guides/authentication/federation/overview)
  to enable this.
- **PlatformClient** (`getAccessToken`) — Your backend mints Stigmer tokens per
  user using PlatformClient credentials. Use this to embed Stigmer in your
  product without OIDC setup.
  [Set up PlatformClient](/docs/guides/authentication/platform-client/overview)
  to enable this.

Both `getAccessToken` paths produce the same result: a JWT that the SDK sends as
`Authorization: Bearer`. The difference is where the token comes from. See the
[Authentication guide](/docs/guides/authentication/overview) for help choosing.

### Automation

A key speaks for the account it is for. A CI job, a script or a backend that
uses a person's key stops working when that person leaves, and everything it
does is recorded as them. Give it a
[service account](/docs/guides/authentication/service-accounts) instead, your
Organization's own account for automation, and use that account's key:

```bash
stigmer service-account create ci-deploy --role member
stigmer apikey create --service-account ci-deploy --name github-actions --expires-in 90d
```

Store the key as the job's `STIGMER_API_KEY` secret. A service account's key
works only in its own Organization and keeps working after the admin who created
it leaves.

<Callout type="warn">
  API keys start with `sk_`. Store them in environment variables. Never commit
  them to source control.
</Callout>

<Callout type="error">
  **Never expose API keys in client-side code.** An API key is a secret
  credential that acts with every permission its account holds. In browser apps,
  use `getAccessToken` with
  [identity federation](/docs/guides/authentication/federation/overview) or
  [PlatformClient](/docs/guides/authentication/platform-client/overview) instead.
</Callout>

Set the `STIGMER_API_KEY` environment variable, then pass it to the client
constructor:

<SDKTabs>
<Tab value="TypeScript">
```typescript
import { Stigmer } from "@stigmer/sdk";

const stigmer = new Stigmer({
  baseUrl: "https://api.stigmer.ai",
  apiKey: process.env.STIGMER_API_KEY!,
});
```

Use `getAccessToken` for browser applications. Each user authenticates through
your platform's auth provider, and the callback returns their JWT. With
[JIT provisioning](/docs/guides/authentication/federation/register-federation-issuer#enable-jit-provisioning)
enabled, Stigmer creates accounts automatically on first authentication:

```typescript
const stigmer = new Stigmer({
  baseUrl: "https://api.stigmer.ai",
  getAccessToken: () => fetchTokenFromAuthProvider(),
});
```

Provide exactly one of `apiKey` or `getAccessToken`, not both.
</Tab>
<Tab value="Go">
```go
import stigmer "github.com/stigmer/stigmer/sdk/go/v3"

client, err := stigmer.NewClient(stigmer.WithAPIKey(os.Getenv("STIGMER_API_KEY")))
if err != nil {
    log.Fatal(err)
}
defer client.Close()
```
</Tab>
<Tab value="Python">
```python
from stigmer import StigmerClient

client = StigmerClient(os.environ["STIGMER_API_KEY"])
```

The Python client also supports the context manager protocol:

```python
with StigmerClient(os.environ["STIGMER_API_KEY"]) as client:
    agent = client.agents.get("agent-id")
```
</Tab>
<Tab value="Java">
```java
import ai.stigmer.sdk.StigmerClient;

try (var client = StigmerClient.builder(
        System.getenv("STIGMER_API_KEY")
    ).build()) {
    // use client
}
```
</Tab>
</SDKTabs>

## Configuration

All SDKs connect to `api.stigmer.ai` by default. Override the endpoint when
connecting to a different server:

<SDKTabs>
<Tab value="TypeScript">
```typescript
const stigmer = new Stigmer({
  baseUrl: "https://custom-api.example.com",
  apiKey: process.env.STIGMER_API_KEY!,
  transport: "connect", // default: "grpc-web"
});
```

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `baseUrl` | `string` | — | HTTPS URL of the Stigmer API server. Required. |
| `apiKey` | `string` | — | Static API key. |
| `getAccessToken` | `() => string \| null` | — | Dynamic token provider. |
| `transport` | `"grpc-web" \| "connect"` | `"grpc-web"` | Wire protocol. `connect` uses HTTP/JSON for easier debugging. |
| `onUnauthenticated` | `() => void` | — | Called once when the server returns UNAUTHENTICATED. |
</Tab>
<Tab value="Go">
```go
client, err := stigmer.NewClient(
    os.Getenv("STIGMER_API_KEY"),
    stigmer.WithBaseURL("custom-api.example.com:443"),
)
```

| Option | Description |
|--------|-------------|
| `WithBaseURL(target)` | gRPC target address (`host:port`). Default: `api.stigmer.ai:443`. |
| `WithInsecure()` | Disable TLS. Use only for local development. |
| `WithDialOptions(opts...)` | Append additional gRPC dial options. |

Always call `defer client.Close()` to release the underlying gRPC connection.
</Tab>
<Tab value="Python">
```python
client = StigmerClient(
    os.environ["STIGMER_API_KEY"],
    base_url="custom-api.example.com:443",
)
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `api_key` | `str` | — | API key. Required. |
| `base_url` | `str` | `api.stigmer.ai:443` | gRPC target address (`host:port`). |
| `insecure` | `bool` | `False` | Disable TLS. Use only for local development. |
</Tab>
<Tab value="Java">
```java
var client = StigmerClient.builder(System.getenv("STIGMER_API_KEY"))
    .baseUrl("custom-api.example.com:443")
    .build();
```

| Method | Description |
|--------|-------------|
| `.baseUrl(target)` | gRPC target address (`host:port`). Default: `api.stigmer.ai:443`. |
| `.insecure()` | Disable TLS. Use only for local development. |

`StigmerClient` implements `AutoCloseable`. Use try-with-resources to ensure
the gRPC channel shuts down cleanly.
</Tab>
</SDKTabs>

## Resource clients

Every SDK organizes the API around **resource clients**. Each resource has its
own client with methods like `get`, `create`, `list`, `apply`, `update`, and
`delete`.

<SDKTabs>
<Tab value="TypeScript">
```typescript
stigmer.agent.get(id)
stigmer.session.create(input)
stigmer.session.streamEvents(request)
```

TypeScript uses singular camelCase accessors on the `Stigmer` instance.
</Tab>
<Tab value="Go">
```go
client.Agent.Get(ctx, id)
client.Session.Create(ctx, &stigmer.SessionInput{...})
client.Session.StreamEvents(ctx, request)
```

Go uses singular PascalCase fields. Every method takes a `context.Context` as
its first argument.
</Tab>
<Tab value="Python">
```python
client.agents.get(id)
client.sessions.create(SessionInput(...))
client.sessions.stream_events(request)
```

Python uses plural snake_case attributes.
</Tab>
<Tab value="Java">
```java
client.agent.get(id);
client.session.create(SessionInput.builder()...build());
client.session.streamEvents(request);
```

Java uses singular camelCase fields on the client.
</Tab>
</SDKTabs>

Browse the sidebar for the full list of resources. Each resource page documents
every method, its parameters, and its return types.

## Error handling

All SDK methods throw a structured error type that wraps the underlying gRPC
status code into a portable error code. Each SDK provides classification
helpers to check common error conditions without inspecting codes directly.

| Language | Error type | Import |
|----------|-----------|--------|
| TypeScript | `StigmerError` | `@stigmer/sdk` |
| Go | `*stigmer.Error` | `github.com/stigmer/stigmer/sdk/go/v3` |
| Python | `StigmerError` | `stigmer` |
| Java | `StigmerException` | `ai.stigmer.sdk.gen` |

### Classification helpers

| Helper | Returns `true` when |
|--------|-------------------|
| `isNotFound` | The requested resource does not exist. |
| `isUnauthenticated` | The API key is missing or not accepted. |
| `isPermissionDenied` | The API key lacks the required permission. |
| `isRetryable` | The error is transient (server error or temporarily unavailable). |

<SDKTabs>
<Tab value="TypeScript">
```typescript
import { StigmerError, isNotFound, isRetryable } from "@stigmer/sdk";

try {
  const agent = await stigmer.agent.get(id);
} catch (err) {
  if (isNotFound(err)) {
    console.log("Agent does not exist");
    return;
  }
  if (isRetryable(err)) {
    // wait and retry
  }
  throw err;
}
```

The TypeScript SDK also exports `classifyError(err)` which returns an
`ErrorCategory` string (`"auth"`, `"permission"`, `"not-found"`,
`"validation"`, `"server"`, `"unavailable"`, `"cancelled"`, `"unknown"`) and
`getUserMessage(err)` which returns a clean, user-appropriate error message.
</Tab>
<Tab value="Go">
```go
agent, err := client.Agent.Get(ctx, id)
if err != nil {
    if stigmer.IsNotFound(err) {
        log.Println("Agent does not exist")
        return
    }
    log.Fatal(err)
}
```
</Tab>
<Tab value="Python">
```python
from stigmer import StigmerError, is_not_found, is_retryable

try:
    agent = client.agents.get(id)
except StigmerError as err:
    if is_not_found(err):
        print("Agent does not exist")
        return
    if is_retryable(err):
        pass  # wait and retry
    raise
```
</Tab>
<Tab value="Java">
```java
import ai.stigmer.sdk.gen.StigmerException;

try {
    var agent = client.agent.get(id);
} catch (StigmerException e) {
    if (e.isNotFound()) {
        System.out.println("Agent does not exist");
        return;
    }
    if (e.isRetryable()) {
        // wait and retry
    }
    throw e;
}
```
</Tab>
</SDKTabs>

## Pagination

Every list pages one way. A request takes `pageSize` and `pageToken`; a
response carries `entries` and `nextPageToken`, newest first. A `pageSize` of 0
asks for the default page of 50, and a size above 100 is read as 100. Pass a
response's `nextPageToken` back as `pageToken` to get the next page; an empty
token means the list is done. A page can hold fewer entries than `pageSize`,
even none, and still carry a token, so keep going until the token is empty.
Lists do not count their entries: a list says whether more follow, not how
many there are.

Every list method has a page iterator beside it that follows the tokens for
you: `list` has `listAll`, `listByAgent` has `listByAgentAll`, and so on
(`ListAll` in Go, `list_all` in Python). Breaking out of the loop stops the
reads.

<SDKTabs>
<Tab value="TypeScript">
```typescript
for await (const session of stigmer.session.listAll({ org: "acme" })) {
  console.log(session.metadata?.name);
}

// Or one page at a time:
const page = await stigmer.session.list({ org: "acme", pageSize: 25 });
const next = await stigmer.session.list({ org: "acme", pageSize: 25, pageToken: page.nextPageToken });
```
</Tab>
<Tab value="Go">
```go
for s, err := range client.Session.ListAll(ctx, &sessionv1.ListSessionsRequest{Org: "acme"}) {
    if err != nil {
        log.Fatal(err)
    }
    fmt.Println(s.GetMetadata().GetName())
}

// Or one page at a time:
page, err := client.Session.List(ctx, &sessionv1.ListSessionsRequest{Org: "acme", PageSize: 25})
if err != nil {
    log.Fatal(err)
}
next, err := client.Session.List(ctx, &sessionv1.ListSessionsRequest{
    Org:       "acme",
    PageSize:  25,
    PageToken: page.GetNextPageToken(),
})
```
</Tab>
<Tab value="Python">
```python
from ai.stigmer.agentic.session.v1 import io_pb2

for session in client.sessions.list_all(io_pb2.ListSessionsRequest(org="acme")):
    print(session.metadata.name)

# Or one page at a time:
page = client.sessions.list(io_pb2.ListSessionsRequest(org="acme", page_size=25))
next_page = client.sessions.list(io_pb2.ListSessionsRequest(
    org="acme",
    page_size=25,
    page_token=page.next_page_token,
))
```
</Tab>
<Tab value="Java">
```java
import ai.stigmer.agentic.session.v1.ListSessionsRequest;

for (var session : client.session.listAll(ListSessionsRequest.newBuilder().setOrg("acme").build())) {
    System.out.println(session.getMetadata().getName());
}

// Or one page at a time:
var page = client.session.list(ListSessionsRequest.newBuilder().setOrg("acme").setPageSize(25).build());
var next = client.session.list(ListSessionsRequest.newBuilder()
    .setOrg("acme")
    .setPageSize(25)
    .setPageToken(page.getNextPageToken())
    .build());
```
</Tab>
</SDKTabs>

`sessionv1` is
`github.com/stigmer/stigmer/sdk/go/v3/proto/ai/stigmer/agentic/session/v1`.

## Streaming

A Session's output is one ordered log of events, in the Claude Managed Agents
event format: the Agent's messages, its tool uses and their results, the calls
waiting for an approval, and each run's `stigmer.run.status`. Every event
carries the run (`run_id`) and the thread (`thread_id`, empty for the Agent's
own) it belongs to.

`streamEvents` follows the log. With `after_seq` set to 0 it first sends every
event already stored, then each new one as it's appended. This example prints
the Agent's messages for one run until the run ends.

<SDKTabs>
<Tab value="TypeScript">
```typescript
import { followSession } from "@stigmer/sdk";

const ended = ["completed", "failed", "cancelled", "terminated"];
for await (const frame of followSession(stigmer, sessionId)) {
  if (frame.frame.case !== "event") continue;
  const { runId: eventRunId, threadId, event } = frame.frame.value;
  if (eventRunId !== runId) continue;
  if (event.case === "agentMessage" && threadId === "") {
    console.log(event.value.content.map((block) => block.text).join(""));
  }
  if (event.case === "stigmerRunStatus" && ended.includes(event.value.phase)) {
    break;
  }
}
```

`followSession` wraps `streamEvents` and reconnects from the last event it
delivered when the stream drops. To send a message and wait for the answer in
one call, use `sendAndWait`.
</Tab>
<Tab value="Go">
```go
stream, err := client.Session.StreamEvents(ctx, &sessionv1.StreamSessionEventsRequest{
    SessionId: sessionID,
    AfterSeq:  proto.Int64(0),
})
if err != nil {
    log.Fatal(err)
}
for {
    frame, err := stream.Recv()
    if err != nil {
        log.Fatal(err)
    }
    event := frame.GetEvent()
    if event.GetRunId() != runID {
        continue
    }
    if msg := event.GetAgentMessage(); msg != nil && event.GetThreadId() == "" {
        for _, block := range msg.GetContent() {
            fmt.Print(block.GetText())
        }
        fmt.Println()
    }
    if status := event.GetStigmerRunStatus(); status != nil {
        switch status.GetPhase() {
        case "completed", "failed", "cancelled", "terminated":
            return
        }
    }
}
```

`sessionv1` is
`github.com/stigmer/stigmer/sdk/go/v3/proto/ai/stigmer/agentic/session/v1`, and
`proto` is `google.golang.org/protobuf/proto`.
</Tab>
<Tab value="Python">
```python
from ai.stigmer.agentic.session.v1 import io_pb2

ENDED = {"completed", "failed", "cancelled", "terminated"}

request = io_pb2.StreamSessionEventsRequest(session_id=session_id, after_seq=0)
for frame in client.sessions.stream_events(request):
    event = frame.event
    if event.run_id != run_id:
        continue
    kind = event.WhichOneof("event")
    if kind == "agent_message" and not event.thread_id:
        print("".join(block.text for block in event.agent_message.content))
    if kind == "stigmer_run_status" and event.stigmer_run_status.phase in ENDED:
        break
```
</Tab>
<Tab value="Java">
```java
import ai.stigmer.agentic.session.v1.StreamSessionEventsRequest;

var ended = Set.of("completed", "failed", "cancelled", "terminated");
var stream = client.session.streamEvents(StreamSessionEventsRequest.newBuilder()
    .setSessionId(sessionId)
    .setAfterSeq(0)
    .build());
while (stream.hasNext()) {
    var event = stream.next().getEvent();
    if (!event.getRunId().equals(runId)) {
        continue;
    }
    if (event.hasAgentMessage() && event.getThreadId().isEmpty()) {
        for (var block : event.getAgentMessage().getContentList()) {
            System.out.print(block.getText());
        }
        System.out.println();
    }
    if (event.hasStigmerRunStatus()
            && ended.contains(event.getStigmerRunStatus().getPhase())) {
        break;
    }
}
```
</Tab>
</SDKTabs>
