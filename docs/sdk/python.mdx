The `stigmer` package is the official Python client for the Stigmer API. It
provides typed resource clients, structured error handling, and
server-streaming support over gRPC.

## Installation

```bash
pip install stigmer
```

## Create a client

Authenticate with an API key from an environment variable:

```python
from stigmer import StigmerClient

client = StigmerClient(os.environ["STIGMER_API_KEY"])
```

The client also supports the context manager protocol, which closes the
connection when the block exits:

```python
with StigmerClient(os.environ["STIGMER_API_KEY"]) as client:
    agent = client.agents.get("agent-id")
```

The client connects to `api.stigmer.ai:443` by default; override with the
`base_url` parameter. See
[SDK Overview > Authentication](/docs/sdk/overview#authentication) for
authentication methods and
[SDK Overview > Configuration](/docs/sdk/overview#configuration) for all
options.

## Make your first call

Every resource has its own client with methods like `get`, `create`, `list`,
`apply`, and `delete`. Python uses plural snake_case attributes:

```python
from stigmer import StigmerError, is_not_found

try:
    agent = client.agents.get(agent_id)
    print(agent.metadata.name)
except StigmerError as err:
    if is_not_found(err):
        print("Agent does not exist")
    else:
        raise
```
