The Stigmer Go SDK is the official Go client for the Stigmer API. It provides
typed resource clients, structured error handling, and server-streaming
support over gRPC.

## Installation

```bash
go get go.stigmer.ai/sdk
```

## Create a client

Authenticate with an API key from an environment variable. Always call
`defer client.Close()` to release the underlying gRPC connection:

```go
import (
    "log"
    "os"

    stigmer "go.stigmer.ai/sdk"
)

client, err := stigmer.NewClient(stigmer.WithAPIKey(os.Getenv("STIGMER_API_KEY")))
if err != nil {
    log.Fatal(err)
}
defer client.Close()
```

In a CI job or a script, use a service account's key, not a person's: see
[SDK Overview > Automation](/docs/sdk/overview#automation).

The client connects to `api.stigmer.ai:443` by default; override with
`stigmer.WithBaseURL(target)`. See
[SDK Overview > Authentication](/docs/sdk/overview#authentication) for
authentication methods and
[SDK Overview > Configuration](/docs/sdk/overview#configuration) for all
options.

## Run an agent

This program connects to the Stigmer running on your machine, sets up a small
agent, asks it one thing and prints its answer. Start Stigmer first with
`stigmer up` and give it a model key
([Start Stigmer and add your model key](/docs/getting-started/quickstart#start-stigmer-and-add-your-model-key)); without a key the server
refuses the message, and the program prints why.

```go
// The Stigmer quick start: connect to the Stigmer running on this machine,
// set up a small agent, ask it one thing and print its answer.
//
// Start Stigmer first with `stigmer up` (given a model key), then: go run .
package main

import (
	"context"
	"fmt"
	"log"

	stigmer "go.stigmer.ai/sdk"
)

func main() {
	log.SetFlags(0)

	// `stigmer up` serves on localhost:7234 and needs no key on your machine.
	client, err := stigmer.NewClient(stigmer.WithBaseURL("localhost:7234"), stigmer.WithInsecure())
	if err != nil {
		log.Fatal(err)
	}
	defer client.Close()
	ctx := context.Background()

	// Apply creates the agent, or updates it when you run this again.
	agent, err := client.Agent.Apply(ctx, &stigmer.AgentInput{
		Name:         "greeter",
		Org:          "stigmer",
		Instructions: "You greet people in one short, friendly sentence.",
	})
	if err != nil {
		log.Fatal(err)
	}

	turn, err := client.SendAndWait(ctx, &stigmer.RunInput{
		Org:         "stigmer",
		SessionSpec: &stigmer.SessionSpecInput{AgentRef: stigmer.ResourceRef{Org: "stigmer", Slug: agent.GetMetadata().GetSlug()}},
		Message:     "Say hello to a developer trying Stigmer for the first time.",
	})
	if err != nil {
		log.Fatal(err)
	}
	if turn.Phase != "completed" {
		log.Fatalf("the turn did not complete (%s): %s", turn.Phase, turn.Error)
	}
	fmt.Println(turn.Answer)
}
```

`SendAndWait` sends the message and waits for the agent's answer, reconnecting if the stream drops. A turn that waits for a person's approval returns with `Phase` `waiting` and its `Asks`; answer them with `client.Session.ConfirmToolUse`, then call `client.WaitForTurn` with the outcome's `LastSeq`.

On Stigmer Cloud, connect with
`stigmer.NewClient(stigmer.WithAPIKey(os.Getenv("STIGMER_API_KEY")))` (keys
read `stk_…`), and use your own organization where the program says
`"stigmer"`.

## Make your first call

Every resource has its own client with methods like `Get`, `Create`, `List`,
`Apply`, `Update`, `Rename`, and `Delete`
([Update and apply](/docs/sdk/overview#update-and-apply)). Go uses singular PascalCase fields, and every method
takes a `context.Context` as its first argument:

```go
import (
	"fmt"
	"log"
)

var id string
// ---cut---
agent, err := client.Agent.Get(ctx, id)
if err != nil {
    if stigmer.IsNotFound(err) {
        log.Println("Agent does not exist")
        return
    }
    log.Fatal(err)
}
fmt.Println(agent.GetMetadata().GetName())
```
