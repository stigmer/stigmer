## Hooks

### useAgentEval

Data hook that loads one `AgentEval` through `agenteval.get()`
and, while it is pending or running, reads it again every
[`AGENT_EVAL_POLL_MS`](#agent_eval_poll_ms) so its tries fill in as they finish. Polling
stops once the eval is completed, partial or failed, or a read answers
NotFound or PermissionDenied.

Pass an empty `id` to skip fetching.

```tsx
function useAgentEval(id: string): UseAgentEvalReturn
```

### useCancelAgentEval

Behavior hook that cancels a pending or running `AgentEval`
through `agenteval.cancel()`. Tries in flight are stopped; the eval ends
partial, "cancelled", with the results of the tries that finished.
Cancelling a finished eval changes nothing. Only the agent's editors
may.

### useStartAgentEval

Behavior hook that starts an `AgentEval` through
`agenteval.create()`. Only the agent's editors may; the server's refusal
(an agent whose plugins have no eval cases, a plugin it does not attach,
more tries than an eval may run, a missing permission) is surfaced as
`error`. The eval's organization pays for every try and every AI-graded
check.

**Signature**

```tsx
function useStartAgentEval(): UseStartAgentEvalReturn
```
