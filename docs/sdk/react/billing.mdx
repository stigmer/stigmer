### usePeriodEstimate

period will be invoiced.

changed: the plan's monthly fee for the whole period, plus the child

### ProviderKeysSection

Settings section for an organization's own provider keys.

On Stigmer Cloud every model call runs on a key the organization owns, on
every plan: an admin saves an Anthropic or OpenAI key, optionally against
the organization's own Anthropic- or OpenAI-compatible endpoint (a company
gateway, a model server it runs), and a Cursor key (a user API key or a
team service-account key, always on Cursor's own hosts) for the agents
that run on Cursor; its agents run on them. The provider bills the
organization directly. A run that needs a provider with no key is refused

Every member sees the list; admins (`can_manage_billing`) save, replace

### PLAN_UPGRADE_REQUIRED

The reason Stigmer Cloud refuses an act the organization's plan does not
include (iam/team/v1 and tenancy/organization/v1 command.proto).


### planMove

The move choosing `target` (a plan, or `"free"`) makes from `standing`, or `null` for none.

```tsx
function planMove(standing: PlanStanding, target: Plan | "free", periodEnd: Date | undefined): PlanMove | null
```


### PlanMove

What choosing a plan (or Free) would do.


### planStanding

The standing a stored subscription gives at `now`: the engine's live
rule (active, past due, or canceled but not yet at its period's end),
else Free. `null` (never subscribed) is Free.

```tsx
function planStanding(subscription: Subscription | null, now: Date): PlanStanding
```


### PlanStanding

An organization's standing on its plan.


### planUpgradeFeature

The feature a refusal says the organization's plan lacks, when `error`
is Stigmer Cloud's `PLAN_UPGRADE_REQUIRED`; `null` for any other error.

```tsx
function planUpgradeFeature(error: unknown): Feature | null
```


### PROVIDER_KEY_REQUIRED

The reason Stigmer Cloud refuses a run that needs a provider the
organization holds no key for: its model's, or Cursor for a run on the
Cursor harness (billing/providerkey/v1/api.proto).


### ProviderKeyProvider

The providers an organization holds a key for, by their wire names.
`anthropic` is Anthropic's API or any endpoint that speaks it, `openai` is
OpenAI's or any endpoint that speaks it; `cursor` is a Cursor user API key
or team service-account key, served from Cursor's own hosts and saved
without a base URL.


### providerKeyRequired

What a refusal names, when `error` is Stigmer Cloud's
`PROVIDER_KEY_REQUIRED`; `null` for any other error.

```tsx
function providerKeyRequired(error: unknown): ProviderKeyRequired | null
```
