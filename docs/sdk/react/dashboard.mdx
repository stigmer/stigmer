## Hooks

### useAgentRunSummary

Data hook that fetches aggregated agent run statistics for an
organization. Returns phase counts, active count, average duration,
and top failing agents.

Cost is intentionally excluded from this response — the dashboard
sources cost from `useOrgUsageReport` (billing source of truth), so
cost is never counted from two sources.

### useDashboardSummary

Composition hook that merges the agent run summary and the org usage
report into a single [`DashboardSummary`](#dashboardsummary).

- Run counts (active, completed, failed) come from the agent run
  summary over the last seven days.
- Cost comes from `getOrgUsageReport` (billing source of truth), not
  from summing per-run costs, so the dashboard shows what billing
  recorded.

### OperationalDashboard

Composed dashboard widget showing an organization's agent run
operational metrics.

not from summing per-run costs, so the dashboard shows what billing
recorded.
