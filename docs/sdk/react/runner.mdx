## Hooks

### useRunnerList

Data hook that fetches runners for an organization.

Calls `stigmer.runner.list({ org })` and returns the result with
loading/error state. System-managed (ephemeral cloud) runners are
filtered out by default — pass `includeSystemManaged: true` to
include them (useful for admin panels like Settings > Runners).

Returns an empty array when `org` is `null` (no organization selected).

**Signature**

```tsx
function useRunnerList(org: string | null, options?: UseRunnerListOptions): UseRunnerListReturn
```

Each runner is rendered as a card row showing name, phase indicator,

context that needs runner fleet visibility. Fetches data via
[`useRunnerList`](#userunnerlist) — no Console-specific dependencies.

### RunnerPicker

Theme-able runner picker built on `@base-ui/react` Select.

Fetches available runners via [`useRunnerList`](#userunnerlist) and renders
them in a dropdown grouped by operational phase. READY runners
appear first, then BUSY (selectable), then inactive runners
(STOPPED/PENDING/FAILED — visible but disabled).

Includes an "Auto" option (default) that lets the backend decide
which runner to use. Platform builders who manage runner assignment
programmatically can disable this via `showAutoOption={false}`.

All visual properties flow through `--stgm-*` tokens — no
hardcoded colors or sizes.

Platform builders who need different rendering use
[`useRunnerList`](#userunnerlist) directly.

## Types

### isActivePhase

Whether the runner is in an active (workload-accepting) phase.

Active = `READY` or `BUSY`. Inactive = everything else.

```tsx
function isActivePhase(phase: RunnerPhase): boolean
```


### PHASE_SORT_ORDER

Sort order for runner phases — active phases first, then by severity.

Used by both [`RunnerPicker`](#runnerpicker) and [`RunnerListPanel`](#runnerlistpanel) to present
runners in a consistent, predictable order across all UI surfaces.


### phaseDotColor

Tailwind `bg-*` class for the small colored dot indicator.

- Ready  → `bg-success`  (green)
- Busy   → `bg-warning`  (amber)
- Others → `bg-muted-foreground` (neutral)

```tsx
function phaseDotColor(phase: RunnerPhase): string
```


### phaseLabel

Human-readable label for a runner phase.

("Ready") and full-row display ("Stopped").
