## Hooks

### useCancelEvalRun

Behavior hook that cancels a pending or running `EvalRun` through
`evalrun.cancel()`. Tries in flight are stopped; the eval run ends
partial, "cancelled", with the results of the tries that finished.
Cancelling a finished eval run changes nothing. Only the editors of its
agent or plugin may.

### useEvalRun

while it is pending or running, reads it again every
[`EVAL_RUN_POLL_MS`](#eval_run_poll_ms) so its tries fill in as they finish. Polling
stops once the eval run is completed, partial or failed, or a read

### useStartEvalRun

Behavior hook that starts an `EvalRun` through `evalrun.create()`.
Only the editors of its agent or plugin may, and comparing a plugin the
agent does not attach takes being able to view it; the server's refusal
(no evals/ cases, more than an eval run may run, a missing permission)
is surfaced as `error`. The eval run's organization pays for every try
and every AI-graded check.

**Signature**

```tsx
function useStartEvalRun(): UseStartEvalRunReturn
```
