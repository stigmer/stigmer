## Hooks

### useFileReferences

Behavior hook managing workspace file references for the composer.

File references are lightweight "attention" signals — workspace-relative
paths the user wants the agent to focus on. Unlike attachments, they
require no upload; the agent reads them directly from the workspace
filesystem post-provisioning.

This hook is independently importable by platform builders who want
to manage file references with their own UI (headless-first, DD-003).

**Signature**


## Components

### FileReferenceChipList

Renders a horizontal list of workspace file-reference chips.

Each chip shows the workspace-relative path (truncated) with a remove
button. Unlike attachment chips, file references have no upload
lifecycle — they are instant, lightweight "attention" signals.

Designed to sit alongside [`AttachmentChipList`](/docs/sdk/react/attachment#attachmentchiplist) in the composer's
attachments zone. Usable standalone by platform builders who compose
their own file-reference UI (headless-first, DD-003).

All visual properties flow through `--stgm-*` tokens (DD-005).
