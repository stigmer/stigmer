## Hooks

### useAgentScoringRule

Data hook that loads an agent's `ScoringRule`, the setting that
switches AI grading on for it, through `scoringrule.getByAgent()`. Anyone
who can view the agent can read it; an agent with grading off answers
`null`.

Pass an empty `agentId` to skip fetching, while the agent is loading.

### useSaveScoringRule

Behavior hook that writes an agent's `ScoringRule` through
`scoringrule.create()` or `scoringrule.update()`. An update names the
grading settings alone (`GRADING_SETTING_PATHS`) on the scoring rule
as loaded, carrying the etag it was read at, so a scoring rule changed
since it was read refuses the save. Only someone who can edit
the agent may; the server's refusal is surfaced as `error`. Turning
grading off is a save with `enabled: false`, which keeps this month's
spend and counts.
