Every demo on this page is the real `@stigmer/react-sdk` component, drawn by the
same code the kit's screenshot tests approve. A scripted server answers instead
of an agent: send a message and the agent reads two files, asks before it runs
`git log`, and answers when you approve. Nothing you type leaves your browser.

## AgentChat

`AgentChat` is the whole chat in one component. It comes in three frames: a
page of its own, a panel you dock beside your product, and a corner popup. See
[The chat in one component](/docs/sdk/react#the-chat-in-one-component) for the
props.

## Make it yours

The [theme playground](/docs/sdk/theme/theming#try-a-look) dresses the chat in
each preset, light or dark, and shows the code to copy. To build a chat of your
own from the hooks alone, see
[Build a chat from the hooks](/docs/sdk/react-core/build-a-chat).
