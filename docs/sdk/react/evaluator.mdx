## Hooks

### useAgentEvaluator

Data hook that loads an agent's `Evaluator`, the setting that
switches AI grading on for it, through `evaluator.getByAgent()`. Anyone
who can view the agent can read it; an agent with grading off answers
`null`.

Pass an empty `agentId` to skip fetching, while the agent is loading.

```tsx
function useAgentEvaluator(agentId: string): UseAgentEvaluatorReturn
```

### useSaveEvaluator

Behavior hook that writes an agent's `Evaluator` through
`evaluator.create()` or `evaluator.update()`. Only someone who can edit
the agent may; the server's refusal is surfaced as `error`. Turning
grading off is a save with `enabled: false`, which keeps this month's
spend and counts.

```tsx
function useSaveEvaluator(): UseSaveEvaluatorReturn
```
