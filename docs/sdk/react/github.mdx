### useGitHubConnection

Behavior hook that manages the GitHub connection lifecycle.

Handles the OAuth flow: the authorize URL from the Stigmer backend,
then the exchange, which the server completes by saving the token as
the `github.com` login in the caller's My vault in `org`. The token
never reaches the page.

Pass `null` as `org` to disable (the hook reports not connected).

### useGitHubFileReader

Creates a [`WorkspaceFileReader`](/docs/sdk/react/workspace#workspacefilereader) backed by the server's GitHub
file read.

Returns `undefined` when `org` is `null` (GitHub not connected),
mirroring the tree lister so callers can treat "no reader" and "no
lister" identically.

The reader itself:
- Returns `null` when the entry is not a readable GitHub git repo
  (non-git entry, missing/unparseable URL) — the "unsupported here" state.
- Throws `WorkspaceFileNotFoundError` when the file is not at the
  ref, so consumers can fall back to session-captured content for files
  not yet pushed; throws plainly on any other failure.
