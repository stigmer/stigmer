### set

Save the organization's key for a provider.

Allowed on every plan. The key is checked once against the provider (or the base URL, when one is given) before it is saved, and a key the provider rejects is refused with INVALID_ARGUMENT, as is a base URL that is not https or does not resolve to a public address. Returns the saved key without its secret.
