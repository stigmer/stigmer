An AgentShare turns an agent into a hosted chat link. It controls who can
chat with the agent at `/chat/<share id>` (anyone with the link, or org
members only), which sites may embed the chat widget, the messages visitors
see when a limit refuses them, and the shared vaults guest conversations
use. The link names the share only by its permanent ID, so
renaming the organization never breaks it; the share's slug names it within
its organization for the CLI and API. Each guest conversation starts on the
version `agent_ref` names, or on the agent's current version when it names none,
and the referenced agent is never modified by share operations.

```yaml
apiVersion: agentic.stigmer.ai/v1
kind: AgentShare
metadata:
  name: org-knowledge-agent
  org: workshop
spec:
  agent_ref:
    kind: agent
    org: workshop
    slug: org-knowledge-agent
  enabled: true
  audience: agent_share_audience_public
  allowed_origins:
    - "https://docs.example.com"
  messages:
    rate_limited: "You're sending messages too quickly — give it a moment."
  vaults:
    - kind: vault
      org: workshop
      slug: github-org-shared
```

### getSharedProfile

Get the public profile of a shared agent by the share's id.

This is the resolution path for the hosted chat page: anonymous visitors (no Stigmer account, no token) resolve a shared link to the trimmed SharedAgentProfile — never the full Agent, whose spec carries the system prompt, environment declarations, and MCP wiring.

Returns NOT_FOUND when the share does not exist, is disabled, has the org audience (anonymous callers must not be able to distinguish an org-internal share from a nonexistent one; use getSharedProfileForMember instead), or the share link is locked and link_token does not match the share's current status.share_link_token. The same NOT_FOUND answers when the share's organization no longer exists. The cases are deliberately indistinguishable so an unshared, revoked, or rotated URL leaks nothing. Returns INVALID_ARGUMENT when share_id is empty.

### getSharedProfileForMember

Get the profile of a shared agent as a signed-in organization member.

This is the resolution path for the hosted chat page when a share has the org audience: the public getSharedProfile deliberately returns NOT_FOUND for such shares, so a signed-in member resolves the same trimmed SharedAgentProfile through this authenticated RPC instead. ### update

Update an agent share: the fields update_mask names change, every other field keeps its stored value.

The referenced agent is immutable. A mask naming the audience or the vaults replaces them whole: an empty audience makes the share organization-only, and empty vaults detach them (both fail closed).

resource.metadata.id names the agent share; apply finds one by slug. The slug changes only through rename, and a mask naming a field another door owns, or a path the agent share does not have, is refused with INVALID_ARGUMENT naming the path.

An update is refused with ABORTED carrying a google.rpc.ErrorInfo detail (domain "stigmer.ai"):

- ETAG_MISMATCH — resource.metadata.etag is set and the agent share changed since that etag was read: read it again and make the change again. No metadata. - WRITE_CONFLICT — the agent share kept changing while the update was being saved: try again. No metadata.

### rotateShareLink

Rotate the share's link token.

Generates a fresh server-side token for the share's hosted chat link. The share URL becomes `/chat/&lt;share id&gt;?k=&lt;token&gt;` and the previous link (tokened or plain) stops working immediately — including for visitors mid-conversation. Use this to kill a leaked or over-shared public link without disabling or deleting the share.

The token lives in status.share_link_token, so manifest applies never reset it. Rotation affects public-audience shares only; org-audience access is governed by live org membership instead.

### AgentShareAudience

AgentShareAudience selects who can chat over a share's hosted link.

| Value | Description |
|-------|-------------|
| `agent_share_audience_public` | Anyone with the link can chat — no Stigmer account required. |
| `agent_share_audience_org` | Only signed-in members of the sharing organization can chat. |

### ServiceTier

ServiceTier selects the provider-side speed/service tier for a run's model calls.

| Value | Description |
|-------|-------------|
| `SERVICE_TIER_STANDARD` | Standard tier: the model's base-priced configuration, requested explicitly. |
| `SERVICE_TIER_FAST` | Fast tier: the model's fast variant, billed at the registry's fast variant rates. |

### ThinkingMode

ThinkingMode selects the model's extended-reasoning ("thinking") variant for a run's model calls — the second variant dimension alongside ServiceTier (stigmer/stigmer#772).

| Value | Description |
|-------|-------------|
| `THINKING_MODE_DISABLED` | Extended reasoning off: the model's base variant, requested explicitly (thinking=false pinned where the model declares the parameter). |
| `THINKING_MODE_ENABLED` | Extended reasoning on: the model's thinking variant, billed at base per-token rates (reasoning tokens bill as output tokens). |
