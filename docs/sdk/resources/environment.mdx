An Environment is a named sandbox setup: the packages installed in every
sandbox a conversation using it runs in (`apt`, `cargo`, `gem`, `go`, `npm`,
`pip`), and the websites it may reach (`networking`: `unrestricted`, or
`limited` to `allowed_hosts`, optionally with the package registries and the
agent's MCP servers). A conversation uses the Environment it names, else its
routine's, else its agent's default, else its organization's. It holds no
secret, variable or image, and only an organization's admins create one.

```yaml
apiVersion: agentic.stigmer.ai/v1
kind: Environment
metadata:
  name: Data science
  slug: data-science
spec:
  description: "pandas and poppler, GitHub and our API only"
  networking:
    type: limited
    allowed_hosts: [api.github.com, our-api.example.com]
    allow_package_managers: true
  packages:
    apt: [poppler-utils]
    pip: [pandas, sqlalchemy==2.0.30]
```

### apply

### update

Update an Environment: the fields update_mask names change, every other field keeps its stored value.

A conversation using the Environment gets new packages at its sandbox's next start and new network access at its next turn.

resource.metadata.id names the Environment; apply finds one by slug. The slug changes only through rename, and a mask naming a path the Environment does not have is refused with INVALID_ARGUMENT naming the path.

An update is refused with ABORTED carrying a google.rpc.ErrorInfo detail (domain "stigmer.ai"):

- ETAG_MISMATCH — resource.metadata.etag is set and the Environment changed since that etag was read: read it again and make the change again. No metadata. - WRITE_CONFLICT — the Environment kept changing while the update was being saved: try again. No metadata.

### rename

Rename an Environment: change its slug, the name people type.

The Environment keeps its id, so everything that names it keeps working, and every answer names it by the new slug. The old slug keeps leading to the Environment for reading for 30 days, during which no other Environment of the organization can take it and this one can take it back; then it is released. A write that names the old slug is refused with SLUG_RENAMED (see apply). A slug another Environment holds is refused with ALREADY_EXISTS, and one another Environment was recently renamed away from with SLUG_RESERVED (see create).
