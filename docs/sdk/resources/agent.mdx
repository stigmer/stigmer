An Agent defines what an AI assistant knows and can do. It declares the agent's
instructions (system prompt), the plugins it uses (each whole: its skills,
agents, hooks and MCP servers), the MCP servers written in it (`mcp_servers`,
reached over HTTP, added or changed only by the organization's admins), which
Skills it has, the saved agents it may hand work to as subagents (`subagents`,
each pinned to a version when the agent is saved), and the tools it may and may
never use, in Claude Code's names (`tools` and `disallowed_tools`, deny applied
first; a plugin server's tools are `mcp__plugin_<plugin>_<server>__<tool>`, its
own server's `mcp__<server>__<tool>`). Hooks, a listed plugin's or a block
written in the agent's `hooks`, can refuse a tool call, ask a person first, or
let it run. Its `run_config` and `harness` are the run defaults a conversation
on it starts with: the model and thinking a message, routine or channel may replace,
and limits it may lower but never raise.

```yaml
apiVersion: agentic.stigmer.ai/v1
kind: Agent
metadata:
  name: quarterly-variance-reporter
  slug: variance-reporter
spec:
  description: "Turns a customer's ledger into a variance report"
  instructions: "You review a customer's quarterly ledger..."
  plugins:
    - kind: plugin
      slug: ledger
    - kind: plugin
      slug: safety
  skill_refs:
    - kind: skill
      slug: variance-report
  tools: [Read, Grep, Glob, mcp__plugin_ledger_ledger]
  disallowed_tools: [mcp__plugin_ledger_ledger__post_adjustment]
  harness: HARNESS_STIGMER
  run_config:
    model_name: claude-sonnet-4.5
    max_cost_usd: 2
```

### update

Update an agent: the fields update_mask names change, every other field keeps its stored value.

resource.metadata.id names the agent; apply finds one by slug. The slug changes only through rename, and a mask naming a field another door owns, or a path the agent does not have, is refused with INVALID_ARGUMENT naming the path.

An update is refused with ABORTED carrying a google.rpc.ErrorInfo detail (domain "stigmer.ai"):

- ETAG_MISMATCH — resource.metadata.etag is set and the agent changed since that etag was read: read it again and make the change again. No metadata. - WRITE_CONFLICT — the agent kept changing while the update was being saved: try again. No metadata.

### rename

Rename an agent: change its slug, the name people type.

The agent keeps its id, so everything that names it keeps working, and every answer names it by the new slug. The old slug keeps leading to the agent for reading for 30 days, during which no other agent of the organization can take it and this one can take it back; then it is released. A write that names the old slug is refused with SLUG_RENAMED (see apply). A slug another agent holds is refused with ALREADY_EXISTS, and one another agent was recently renamed away from with SLUG_RESERVED (see create).

Its routines, channels, conversations and the agents that hand work to it name it by id; a parent agent's turns call it by its new slug.

### ThinkingMode

ThinkingMode selects the model's extended-reasoning ("thinking") variant for a run's model calls — the second variant dimension alongside ServiceTier (stigmer/stigmer#772).

| Value | Description |
|-------|-------------|
| `THINKING_MODE_DISABLED` | Extended reasoning off: the model's base variant, requested explicitly (thinking=false pinned where the model declares the parameter). |
| `THINKING_MODE_ENABLED` | Extended reasoning on: the model's thinking variant, billed at base per-token rates (reasoning tokens bill as output tokens). |
