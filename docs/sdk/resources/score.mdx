A Score is one grade of a finished run. A run carries a score for each thing
measured, its metric: a person's thumbs up or down on the final answer
(`feedback`), the free checks Stigmer runs when a run completes
(`run-health`), and an AI judge's verdict when the run's agent has AI grading
switched on (`judge`). Anyone who can see the run sees its scores.

Scores are written by people rating a run and by the platform — you never
author one as a manifest. The shape below is what `get` and the list
methods return.

```yaml
apiVersion: agentic.stigmer.ai/v1
kind: Score
metadata:
  name: scr_01j5q3k7m8r2s4tnz2hfp0q0g9
  org: acme
spec:
  run_id: run_01j5q3k7m8r2s4tnz2hfp0q0f5
  session_id: ses_01j5q3k7m8r2s4tnz2hfp0q0e1
  metric: run-health
  source: score_source_check
  evaluator_version: 3f6c0e2a
  passed: false
  criteria:
    - name: no-repeated-calls
      result: criterion_result_passed
    - name: last-action-succeeded
      result: criterion_result_failed
      reason: "ended on a failed action: create_ticket (step 7)"
    - name: structured-output-delivered
      result: criterion_result_not_applicable
status:
  state: score_state_graded
```

### update

Update a score: the fields update_mask names change, every other field keeps its stored value.

Only feedback is editable, only by the person who gave it, and only its value and comment; a check's verdict never changes.

resource.metadata.id names the score; apply finds one by slug. The slug changes only through rename, and a mask naming a field another door owns, or a path the score does not have, is refused with INVALID_ARGUMENT naming the path.

An update is refused with ABORTED carrying a google.rpc.ErrorInfo detail (domain "stigmer.ai"):

- ETAG_MISMATCH — resource.metadata.etag is set and the score changed since that etag was read: read it again and make the change again. No metadata. - WRITE_CONFLICT — the score kept changing while the update was being saved: try again. No metadata.

### ScoreState

ScoreState tells whether a score carries a grade.

| Value | Description |
|-------|-------------|
| `score_state_graded` | The score carries a value. |
| `score_state_not_graded` | The run could not be graded; the reason says why. |
| `score_state_pending` | The run was picked for grading and the grade is not in yet. |

### ScoreSource

ScoreSource names who or what gave a score.

| Value | Description |
|-------|-------------|
| `score_source_check` | A free check the platform runs on every completed run, with no model call. |
| `score_source_human` | A person who can see the run. |
| `score_source_judge` | An AI judge grading the run against Stigmer's standard rubrics, switched on per agent by its evaluator. |
| `score_source_eval` | A plugin's own eval: one try of one evals/ case, graded by the case's checks. |

### CriterionResult

CriterionResult is one criterion's outcome.

| Value | Description |
|-------|-------------|
| `criterion_result_passed` | The run met the criterion. |
| `criterion_result_failed` | The run did not meet the criterion; the reason says how. |
| `criterion_result_not_applicable` | The criterion does not apply to this run. |
