An AgentExecution represents a single turn in a conversation: one user message
and the agent's response. It captures everything that happened during that turn
-- the messages exchanged, tool calls made, sub-agent delegations, approval
decisions, and artifacts produced.

```yaml
apiVersion: agentic.stigmer.ai/v1
kind: AgentExecution
metadata:
  name: ask-about-deployment
spec:
  session_id: "ses_01HGXXX..."
  agent_id: "agt_01HGYYY..."
  message: "What is the status of my latest deployment?"
  execution_config:
    model_name: "claude-sonnet-4-20250514"
```

### ExecutionControlSignal

ExecutionControlSignal is a platform-to-runner directive returned by the updateStatus RPC.

| Value | Description |
|-------|-------------|
| `EXECUTION_CONTROL_SIGNAL_STOP` | Execution must stop gracefully. |
| `EXECUTION_CONTROL_SIGNAL_WARNING` | Informational warning (e.g. low credit balance). |

### ApprovalAction

ApprovalAction represents the user's decision on an approval request.

| Value | Description |
|-------|-------------|
| `APPROVAL_ACTION_APPROVE` | Execute the tool normally. |
| `APPROVAL_ACTION_SKIP` | Skip tool execution, continue without it. |
| `APPROVAL_ACTION_REJECT` | Reject tool execution, fail the entire execution. |

### ExecutionPhase

ExecutionPhase defines the lifecycle phase of an agent execution.

| Value | Description |
|-------|-------------|
| `EXECUTION_PENDING` | Execution is queued and waiting for a worker to start processing. |
| `EXECUTION_IN_PROGRESS` | Execution is actively running — the agent is processing and producing output. |
| `EXECUTION_COMPLETED` | Execution finished successfully and the agent produced a final response. |
| `EXECUTION_FAILED` | Execution encountered an unexpected error and could not finish. |
| `EXECUTION_CANCELLED` | Execution was gracefully stopped by the user before it finished. |
| `EXECUTION_TERMINATED` | Execution was stopped by the platform. |
| `EXECUTION_WAITING_FOR_APPROVAL` | Blocked on tool approval (HITL Phase 1). |
| `EXECUTION_PAUSED` | Execution was paused by user and can be resumed. |

### MessageType

MessageType defines the type of message in the conversation.

| Value | Description |
|-------|-------------|
| `MESSAGE_HUMAN` | A message sent by the user to the agent. |
| `MESSAGE_AI` | A response generated by the AI agent. |
| `MESSAGE_TOOL` | The result returned by a tool after execution. |
| `MESSAGE_SYSTEM` | A system-generated message injected by the platform (e.g., budget warnings, summarization notices). |
| `MESSAGE_THINKING` | Reasoning/thinking content from the model. |

### ExecutionArtifactKind

ExecutionArtifactKind defines the type of artifact published by an agent.

| Value | Description |
|-------|-------------|
| `EXECUTION_ARTIFACT_KIND_FILE` | A single file published by the agent. |
| `EXECUTION_ARTIFACT_KIND_DIRECTORY` | A directory published by the agent, archived as a ZIP file for download. |

### SubAgentStatus

SubAgentStatus defines the status of a sub-agent execution.

| Value | Description |
|-------|-------------|
| `SUB_AGENT_PENDING` | Sub-agent invocation is queued and waiting to start. |
| `SUB_AGENT_IN_PROGRESS` | Sub-agent is actively executing its delegated task. |
| `SUB_AGENT_COMPLETED` | Sub-agent finished its task successfully and returned a result. |
| `SUB_AGENT_FAILED` | Sub-agent encountered an error and could not complete its task. |
| `SUB_AGENT_CANCELLED` | Parent execution was cancelled while this sub-agent was active. |

### SummarizationSource

SummarizationSource identifies what triggered a context summarization event.

| Value | Description |
|-------|-------------|
| `graph_start` | Summarization triggered at the start of processing, when resuming a conversation that already exceeds the token threshold. |
| `mid_execution` | Summarization triggered mid-execution, when accumulated tool responses push context past the token threshold. |

### TodoStatus

TodoStatus defines the status of a todo item.

| Value | Description |
|-------|-------------|
| `TODO_PENDING` | Task has not been started yet. |
| `TODO_IN_PROGRESS` | Task is currently being worked on by the agent. |
| `TODO_COMPLETED` | Task was completed successfully. |
| `TODO_CANCELLED` | Task was cancelled and is no longer needed. |

### ToolCallStatus

ToolCallStatus defines the status of a tool call.

| Value | Description |
|-------|-------------|
| `TOOL_CALL_PENDING` | Tool call is queued and waiting to execute. |
| `TOOL_CALL_RUNNING` | Tool is currently executing. |
| `TOOL_CALL_COMPLETED` | Tool executed successfully and returned a result. |
| `TOOL_CALL_FAILED` | Tool execution failed with an error. |
| `TOOL_CALL_WAITING_APPROVAL` | Blocked on user approval (HITL Phase 1). |
| `TOOL_CALL_SKIPPED` | User skipped this tool (HITL Phase 1). |

### ToolCallStreamingSource

ToolCallStreamingSource identifies what is currently being streamed on a tool call.

| Value | Description |
|-------|-------------|
| `TOOL_CALL_STREAMING_SOURCE_INPUT` | The LLM is generating the tool's arguments. |
| `TOOL_CALL_STREAMING_SOURCE_OUTPUT` | The tool is executing and producing output progressively. |

### WorkspaceWriteBackPhase

WorkspaceWriteBackPhase tracks the progress of a single workspace write-back through its lifecycle steps.

| Value | Description |
|-------|-------------|
| `WORKSPACE_WRITE_BACK_COMMITTED` | Changes were committed to a new branch in the sandbox. |
| `WORKSPACE_WRITE_BACK_PUSHED` | The branch was pushed to the remote repository. |
| `WORKSPACE_WRITE_BACK_PR_CREATED` | A pull request was created on the remote repository. |
| `WORKSPACE_WRITE_BACK_FAILED` | The write-back failed at some step. |
