### ValidationState

ValidationState represents the current state of serverless workflow validation.

| Value | Description |
|-------|-------------|
| `PENDING` | Validation has been triggered but not yet completed This is the initial state when a workflow is created. |
| `VALID` | Validation completed successfully - workflow structure is valid The generated YAML is stored and can be used for execution. |
| `INVALID` | Validation completed but found errors - workflow structure is invalid The workflow cannot be executed until errors are fixed Errors are listed in the 'errors' field. |
| `FAILED` | Validation process itself failed (system error, not user error) Examples: Temporal workflow crashed, activity timeout, etc. User should retry validation or contact support. |
