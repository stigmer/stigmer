Search for resources matching a text query.

The type can be specified using any alias:

- agents, agent, agt
- workflows, workflow, wf

The search looks for matches in resource names, descriptions, and tags. Results
are sorted by relevance score (best matches first).

By default, searches all resources you have access to, including public platform
resources. Use --exclude-public to see only your own resources.

Output formats:

- table: Human-readable table (default)
- yaml: Full results as YAML
- json: Full results as JSON

## Usage

```bash
stigmer search <type> <query> [flags]
```

## Flags

| Flag               | Type     | Default | Description                       |
| ------------------ | -------- | ------- | --------------------------------- |
| `--exclude-public` | `bool`   |         | exclude public/platform resources |
| `--output`, `-o`   | `string` | `table` | output format: table, yaml, json  |
| `--page`           | `int32`  | `1`     | page number (1-indexed)           |
| `--page-size`      | `int32`  | `20`    | results per page (max 100)        |

## Global Flags

| Flag            | Type     | Default | Description                                               |
| --------------- | -------- | ------- | --------------------------------------------------------- |
| `--api-key`     | `string` |         | API key for cloud authentication (overrides stored token) |
| `--debug`, `-d` | `bool`   |         | enable debug mode with detailed logs                      |
| `--org`         | `string` |         | organization slug (overrides context)                     |

## Examples

```bash
# Search for agents related to code review
stigmer search agents "code review"

# Search for workflows related to deployment
stigmer search workflows "deploy"

# Search within a specific organization
stigmer search agents "kubernetes" --org acme-corp

# Exclude public/platform resources
stigmer search agents "api" --exclude-public

# Output as JSON for scripting
stigmer search workflows "data" --output json

# Paginate results
stigmer search agents "test" --page 2 --page-size 50
```
