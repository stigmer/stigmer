View token usage and cost reports at different levels of detail.

`stigmer usage` shows how many tokens your agents consumed and the associated
costs. Reports are available at three levels: per-session, per-agent, and
per-organization. Costs are calculated using the model pricing at the time of
each execution.

## Usage

```bash
stigmer usage
```

### Common patterns

```bash
# View usage for a specific session
stigmer usage session ses-01abc123

# View agent usage for a date range
stigmer usage agent agt-01abc123 --from 2026-03-01 --to 2026-03-31

# View organization-wide usage
stigmer usage org --from 2026-03-01 --to 2026-03-31
```

### Report levels

| Subcommand      | Scope                     | Date range                            |
| --------------- | ------------------------- | ------------------------------------- |
| `usage session` | Single session            | Not applicable (shows all executions) |
| `usage agent`   | All sessions for an agent | Optional `--from` / `--to`            |
| `usage org`     | Entire organization       | Required `--from` / `--to`            |

### What the report includes

- **Summary**: Total tokens (input + output), total cost
- **Per-model breakdown**: Token counts and costs by LLM model
- **Per-execution detail** (session level): Each execution with its model,
  tokens, and cost
- **Cache statistics**: Cached vs uncached token usage

## Subcommands

### stigmer usage agent

View aggregated token usage, cost, and model breakdown for an agent across all
its sessions within an optional date range.

Shows summary statistics, per-model cost breakdown, and per-session detail.

```bash
stigmer usage agent <agent-id> [flags]
```

| Flag             | Type     | Default | Description                            |
| ---------------- | -------- | ------- | -------------------------------------- |
| `--from`         | `string` |         | start date (ISO 8601, e.g. 2026-03-01) |
| `--output`, `-o` | `string` | `table` | output format: table, json, yaml       |
| `--to`           | `string` |         | end date (ISO 8601, e.g. 2026-03-13)   |

```bash
# View all-time usage for an agent
stigmer usage agent my-coding-assistant

# View usage within a date range
stigmer usage agent my-coding-assistant --from 2026-03-01 --to 2026-03-13

# Output as JSON
stigmer usage agent my-coding-assistant --output json
```

### stigmer usage org

View aggregated token usage, cost, and model breakdown for an entire
organization within a date range.

Shows org-wide summary, per-model cost breakdown, top agents by cost, and a
daily cost trend.

The --from and --to flags are required. Organization is resolved from the --org
flag or the current CLI context.

```bash
stigmer usage org [flags]
```

| Flag             | Type     | Default | Description                                      |
| ---------------- | -------- | ------- | ------------------------------------------------ |
| `--from`         | `string` |         | start date (ISO 8601, e.g. 2026-03-01, required) |
| `--output`, `-o` | `string` | `table` | output format: table, json, yaml                 |
| `--to`           | `string` |         | end date (ISO 8601, e.g. 2026-03-31, required)   |

```bash
# View org usage for March 2026
stigmer usage org --from 2026-03-01 --to 2026-03-31

# Specify organization explicitly
stigmer usage org --from 2026-03-01 --to 2026-03-31 --org acme-corp

# Output as JSON
stigmer usage org --from 2026-03-01 --to 2026-03-31 --output json
```

### stigmer usage session

View token usage, cost, and model breakdown for all executions in a session.

Shows per-model cost breakdown, per-execution detail, cache effectiveness, and
summarization costs.

```bash
stigmer usage session <session-id> [flags]
```

| Flag             | Type     | Default | Description                      |
| ---------------- | -------- | ------- | -------------------------------- |
| `--output`, `-o` | `string` | `table` | output format: table, json, yaml |

```bash
# View session usage
stigmer usage session ses_abc123

# Output as JSON for scripting
stigmer usage session ses_abc123 --output json
```
