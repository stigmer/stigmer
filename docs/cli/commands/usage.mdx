View token usage reports at different levels of detail.

`stigmer usage` shows how many tokens your agents used and who served them.
Reports are available at three levels: per-session, per-agent, and
per-organization. Usage is counted in tokens; Stigmer never prices it. Your
model provider bills the calls made on your own keys.

## Usage

```bash
stigmer usage
```

### Common patterns

```bash
# View usage for a specific session
stigmer usage session ses-01abc123

# View agent usage for a date range
stigmer usage agent agt-01abc123 --from 2026-03-01 --to 2026-03-31

# View organization-wide usage
stigmer usage org --from 2026-03-01 --to 2026-03-31
```

### Report levels

| Subcommand      | Scope                     | Date range                      |
| --------------- | ------------------------- | ------------------------------- |
| `usage session` | Single session            | Not applicable (shows all runs) |
| `usage agent`   | All sessions for an agent | Optional `--from` / `--to`      |
| `usage org`     | Entire organization       | Required `--from` / `--to`      |

A date is a UTC calendar day (`2026-03-01`) or an RFC 3339 instant
(`2026-03-01T09:00:00Z`). Both bounds are inclusive: `--to 2026-03-31` counts
every run created on March 31. A run counts in the range it was created in.

### What the report includes

- **Summary**: Total tokens (input, output and cached), and the average per run
- **Served by**: Whose provider credential served the tokens: your own keys, or
  Stigmer's free model where one is offered, split by share when both appear
- **Per-model breakdown**: Tokens by LLM model and each model's share
- **Per-run detail** (session level): Each run with its model, tokens, and
  status
- **Organization detail**: The agents with the most tokens, the split by
  harness, and tokens per day
- **Cache statistics**: The share of input served from the cache

Numbers marked **estimated** (or `~` beside a run) were counted from the run's
own report rather than metered call by call. This is how every run is counted on
a self-hosted deployment.
