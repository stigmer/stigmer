Manage authentication with Stigmer Cloud.

`stigmer auth` handles browser-based PKCE OAuth authentication. Use it to log
in, log out, and check your current identity.

## Usage

```bash
stigmer auth
```

### Common patterns

```bash
# Log in to Stigmer Cloud
stigmer auth login

# Check who you're logged in as
stigmer auth whoami

# Log out
stigmer auth logout
```

### How authentication works

`stigmer auth login` opens your default browser to the Stigmer login page. After
you authenticate, the CLI receives an access token and saves it to
`~/.stigmer/config.yaml`. The backend is automatically set to cloud mode.

For programmatic access (CI/CD, scripts), use [API keys](./apikey) instead of
browser-based auth.
