Compare local YAML resource files with their remote server state.

Auto-detects the resource kind from the YAML 'kind' field. Shows a unified diff
of what would change if you run 'stigmer apply -f'.

Supports Agent, Workflow, and McpServer resources.

## Usage

```bash
stigmer diff [flags]
```

## Options

| Flag           | Type     | Default | Description                               |
| -------------- | -------- | ------- | ----------------------------------------- |
| `--context`    | `int`    | `3`     | number of context lines in diff output    |
| `--file`, `-f` | `string` |         | path to YAML file or directory (required) |

## Global Flags

| Flag            | Type     | Default | Description                                                     |
| --------------- | -------- | ------- | --------------------------------------------------------------- |
| `--api-key`     | `string` |         | API key for cloud authentication (overrides stored token)       |
| `--debug`, `-d` | `bool`   |         | enable debug mode with detailed logs                            |
| `--org`         | `string` |         | organization slug (overrides context)                           |
| `--standalone`  | `bool`   |         | ignore config file; all config must come from flags or env vars |

## Examples

```bash
# Diff a workflow
stigmer diff -f workflow.yaml

# Diff an agent
stigmer diff -f agent.yaml

# Diff all YAML files in a directory
stigmer diff -f ./manifests/

# Show more context lines
stigmer diff -f workflow.yaml --context 5
```
