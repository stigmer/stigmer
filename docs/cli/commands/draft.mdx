Create resource configurations with AI assistance.

`stigmer draft` invokes specialized system agents to help you create
well-structured configuration files. Tell the agent what you want to build,
optionally attach reference files for context, and the agent generates a
complete resource definition.

## Usage

```bash
stigmer draft
```

### Common patterns

```bash
# Draft a new skill
stigmer draft skill -m "Create a skill for validating Kubernetes manifests"

# Draft an agent
stigmer draft agent -m "Create an agent that reviews pull requests"

# Draft an MCP server
stigmer draft mcp-server -m "Create a server that connects to Jira"

# Provide context files
stigmer draft skill --attach ./example-skill.md -m "Create something similar for Terraform"
```

### How drafting works

Each draft command:

1. Invokes a specialized system agent (skill-creator, agent-creator, or
   mcp-server-creator)
2. Passes your message and any attached files as context
3. Streams the agent's work in real time
4. Downloads the generated artifact to the output directory

The generated files follow Stigmer's best practices for the resource type.

### Supported resource types

| Subcommand         | Creates                     | System agent       |
| ------------------ | --------------------------- | ------------------ |
| `draft skill`      | `SKILL.md` files            | skill-creator      |
| `draft agent`      | Agent YAML definitions      | agent-creator      |
| `draft mcp-server` | MCP Server YAML definitions | mcp-server-creator |

### Providing context

Attach files to help the agent understand what you want:

```bash
# Use an existing skill as a reference
stigmer draft skill --attach ./example-skill.md -m "Create a similar skill for Terraform"

# Attach API specs for an MCP server
stigmer draft mcp-server --attach ./openapi.yaml -m "Create a server for this API"
```

### Output directory

By default, artifacts are saved to the current directory (or the workspace root
when a workspace is active). Use `--output` to specify a different path:

```bash
stigmer draft agent -m "Code reviewer" --output ./agents/
```

```bash

```

The agent examines your project structure and creates a tailored agent
definition.

### Non-interactive draft for CI

```bash
stigmer draft agent \
  -m "Create a test runner agent" \
  --auto-approve \
  --output ./generated/ \
  --json
```
