Apply resources to the Stigmer backend.

### Modes

File mode (with -f): Apply individual YAML resource files Declarative mode:
Detect stigmer.yaml, scan for resources, apply with project tracking SDK mode:
Run SDK entry point for programmatic resource synthesis

Without -f, the CLI looks for stigmer.yaml in the current directory (or --config
path). If entry_point is set in stigmer.yaml, SDK mode is used. Otherwise,
declarative mode scans the directory for YAML resource files and applies each
individually.

### File Mode Supports

- Agent, Workflow, McpServer resources
- Directory paths (applies all .yaml/.yml files)
- Multi-document YAML (--- separated)

### Declarative Mode Supports

- All file mode resource kinds in a project directory
- Automatic resource discovery and membership tracking
- Orphan pruning with --prune flag

## Usage

```bash
stigmer apply [flags]
```

## Flags

| Flag            | Type     | Default | Description                              |
| --------------- | -------- | ------- | ---------------------------------------- |
| `--config`      | `string` |         | path to project directory (project mode) |
| `--dry-run`     | `bool`   |         | validate without applying                |
| `--file`, `-f`  | `string` |         | path to YAML file or directory           |
| `--json`        | `bool`   |         | output result as JSON                    |
| `--prune`       | `bool`   | `true`  | delete orphaned resources (project mode) |
| `--quiet`, `-q` | `bool`   |         | suppress output, print status line only  |

## Global Flags

| Flag            | Type     | Default | Description                                               |
| --------------- | -------- | ------- | --------------------------------------------------------- |
| `--api-key`     | `string` |         | API key for cloud authentication (overrides stored token) |
| `--debug`, `-d` | `bool`   |         | enable debug mode with detailed logs                      |
| `--org`         | `string` |         | organization slug (overrides context)                     |

## Examples

```bash
# File mode - apply from YAML file
stigmer apply -f agent.yaml
stigmer apply -f workflow.yaml --dry-run
stigmer apply -f ./manifests/  # directory

# Declarative mode - deploy from stigmer.yaml project directory
stigmer apply                       # scans cwd for resources
stigmer apply --config /path/to/project/
stigmer apply --dry-run
stigmer apply --prune=false         # skip orphan deletion
```
