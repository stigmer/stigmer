Validate resource YAML files without applying them.

`stigmer validate` checks that your resource files contain valid YAML with a
correct schema. It supports agents, workflows, MCP servers, and projects. The
resource type is auto-detected from the `kind` field in the YAML.

Use this command before `stigmer apply` to catch errors early — especially
useful in CI pipelines.

## Usage

```bash
stigmer validate [flags]
```

### Common patterns

```bash
# Validate a single file
stigmer validate -f agent.yaml

# Validate all YAML files in a directory
stigmer validate -f ./manifests/

# Validate a project configuration
stigmer validate -f stigmer.yaml
```

## Options

| Flag           | Type     | Default | Description                      |
| -------------- | -------- | ------- | -------------------------------- |
| `--file`, `-f` | `string` |         | path to a YAML file or directory |
| `--json`       | `bool`   |         | emit the result as JSON          |
| `--quiet`      | `bool`   |         | print only the status line       |

### What gets validated

- YAML syntax
- Required fields (apiVersion, kind, metadata, spec)
- Resource-specific schema rules per kind
- Multi-document YAML (`---` separated)

### Supported inputs

| Input                        | Behavior                                 |
| ---------------------------- | ---------------------------------------- |
| Single `.yaml` / `.yml` file | Validate one resource definition         |
| Directory path               | Validate all YAML files in the directory |
| Multi-document YAML          | Validate each document separately        |

## Examples

### Validate before deploying

```bash
stigmer validate -f agent.yaml && stigmer apply -f agent.yaml
```

Run validation first, then apply only if it passes.

### Validate a project directory

```bash
stigmer validate -f ./manifests/
```

Checks every YAML file in the directory.

### CI pipeline validation

```bash
stigmer validate -f ./manifests/ || exit 1
```

Exit with a non-zero code if any file fails validation.
