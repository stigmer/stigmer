Manage Stigmer CLI configuration.

`stigmer config` reads and writes settings stored in `~/.stigmer/config.yaml`.
This includes backend selection (local vs cloud), organization context, LLM
provider settings, and execution options.

Configuration priority (highest to lowest):

1. CLI flags
2. Environment variables
3. Config file

## Usage

```bash
stigmer config
```

### Common patterns

```bash
# List all configuration values
stigmer config list

# Get a specific value
stigmer config get llm.provider

# Set a value
stigmer config set llm.provider anthropic

# Show the config file path
stigmer config path

# Switch backend
stigmer config backend set cloud

# Set active organization
stigmer config context set --org my-org
```

### Available configuration keys

| Key                       | Purpose                                           |
| ------------------------- | ------------------------------------------------- |
| `execution.mode`          | Agent execution mode (`local`, `sandbox`, `auto`) |
| `execution.sandbox_image` | Docker image for sandbox execution                |
| `llm.provider`            | LLM provider (`anthropic`, `openai`, `ollama`)    |
| `llm.model`               | Default model name                                |
| `llm.base_url`            | Custom API endpoint URL                           |
