## Global Flags

These flags are available on every command. `--org`, `--debug` and
`--standalone` may be written before or after the command; `--api-key` goes
before it.

| Flag            | Type     | Default | Description                                            |
| --------------- | -------- | ------- | ------------------------------------------------------ |
| `--api-key`     | `string` |         | API key for authentication (before the command)        |
| `--debug`, `-d` | `bool`   |         | enable debug output                                    |
| `--org`         | `string` |         | organization, on servers that hold several             |
| `--standalone`  | `bool`   |         | ignore the config file; use flags and environment only |
