Delete a resource from the Stigmer backend.

`stigmer delete` permanently removes a resource by type and reference. For
running executions, delete gracefully cancels the agent. This operation cannot
be undone.

## Usage

```bash
stigmer delete <type> <reference> [flags]
```

### Common patterns

```bash
# Delete an agent by slug
stigmer delete agent my-agent

# Delete a workflow by ID
stigmer delete workflow wfl_abc123

# Cancel a running execution
stigmer delete execution aex_01abc123

# Skip the confirmation prompt
stigmer delete agent my-agent --force
```

## Options

| Flag            | Type   | Default | Description                  |
| --------------- | ------ | ------- | ---------------------------- |
| `--force`, `-f` | `bool` |         | skip the confirmation prompt |
| `--json`        | `bool` |         | emit the result as JSON      |
| `--quiet`       | `bool` |         | print only the status line   |

### Supported resource types

| Type        | Aliases                              | Behavior                                              |
| ----------- | ------------------------------------ | ----------------------------------------------------- |
| Agent       | `agent`, `agt`, `agents`             | Permanently deletes the agent definition              |
| Agent Share | `agent-share`, `agentshare`, `ash`   | Tears down the share; the hosted link stops resolving |
| Workflow    | `workflow`, `wf`, `workflows`        | Permanently deletes the workflow                      |
| MCP Server  | `mcpserver`, `mcp`, `mcp-server`     | Permanently deletes the MCP server                    |
| Skill       | `skill`, `skills`                    | Permanently deletes the skill                         |
| Environment | `environment`, `env`, `environments` | Permanently deletes the environment and its values    |
| Project     | `project`, `proj`, `projects`        | Permanently deletes the project                       |
| Execution   | `execution`, `exec`                  | Gracefully cancels a running execution                |

### Confirmation

By default, `stigmer delete` prompts for confirmation before proceeding. Use
`--force` to skip the prompt in scripts and CI pipelines.

```bash
# Interactive confirmation
stigmer delete agent my-agent

# Skip confirmation (use in scripts)
stigmer delete agent my-agent --force
```

## Examples

### Delete an agent

```bash
stigmer delete agent my-agent
```

You are prompted to confirm. The agent and all its versions are permanently
removed.

### Cancel a running execution

```bash
stigmer delete execution aex_01abc123
```

The running agent receives a graceful cancellation signal.

### Scripted deletion with JSON output

```bash
stigmer delete agent my-agent --force --json
```
