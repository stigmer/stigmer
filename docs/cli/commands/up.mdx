Start a Stigmer agent runner connected to a backend.

By default, connects to the configured backend (cloud or local). Use --endpoint
and --token to connect to any backend without requiring a config file (useful in
CI/CD, containers, sandboxes).

Use 'stigmer up server' to start the full local development stack (Temporal,
stigmer-server, and an embedded runner).

## Usage

```bash
stigmer up [flags]
```

## Options

| Flag            | Type     | Default | Description                                     |
| --------------- | -------- | ------- | ----------------------------------------------- |
| `--endpoint`    | `string` |         | Backend gRPC endpoint (overrides config)        |
| `--json`        | `bool`   |         | output result as JSON                           |
| `--name`        | `string` |         | Runner name (default: hostname)                 |
| `--quiet`, `-q` | `bool`   |         | suppress output, print status line only         |
| `--token`       | `string` |         | API key / auth token (overrides config and env) |

## Global Flags

| Flag            | Type     | Default | Description                                               |
| --------------- | -------- | ------- | --------------------------------------------------------- |
| `--api-key`     | `string` |         | API key for cloud authentication (overrides stored token) |
| `--debug`, `-d` | `bool`   |         | enable debug mode with detailed logs                      |
| `--org`         | `string` |         | organization slug (overrides context)                     |

## Examples

```bash
# Start a runner (uses configured backend)
stigmer up

# Start a runner with explicit credentials
stigmer up --endpoint api.stigmer.ai:443 --token sk-...

# Start a runner with a custom name
stigmer up --name my-macbook

# Start the full local development stack
stigmer up server
```

### stigmer up server

Start the complete local Stigmer stack: Temporal, stigmer-server, and an
embedded agent runner. This is the quickstart command for local development — no
cloud account needed.

```bash
stigmer up server [flags]
```

| Flag                  | Type     | Default | Description                                                    |
| --------------------- | -------- | ------- | -------------------------------------------------------------- |
| `--execution-mode`    | `string` |         | Agent execution mode: local, sandbox, or auto (default: local) |
| `--json`              | `bool`   |         | output result as JSON                                          |
| `--no-web`            | `bool`   |         | Disable the embedded web console                               |
| `--open`              | `bool`   |         | Open the web console in your browser after startup             |
| `--quiet`, `-q`       | `bool`   |         | suppress output, print status line only                        |
| `--sandbox-auto-pull` | `bool`   | `true`  | Auto-pull sandbox image if missing                             |
| `--sandbox-cleanup`   | `bool`   | `true`  | Cleanup sandbox containers after execution                     |
| `--sandbox-image`     | `string` |         | Docker image for sandbox mode                                  |
| `--sandbox-ttl`       | `int`    | `3600`  | Sandbox container reuse TTL in seconds                         |

```bash
# Start the full local stack
stigmer up server

# Start with the web console open
stigmer up server --open

# Start in sandbox execution mode
stigmer up server --execution-mode sandbox

# Start without the web console
stigmer up server --no-web
```
