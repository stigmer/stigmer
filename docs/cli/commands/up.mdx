Start the complete local Stigmer stack: Temporal, stigmer-server, and an
embedded execution worker. This is the quickstart command for local development
— no cloud account needed.

Use 'stigmer up server' as an explicit alias.

## Usage

```bash
stigmer up [flags]
```

## Options

| Flag                  | Type     | Default | Description                                                    |
| --------------------- | -------- | ------- | -------------------------------------------------------------- |
| `--activity-routing`  | `string` |         | Activity routing mode: global or session (default: global)     |
| `--execution-mode`    | `string` |         | Agent execution mode: local, sandbox, or auto (default: local) |
| `--json`              | `bool`   |         | output result as JSON                                          |
| `--no-web`            | `bool`   |         | Disable the embedded web console                               |
| `--open`              | `bool`   |         | Open the web console in your browser after startup             |
| `--quiet`, `-q`       | `bool`   |         | suppress output, print status line only                        |
| `--sandbox-auto-pull` | `bool`   | `true`  | Auto-pull sandbox image if missing                             |
| `--sandbox-cleanup`   | `bool`   | `true`  | Cleanup sandbox containers after execution                     |
| `--sandbox-image`     | `string` |         | Docker image for sandbox mode                                  |
| `--sandbox-ttl`       | `int`    | `3600`  | Sandbox container reuse TTL in seconds                         |

## Examples

```bash
# Start the full local stack
stigmer up

# Start with the web console open
stigmer up --open

# Start in sandbox execution mode
stigmer up --execution-mode sandbox

# Start without the web console
stigmer up --no-web
```

## Subcommands

### stigmer up server

Start only the control plane: Temporal and stigmer-server. No runner processes
are started. Use this when you manage your own runners (desktop app with
embedded runner, customer code, or cloud sandboxes).

Use 'stigmer up' (without 'server') for the full stack including runners.

```bash
stigmer up server [flags]
```

| Flag                 | Type     | Default | Description                                                |
| -------------------- | -------- | ------- | ---------------------------------------------------------- |
| `--activity-routing` | `string` |         | Activity routing mode: global or session (default: global) |
| `--json`             | `bool`   |         | output result as JSON                                      |
| `--no-web`           | `bool`   |         | Disable the embedded web console                           |
| `--open`             | `bool`   |         | Open the web console in your browser after startup         |
| `--quiet`, `-q`      | `bool`   |         | suppress output, print status line only                    |

```bash
# Start control plane only
stigmer up server

# Start with the web console open
stigmer up server --open

# Start without the web console
stigmer up server --no-web
```
