List all resources of a given type.

`stigmer list` queries the Stigmer backend and displays a table of resources
matching the specified type. Use `stigmer list types` to see all available
resource types.

## Usage

```bash
stigmer list <type> [flags]
```

### Common patterns

```bash
# List all agents
stigmer list agents

# List available resource types
stigmer list types

# List with a result limit
stigmer list agents --limit 10

# Output as JSON for scripting
stigmer list workflows --output json
```

## Options

| Flag             | Type     | Default | Description                                                           |
| ---------------- | -------- | ------- | --------------------------------------------------------------------- |
| `--json`         | `bool`   |         | shorthand for --output json                                           |
| `--limit`        | `string` | `50`    | maximum number of results                                             |
| `--output`, `-o` | `string` |         | output format: table, json, or yaml                                   |
| `--type`         | `string` |         | execution type filter: agent or workflow (only for 'list executions') |
| `--verb`         | `string` |         | filter to types supporting this verb (only for 'list types')          |

### Listing resource types

Use `stigmer list types` to discover which resource types are available. Filter
by verb to find types that support a specific operation:

```bash
# List all resource types
stigmer list types

# List types that support the "run" verb
stigmer list types --verb run
```
