List all resources of a given type.

`stigmer list` queries the Stigmer backend and displays a table of resources
matching the specified type. Use `stigmer list types` to see all available
resource types.

## Usage

```bash
stigmer list <type> [flags]
```

### Common patterns

```bash
# List all agents
stigmer list agents

# List available resource types
stigmer list types

# List with a result limit
stigmer list agents --limit 10

# List the agents labelled team=support
stigmer list agents --label team=support

# Output as JSON for scripting
stigmer list skills --output json
```

## Options

| Flag             | Type     | Default | Description                                                                 |
| ---------------- | -------- | ------- | --------------------------------------------------------------------------- |
| `--json`         | `bool`   |         | shorthand for --output json                                                 |
| `--label`, `-l`  | `string` |         | keep only resources carrying this label (repeatable; every pair must match) |
| `--limit`        | `string` | `50`    | maximum number of results (0 reads every page)                              |
| `--output`, `-o` | `string` |         | output format: table, json, or yaml                                         |
| `--verb`         | `string` |         | filter to types supporting this verb (only for 'list types')                |

### Listing resource types

Use `stigmer list types` to discover which resource types are available. Filter
by verb to find types that support a specific operation:

```bash
# List all resource types
stigmer list types

# List types that support the "run" verb
stigmer list types --verb run
```

## Examples

### List all agents in the current organization

```bash
stigmer list agents
```

### List skills with JSON output

```bash
stigmer list skills --output json | jq '.[].metadata.name'
```

### Read more than the default 50

The CLI reads the server's pages for you, up to `--limit`; `--limit 0` reads
every page:

```bash
stigmer list agents --limit 200
stigmer list agents --limit 0
```

### Filter by label

`--label key=value` keeps only the resources carrying that label. Repeat it to
require several; every pair must match exactly. A selective filter can take more
than one page of reading to fill a page, and the CLI follows the pages for you:

```bash
stigmer list agents --label team=support
stigmer list routines -l team=support -l tier=gold
```
