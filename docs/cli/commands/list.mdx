List all resources of a given type.

`stigmer list` queries the Stigmer backend and displays a table of resources
matching the specified type. Use `stigmer list types` to see all available
resource types.

## Usage

```bash
stigmer list <type> [flags]
```

### Common patterns

```bash
# List all agents
stigmer list agents

# List available resource types
stigmer list types

# List with a result limit
stigmer list agents --limit 10

# Output as JSON for scripting
stigmer list workflows --output json
```

## Options

| Flag             | Type     | Default | Description                                                             |
| ---------------- | -------- | ------- | ----------------------------------------------------------------------- |
| `--limit`        | `int32`  | `50`    | maximum number of results                                               |
| `--output`, `-o` | `string` | `table` | output format: table, yaml, json                                        |
| `--type`         | `string` |         | filter executions by type: agent, workflow (only for 'list executions') |
| `--verb`         | `string` |         | filter to types supporting this verb (only for 'list types')            |

### Supported resource types

| Type           | Aliases                                |
| -------------- | -------------------------------------- |
| Resource types | `types`, `type`                        |
| Agent          | `agents`, `agent`, `agt`               |
| Workflow       | `workflows`, `workflow`, `wf`          |
| MCP Server     | `mcpservers`, `mcpserver`, `mcp`       |
| Skill          | `skills`, `skill`                      |
| Organization   | `organizations`, `organization`, `org` |
| Project        | `projects`, `project`, `proj`          |
| Execution      | `executions`, `execution`, `exec`      |
| Session        | `sessions`, `session`, `ses`           |

Both singular and plural forms are accepted.

### Listing resource types

Use `stigmer list types` to discover which resource types are available. Filter
by verb to find types that support a specific operation:

```bash
# List all resource types
stigmer list types

# List types that support the "run" verb
stigmer list types --verb run
```

## Examples

### List all agents in the current organization

```bash
stigmer list agents
```

### List workflows with JSON output

```bash
stigmer list workflows --output json | jq '.[].metadata.name'
```

### Paginate through many resources

```bash
stigmer list agents --limit 100
```
