Resume an existing session by ID, or browse recent sessions interactively.

`stigmer resume` reconnects you to a previous conversation. If the latest
execution is still running, you re-attach to the live stream. If all executions
have completed, you see the full conversation history and can send follow-up
messages.

## Usage

```bash
stigmer resume [reference] [flags]
```

### Common patterns

```bash
# Browse recent sessions interactively
stigmer resume

# Resume by session ID
stigmer resume ses-01abc123xyz456

# Search sessions by subject
stigmer resume "deploy staging"
```

## Options

| Flag              | Type     | Default | Description                                                         |
| ----------------- | -------- | ------- | ------------------------------------------------------------------- |
| `--json`          | `bool`   |         | stream events as newline-delimited JSON                             |
| `--mode`          | `string` |         | follow-up interaction mode: "agent" (default) or "plan" (read-only) |
| `--verbose`, `-v` | `bool`   |         | show all execution events                                           |

### How resuming works

| Scenario                    | Behavior                                          |
| --------------------------- | ------------------------------------------------- |
| Latest execution is running | Re-attach to the live output stream               |
| All executions complete     | Display conversation history, accept new messages |
| Search text provided        | Find sessions by subject, show interactive picker |

Session IDs must be provided in full (e.g., `ses-01abc123xyz456`). Partial IDs
are not accepted.

## Examples

### Browse and select a session
