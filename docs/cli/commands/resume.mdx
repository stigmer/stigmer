Resume an existing session by ID, or browse recent sessions interactively.

### Usage Forms

stigmer resume Browse and select a session interactively stigmer resume
<session-id> Resume a session by its full ID stigmer resume <text> Search
sessions and select interactively

A session ID must be provided in full (e.g., ses-01abc123xyz456). Partial
session IDs are not accepted.

When text is provided instead of a session ID, sessions are searched by subject
and the matching results are shown in an interactive picker.

If the latest execution in the session is still running, you re-attach to the
live stream. If all executions have completed, you see the full conversation
history and can send follow-up messages.

## Usage

```bash
stigmer resume [session-id-or-text] [flags]
```

## Flags

| Flag              | Type   | Default | Description                                                          |
| ----------------- | ------ | ------- | -------------------------------------------------------------------- |
| `--json`          | `bool` |         | stream execution events as newline-delimited JSON (for scripting/CI) |
| `--verbose`, `-v` | `bool` |         | show all execution events                                            |

## Global Flags

| Flag            | Type     | Default | Description                                               |
| --------------- | -------- | ------- | --------------------------------------------------------- |
| `--api-key`     | `string` |         | API key for cloud authentication (overrides stored token) |
| `--debug`, `-d` | `bool`   |         | enable debug mode with detailed logs                      |
| `--org`         | `string` |         | organization slug (overrides context)                     |

## Examples

```bash
# Browse recent sessions interactively
stigmer resume

# Resume a specific session
stigmer resume ses-01abc123xyz456

# Search sessions by subject
stigmer resume "deploy staging"

# Resume with organization override
stigmer resume ses-01abc123xyz456 --org acme-corp
```
