Manage the embedded seedpack — system agents, skills, and MCP server definitions
bundled with the CLI.

The seedpack contains foundational resources (the `stigmer` organization's
built-in agents and skills). On local backends, the seedpack is applied
automatically during server startup. On cloud backends, use
`stigmer seedpack apply` to provision these resources.

## Usage

```bash
stigmer seedpack
```

## Subcommands

### stigmer seedpack apply

Extract the embedded seedpack and apply it to whatever backend the CLI is
currently configured for (local or cloud).

The apply is idempotent: if the seedpack content has not changed since the last
successful apply, the operation is skipped. Use --force to re-apply
unconditionally.

The target organization defaults to "stigmer" and can be overridden via the
STIGMER_SEEDPACK_ORG environment variable.

```bash
stigmer seedpack apply [flags]
```

| Flag            | Type   | Default | Description                                   |
| --------------- | ------ | ------- | --------------------------------------------- |
| `--force`       | `bool` |         | re-apply even if the seedpack has not changed |
| `--json`        | `bool` |         | output result as JSON                         |
| `--quiet`, `-q` | `bool` |         | suppress output, print status line only       |

```bash
# Apply seedpack to the current backend
stigmer seedpack apply

# Force re-apply even if already up to date
stigmer seedpack apply --force

# Apply to a cloud backend
stigmer config backend set cloud
stigmer auth login
stigmer seedpack apply
```

### stigmer seedpack status

Check whether the embedded seedpack has been applied to the current backend.

```bash
stigmer seedpack status [flags]
```

| Flag            | Type   | Default | Description                             |
| --------------- | ------ | ------- | --------------------------------------- |
| `--json`        | `bool` |         | output result as JSON                   |
| `--quiet`, `-q` | `bool` |         | suppress output, print status line only |
