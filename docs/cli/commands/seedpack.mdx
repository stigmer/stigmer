Manage the embedded seedpack — system agents, skills, and MCP server definitions
bundled with the CLI.

The seedpack contains foundational resources (the `stigmer` organization's
built-in agents and skills). On local backends, the seedpack is applied
automatically during server startup. On cloud backends, use
`stigmer seedpack apply` to provision these resources.

## Usage

```bash
stigmer seedpack
```

## Subcommands

### stigmer seedpack apply

apply the seedpack to the configured backend

```bash
stigmer seedpack apply [flags]
```

| Flag      | Type   | Default | Description                                   |
| --------- | ------ | ------- | --------------------------------------------- |
| `--force` | `bool` |         | re-apply even if the seedpack has not changed |
| `--json`  | `bool` |         | emit the result as JSON                       |
| `--quiet` | `bool` |         | print only the status line                    |

### stigmer seedpack status

show seedpack bootstrap status

```bash
stigmer seedpack status [flags]
```

| Flag      | Type   | Default | Description                |
| --------- | ------ | ------- | -------------------------- |
| `--json`  | `bool` |         | emit the result as JSON    |
| `--quiet` | `bool` |         | print only the status line |

## Examples

### Apply the seedpack to a cloud backend

```bash
stigmer config backend set cloud
stigmer auth login
stigmer seedpack apply
```

### Force re-apply (even if unchanged)

```bash
stigmer seedpack apply --force
```

### Check seedpack status

```bash
stigmer seedpack status
```
