Share an Agent via a hosted chat link.

`stigmer share` turns an Agent into a hosted chat page — for anyone with the
link (no Stigmer account needed) or for signed-in members of your Organization.
It prints the hosted chat link and, for public shares, a two-line embed snippet
you can paste into any website. Visitors chat on the sharing Organization's
credits.

## Usage

```bash
stigmer share
```

### Common patterns

```bash
# Share an Agent and print its public chat link + embed snippet
stigmer share agent support-agent

# Share with your Organization's members only
stigmer share agent internal-helper --audience org

# Reset a public link — the old link stops working immediately
stigmer share agent support-agent --reset-link

# Share, then open the chat page in your browser
stigmer share agent acme-corp/support-agent --open

# Stop sharing — the link stops working immediately
stigmer share agent support-agent --off
```

## Examples

### Share an Agent

```bash
stigmer share agent acme-corp/support-agent
```

The command enables sharing and prints the public chat link
(`https://app.stigmer.ai/chat/acme-corp/support-agent`) plus an embed snippet
for your website. Sharing is idempotent — running it again reports the link
without another write.

Any embed origins or visitor messages you configured in the console's Share
dialog are preserved; the CLI only flips the sharing switch.

### Share with your Organization only

```bash
stigmer share agent acme-corp/internal-helper --audience org
```

Only signed-in members of your Organization can chat; anyone else sees the same
"not found" page as for an Agent that never existed. Omitting `--audience`
preserves the share's current audience — a plain toggle never turns an
org-members-only share back into a public one.

### Share a public Agent from another Organization

```bash
stigmer share agent other-org/their-public-agent
```

When the referenced Agent is public and belongs to another Organization, the
share is created in _your_ Organization: your link
(`https://app.stigmer.ai/chat/<your-org>/their-public-agent`), your credits,
your credential bindings. The Agent stays with the Organization that built it —
if its owner makes it private or deletes it, your link stops working on the
visitor's next message.

### Reset a leaked public link

```bash
stigmer share agent acme-corp/support-agent --reset-link
```

Mints a fresh link carrying a secret key (`?k=<key>`) and kills the current one
— including for visitors mid-conversation. Sharing stays on. Re-copy the embed
snippet afterwards so your website keeps working. Resetting applies to public
shares only; org-members-only access ends with membership instead.

### Revoke a shared link

```bash
stigmer share agent acme-corp/support-agent --off
```

Disabling sharing is the kill switch: the hosted link and any embeds stop
working on the visitor's next message. Your origin and message settings are kept
for the next time you enable sharing.

## Notes

- Anyone with a public link can chat, and usage bills the sharing Organization's
  credits. Public links can be forwarded and indexed by search engines — don't
  share Agents that know confidential information.
- Guest chat is served by Stigmer Cloud. Against a local backend the command
  still records the share, but the local link won't serve visitors.
- A share of another Organization's Agent serves anyone with the link —
  `--audience org` is refused with guidance. If the Agent depends on Skills or
  MCP Servers that are not public, the server refuses the share and names what
  is blocking.
- To restrict which websites may embed the Agent, customize visitor messages, or
  bind tool credentials, use the Share dialog in the web console.
- Sharing is stored as its own AgentShare resource, separate from the Agent.
  Manage it declaratively with `stigmer apply`, and inspect it with
  `stigmer get agent-share <ref>`.

## Subcommands

### stigmer share agent

enable sharing for an agent and print its chat link and embed snippet


| Flag           | Type     | Default | Description                                                                                                                     |
| -------------- | -------- | ------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `--audience`   | `string` |         | who can chat: 'public' (anyone with the link) or 'org' (signed-in organization members only); omit to keep the current audience |
| `--json`       | `bool`   |         | emit the result as JSON                                                                                                         |
| `--off`        | `bool`   |         | disable sharing (the link stops working immediately)                                                                            |
| `--open`       | `bool`   |         | open the chat link in your browser                                                                                              |
| `--quiet`      | `bool`   |         | print only the status line                                                                                                      |
| `--reset-link` | `bool`   |         | generate a new share link and kill the current one immediately (public audience)                                                |
