Configure the LLM provider for agent execution.

`stigmer setup` configures which LLM provider agents use when they run on the
local stack. Run it without flags for an interactive menu, or pass `--provider`
(with the related flags) for a non-interactive setup suitable for scripts and
CI. Either path writes to your local configuration, preserving every other
setting.

Supported providers: `anthropic`, `openai`, `ollama`, and `skip`.

## Usage

```bash
stigmer setup [flags]
```

### Common patterns

```bash
# Interactive setup
stigmer setup

# Non-interactive: configure Anthropic
stigmer setup --provider anthropic --api-key sk-ant-xxx

# Point at a local Ollama endpoint
stigmer setup --provider ollama --base-url http://localhost:11434
```

## Options

| Flag         | Type     | Default | Description                                                    |
| ------------ | -------- | ------- | -------------------------------------------------------------- |
| `--api-key`  | `string` |         | API key for a cloud provider                                   |
| `--base-url` | `string` |         | custom base URL (e.g. an Ollama endpoint)                      |
| `--json`     | `bool`   |         | emit the result as JSON                                        |
| `--model`    | `string` |         | model name (defaults per provider)                             |
| `--provider` | `string` |         | provider: anthropic, openai, ollama, or skip (non-interactive) |
| `--quiet`    | `bool`   |         | print only the status line                                     |

## Examples

### Interactive provider selection

```bash
stigmer setup
```

A menu walks you through choosing a provider and entering credentials.

### Non-interactive configuration for CI

```bash
stigmer setup --provider openai --api-key "$OPENAI_API_KEY" --model gpt-4o
```

### Apply a new provider to a running stack

```bash
stigmer setup --provider anthropic --api-key sk-ant-xxx
stigmer down && stigmer up
```

The stack must be restarted to pick up a new LLM configuration.
