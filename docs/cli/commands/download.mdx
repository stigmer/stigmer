Download artifacts produced by an agent execution.

`stigmer download` retrieves files that an agent created during execution.
Artifacts are stored in the Stigmer artifact store and can be downloaded after
the execution completes.

## Usage

```bash
stigmer download <type> <id> [flags]
```

### Common patterns

```bash
# Download all artifacts from an execution
stigmer download execution aex_01abc123

# Download to a specific directory
stigmer download execution aex_01abc123 --output-dir ./results/

# Download a specific artifact by name
stigmer download execution aex_01abc123 --artifact report.pdf
```

## Options

| Flag                 | Type     | Default | Description                             |
| -------------------- | -------- | ------- | --------------------------------------- |
| `--all`              | `bool`   | `true`  | download all artifacts (default)        |
| `--artifact`         | `string` |         | specific artifact to download (by name) |
| `--output-dir`, `-o` | `string` | `.`     | output directory for downloaded files   |

## Examples

### Download all artifacts

```bash
stigmer download execution aex_01abc123
```

All artifacts are saved to the current directory.

### Download to a specific location

```bash
stigmer download execution aex_01abc123 -o ./output/
```

### Download a single artifact

```bash
stigmer download execution aex_01abc123 --artifact generated-agent.yaml
```
