Download artifacts produced by an agent execution.

Currently only supports execution type.

Artifacts are files created by the agent during execution (e.g., reports,
processed data, generated code). They are stored in the artifact store and can
be downloaded after the execution completes.

## Usage

```bash
stigmer download <type> <id> [flags]
```

## Flags

| Flag                 | Type     | Default | Description                             |
| -------------------- | -------- | ------- | --------------------------------------- |
| `--all`              | `bool`   | `true`  | download all artifacts (default)        |
| `--artifact`         | `string` |         | specific artifact to download (by name) |
| `--output-dir`, `-o` | `string` | `.`     | output directory for downloaded files   |

## Global Flags

| Flag            | Type     | Default | Description                                               |
| --------------- | -------- | ------- | --------------------------------------------------------- |
| `--api-key`     | `string` |         | API key for cloud authentication (overrides stored token) |
| `--debug`, `-d` | `bool`   |         | enable debug mode with detailed logs                      |
| `--org`         | `string` |         | organization slug (overrides context)                     |

## Examples

```bash
# Download all artifacts from an execution
stigmer download execution aex_01abc123

# Download to specific directory
stigmer download execution aex_01abc123 --output-dir ./results

# Download specific artifact by name
stigmer download execution aex_01abc123 --artifact report.pdf
```
