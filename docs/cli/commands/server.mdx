Start the Stigmer server in local mode.

This command starts the Stigmer server:

- Auto-downloads and starts Temporal
- On first run, prompts to choose an LLM provider (Anthropic, OpenAI, or Ollama)
- Starts stigmer-server on localhost:7234
- Starts agent-runner for AI agent execution

Run 'stigmer server setup' to reconfigure the LLM provider at any time.

## Usage

```bash
stigmer server [flags]
```

### stigmer server logs

View logs from the Stigmer server daemon.

By default, streams logs in real-time from all components (like kubectl logs
-f). Use --follow=false to disable streaming and only show recent logs. Use
--tail to limit how many existing lines to show before streaming (default: 50).
Use --stderr to view error logs (note: stigmer-server logs go to stderr by
default). Use --component to select a specific component (stigmer-server,
agent-runner, or workflow-runner). Use --all to view logs from all components in
a single interleaved stream (defaults to stderr).

```bash
stigmer server logs [flags]
```

| Flag                | Type     | Default          | Description                                                                   |
| ------------------- | -------- | ---------------- | ----------------------------------------------------------------------------- |
| `--all`             | `bool`   | `true`           | Show logs from all components (interleaved by timestamp, defaults to stderr)  |
| `--component`, `-c` | `string` | `stigmer-server` | Component to show logs for (stigmer-server, agent-runner, or workflow-runner) |
| `--follow`, `-f`    | `bool`   | `true`           | Stream logs in real-time (like kubectl logs -f)                               |
| `--stderr`          | `bool`   |                  | Show stderr logs instead of stdout (note: stigmer-server logs go to stderr)   |
| `--tail`, `-n`      | `int`    | `50`             | Number of recent lines to show before streaming (0 = all lines)               |

### stigmer server reset

Stop all services and remove all persistent state — the SQLite database, skill
artifacts, sessions, runtimes, Temporal state, logs, and downloaded binaries —
then automatically restart the server fresh.

Configuration (config.yaml) is preserved by default. Use --include-config to
also remove it; the setup wizard will run again on next start.

```bash
stigmer server reset [flags]
```

| Flag               | Type   | Default | Description                                               |
| ------------------ | ------ | ------- | --------------------------------------------------------- |
| `--force`          | `bool` |         | Skip confirmation prompt                                  |
| `--include-config` | `bool` |         | Also remove configuration (API keys, backend preferences) |

### stigmer server setup

Run the interactive setup wizard to configure your LLM provider.

This re-runs the same wizard shown on first startup. Use it to switch between
Anthropic, OpenAI, Ollama, or to add an API key after skipping initial setup.

After changing the provider, restart the server to apply: stigmer server stop &&
stigmer server

```bash
stigmer server setup
```
