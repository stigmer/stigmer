Start the MCP server that exposes Stigmer resources to AI coding assistants.

The MCP (Model Context Protocol) server lets tools like Cursor, Claude Desktop,
and Windsurf search, list, and inspect agents, skills, and workflows stored in
Stigmer. By default the server runs in STDIO mode — the MCP client spawns this
process and communicates over stdin/stdout.

When running via the CLI, the server address and API key are automatically
resolved from `~/.stigmer/config.yaml`. Local backends connect without
authentication; cloud backends use the stored token.

## Usage

```bash
stigmer mcp-server [flags]
```

### Common patterns

```bash
# Start in STDIO mode (default — what MCP clients spawn)
stigmer mcp-server

# Start in HTTP mode on a custom port
stigmer mcp-server --transport http --port 9090

# Start with debug logging
stigmer mcp-server --log-level debug
```

## Options

| Flag               | Type     | Default | Description                                                                 |
| ------------------ | -------- | ------- | --------------------------------------------------------------------------- |
| `--api-key`        | `string` |         | API key for stigmer-server (env: STIGMER_API_KEY)                           |
| `--log-format`     | `string` |         | log encoding: text or json (env: STIGMER_MCP_LOG_FORMAT)                    |
| `--log-level`      | `string` |         | minimum log level: debug, info, warn, or error (env: STIGMER_MCP_LOG_LEVEL) |
| `--port`           | `string` |         | HTTP listen port (env: STIGMER_MCP_HTTP_PORT)                               |
| `--server-address` | `string` |         | gRPC address of stigmer-server (env: STIGMER_SERVER_ADDRESS)                |
| `--transport`      | `string` |         | transport mode: stdio, http, or both (env: STIGMER_MCP_TRANSPORT)           |

### Transport modes

| Mode    | Use case                                |
| ------- | --------------------------------------- |
| `stdio` | MCP client spawns the process (default) |
| `http`  | Remote deployments, multiple clients    |
| `both`  | STDIO and HTTP simultaneously           |

### MCP client configuration

Add Stigmer to your MCP client's configuration. For Cursor, add to `mcp.json`:

```json
{
  "command": "stigmer",
  "args": ["mcp-server"]
}
```

### Environment variables

Configuration precedence: CLI flags > environment variables >
`~/.stigmer/config.yaml` > defaults.

| Variable                        | Default                             | Purpose                                    |
| ------------------------------- | ----------------------------------- | ------------------------------------------ |
| `STIGMER_SERVER_ADDRESS`        | From CLI config or `localhost:9090` | gRPC address of stigmer-server             |
| `STIGMER_API_KEY`               | From CLI config                     | API key (auto-resolved for cloud backends) |
| `STIGMER_MCP_TRANSPORT`         | `stdio`                             | Transport mode                             |
| `STIGMER_MCP_HTTP_PORT`         | `8080`                              | HTTP listen port                           |
| `STIGMER_MCP_HTTP_AUTH_ENABLED` | `true`                              | Enable HTTP authentication                 |
| `STIGMER_MCP_LOG_FORMAT`        | `text`                              | Log format (`text` or `json`)              |
| `STIGMER_MCP_LOG_LEVEL`         | `info`                              | Minimum log level                          |
