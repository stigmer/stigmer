The Stigmer CLI is the primary tool for interacting with the Stigmer platform
from your terminal. Run agents, deploy resource definitions, manage local and
cloud backends, and connect MCP servers — all from the command line.

## Installation

### macOS (Homebrew)

```bash
brew install stigmer/tap/stigmer
```

### Shell script (macOS / Linux)

```bash
curl -fsSL https://get.stigmer.ai | sh
```

### From source

```bash
git clone https://github.com/stigmer/stigmer.git
cd stigmer
npm install
npm start -w @stigmer/cli -- --help
```

## Backend modes

The CLI connects to one of two backends:

| Mode      | Description                                               |
| --------- | --------------------------------------------------------- |
| **Local** | Stigmer server running on your machine (`localhost:7234`) |
| **Cloud** | Stigmer Cloud API (`api.stigmer.ai`)                      |

Switch between backends with `stigmer config backend set`:

```bash
# Use the local server
stigmer config backend set local

# Use Stigmer Cloud
stigmer config backend set cloud
stigmer auth login
```

### Starting the local server

```bash
stigmer server
```

On first run, an interactive prompt asks for your Anthropic API key — local
agent execution runs on Anthropic Claude models. The server starts Temporal for
durable execution and the agent-runner for AI agent processing.

## Quick start

```bash
# Start the server
stigmer server

# Run an agent interactively
stigmer run

# Run a specific agent with a message
stigmer run my-agent -m "Summarize the quarterly report"

# Deploy resources from YAML
stigmer apply -f agent.yaml
```

## LLM configuration

Local mode runs agents on Anthropic Claude models. Provide your API key once —
either export `ANTHROPIC_API_KEY` in your shell or enter it during setup — and
the platform picks the best current model automatically.

Reconfigure at any time with `stigmer setup`.
