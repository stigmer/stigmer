# CLI

The `stigmer` command-line interface lets you run AI Agents, manage Workflows,
and operate the local Stigmer Server from your terminal.

## Getting Started

Install the CLI and start the local server:

```bash
stigmer server
```

The server downloads its dependencies on first run and prompts you to choose an
LLM provider (Anthropic, OpenAI, or Ollama).

Once the server is running, execute an Agent:

```bash
stigmer run my-agent -m "Review this code"
```
