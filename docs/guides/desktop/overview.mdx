title: Stigmer Desktop
description:
  A native desktop app that gives you everything the web console offers, plus
  local runner management, a system tray, deep links, and auto-updates.
---

Stigmer Desktop is a native app for macOS, Linux, and Windows. It renders the
same UI as the web console — Sessions, Agents, Skills, Settings — but adds
capabilities that a browser cannot provide: starting and stopping runner
processes on your machine, running in the background via the system tray,
responding to `stigmer://` deep links, picking local folders with a native file
dialog, and updating itself automatically.

If you already use the web console, the desktop app is not a replacement. It is
an extension. Use it when you want to run Agents on your own machine instead of
in the cloud.

## What the desktop app adds

|                         | Web console          | Stigmer Desktop                                |
| ----------------------- | -------------------- | ---------------------------------------------- |
| **Sessions & Agents**   | Full access          | Same — renders the same SDK components         |
| **Settings & API keys** | Full access          | Same                                           |
| **Local runners**       | Launch via deep link | Start, stop, and monitor directly              |
| **System tray**         | —                    | Runners keep running when the window is closed |
| **Native file picker**  | Browser file input   | Full OS file dialog for workspace selection    |
| **Deep links**          | —                    | Receives `stigmer://` URLs from the browser    |
| **Notifications**       | —                    | Native OS notifications for runner events      |
| **Automatic updates**   | —                    | Checks for updates and applies them on restart |

## Who this guide is for

These guides are for developers who want to run Agents on their own machine. You
should already understand what [Runners](/docs/concepts/runners) are and how
they fit the platform. If terms like "runner phase" or "local vs cloud runner"
aren't familiar yet, start with the
[Runners concept page](/docs/concepts/runners).
