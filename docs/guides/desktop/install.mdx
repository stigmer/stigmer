Stigmer Desktop is available for macOS, Linux, and Windows. Download the
installer for your platform, run it, and sign in with your Stigmer account.

## Supported platforms

| Platform | Architecture        | Installer format      |
| -------- | ------------------- | --------------------- |
| macOS    | Apple Silicon (M1+) | `.dmg`                |
| macOS    | Intel (x86_64)      | `.dmg`                |
| Linux    | x86_64              | `.AppImage` or `.deb` |
| Windows  | x86_64              | `.exe`                |

## Download

Download the latest release from the [Download page](/download). It detects your
platform automatically and links to the correct installer. You can also browse
all releases on the
[GitHub Releases page](https://github.com/stigmer/stigmer/releases?q=desktop).

## Install

<Tabs items={["macOS", "Linux", "Windows"]}>
  <Tab value="macOS">

1. Open the `.dmg` file.
2. Drag **Stigmer** into the **Applications** folder.
3. Launch Stigmer from Applications or Spotlight.

<Callout type="info">
  On first launch, macOS may show a warning because the app is not yet
  code-signed with an Apple Developer certificate. Open **System Settings >
  Privacy & Security** and click **Open Anyway** to allow it. This step is only
  needed once. Future releases will be signed and notarized.
</Callout>

  </Tab>
  <Tab value="Linux">

**AppImage** (works on any distribution):

```bash
chmod +x Stigmer_*.AppImage
./Stigmer_*.AppImage
```

**Debian / Ubuntu** (`.deb`):

```bash
sudo dpkg -i stigmer_*.deb
```

After installation, launch Stigmer from your application menu or run `stigmer`
from the terminal.

  </Tab>
  <Tab value="Windows">

1. Run the `.exe` setup installer.
2. Follow the installation wizard.
3. Launch **Stigmer** from the Start menu.

  </Tab>
</Tabs>

## First launch

When you open Stigmer Desktop for the first time, you see a login screen. Sign
in with your Stigmer account. The app uses the same authentication flow as the
web console — your browser opens briefly to complete the sign-in, then redirects
back to the desktop app.

<Callout type="tip">
  **Running locally?** If your Stigmer server is running on `localhost` (via
  `stigmer server`), the app detects local mode automatically. No cloud account
  is needed — the app connects to your local server directly.
</Callout>

After signing in, you see the same interface as the web console: Sessions,
Agents, Skills, and Settings. Everything you can do in the browser, you can do
here.

## Automatic updates

Stigmer Desktop checks for updates automatically. When a new version is
available, a notification appears with the option to restart and apply the
update. Updates are downloaded in the background — you do not need to revisit
the download page.

The app checks for updates shortly after launch and then every four hours while
running. You can continue working while the update downloads.

## What's next

The app is installed and you're signed in. The real value of Stigmer Desktop is
managing runners on your machine — starting them, stopping them, and monitoring
their status without leaving the app. The next guide covers all of that:
[Manage runners](/docs/guides/desktop/manage-runners).
