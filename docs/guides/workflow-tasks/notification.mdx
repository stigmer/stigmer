NotificationTaskConfig defines the configuration for notification tasks that
send messages to humans through channels like Slack, email, Discord, Microsoft
Teams, or webhooks.

## Kind

`notification`

## YAML Example

```yaml
- alert_slack:
    notification:
      channel: "slack"
      recipients:
        - "#incident-response"
        - "@oncall-lead"
      subject:
        "P${ $context.triage.severity } Incident: ${ $context.ticket.title }"
      body: |
        *Severity*: ${ $context.triage.severity }
        *Category*: ${ $context.triage.category }
        *Summary*: ${ $context.agent_analysis.structured.summary }
      metadata:
        thread_ts: "${ $context.slack_thread_id }"
    export:
      as: "${ . }"
```
