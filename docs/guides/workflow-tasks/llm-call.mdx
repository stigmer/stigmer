LlmCallTaskConfig defines the configuration for llm_call tasks that make direct
LLM API calls without the overhead of a full agent invocation.

## Kind

`llm_call`

## YAML Examples

```yaml
- classify_severity:
    call: llm
    with:
      model: "gpt-4o-mini"
      system_prompt: "You are a support ticket classifier."
      prompt: "Classify this ticket: ${ $context.ticket.description }"
      response_schema:
        type: object
        required: [severity, category]
        properties:
          severity:
            type: string
            enum: [low, medium, high, critical]
          category:
            type: string
      on_invalid: ON_INVALID_RETRY
      max_retries: 2
    export:
      as: "${ . }"
```

```yaml
- summarize:

    with:
      model: "claude-sonnet-4-5"
      prompt: "Summarize in 2 sentences: ${ $context.document.text }"
      temperature: 0.3
      max_tokens: 200
    export:
      as: "${ . }"
```
