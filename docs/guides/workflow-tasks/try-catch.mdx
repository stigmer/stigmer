TryTaskConfig defines the configuration for try_catch tasks that handle errors.

## Kind

`try_catch`

## YAML Example

```yaml
- safe_api_call:
    try:
      - risky_call:
          call: http
          with:
            method: "POST"
            endpoint:
              uri: "https://api.unreliable.com/submit"
    catch:
      as: error
      do:
        - log_failure:
            set:
              variables:
                error_message: "${ $error.message }"
```
