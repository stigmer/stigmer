Your Agents can interact with external systems through MCP servers — tool
connections, carried in plugins, that use the
[Model Context Protocol](https://modelcontextprotocol.io/). This section covers
the practical side: finding tools, connecting them, and setting up
authentication.

If you're new to how tools work in Stigmer, start with the
[Tools concept page](/docs/concepts/tools) for the foundational model.

## Who these guides are for

These guides are for **platform builders** adding tool access to their Agents.
You should be comfortable with plugins and the variables their MCP servers read.
If terms like `plugins`, `mcp__plugin_<plugin>_<server>`, or `destructiveHint`
aren't familiar yet, the [Tools concept page](/docs/concepts/tools) covers them.
If you haven't connected tools before, start with the
[Connect your tools](/docs/getting-started/connect-tools) tutorial for a
hands-on introduction.
