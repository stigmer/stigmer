The runner is the process that executes your Agents and Workflows. These guides
are for platform builders who **embed** the runner in their own application — a
desktop app that runs Sessions on the user's machine, or a backend that hosts
runners for local execution.

If you are new to what a Runner is and how it fits the platform, start with the
[Runners concept page](/docs/concepts/runners). If you only want to _run_ Agents
rather than embed the runner, you do not need these guides: use `stigmer up`, or
let Stigmer Cloud provision a runner for you.

## Who these guides are for

These guides assume you are comfortable with Node.js and the Stigmer SDK. They
build on the concepts in the [Runners concept page](/docs/concepts/runners), so
read that first if the runner lifecycle, execution modes, or how Sessions find
runners are unfamiliar.
