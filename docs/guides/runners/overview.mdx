The `stigmer` CLI gives you full control over runner processes on your machine.
Start a runner with one command, run multiple runners side by side, switch
between native and Docker runtime options, and stop everything when you're done.

If you prefer a graphical interface, the
[Stigmer Desktop app](/docs/guides/desktop/overview) offers the same runner
management through a native window and system tray. Both interfaces manage the
same runners — start one from the CLI and stop it from the desktop app, or the
other way around.

## CLI vs Desktop App vs Web Console

|                          | CLI (`stigmer`)                 | Desktop App                     | Web Console                       |
| ------------------------ | ------------------------------- | ------------------------------- | --------------------------------- |
| **Start a runner**       | `stigmer up`                    | Settings > Runners > Start      | Launch via `stigmer://` deep link |
| **Stop a runner**        | `stigmer down runner`           | Action menu or system tray      | Settings > Runners > Stop         |
| **List runners**         | `stigmer list runners`          | Settings > Runners panel        | Settings > Runners panel          |
| **Docker runtime**       | `--runtime docker`              | Runtime picker in start dialog  | —                                 |
| **Multiple runners**     | One terminal per runner         | All in one window               | View only — start from CLI or app |
| **Background operation** | Runs in a terminal Session      | System tray keeps runners alive | —                                 |
| **Best for**             | Scripting, CI/CD, SSH, headless | Day-to-day development          | Monitoring and remote stop        |

## Who these guides are for

These guides are for developers who prefer the terminal or need runner
management in Environments without a graphical interface — SSH Sessions, CI/CD
pipelines, Docker containers, or headless servers.

You should already understand what [Runners](/docs/concepts/runners) are and how
they fit the platform. If terms like "runner phase" or "local vs cloud runner"
aren't familiar yet, start with the
[Runners concept page](/docs/concepts/runners).

**Prerequisites:**

- The Stigmer CLI is installed. If you went through the
  [Quickstart](/docs/getting-started/quickstart), you already have it.
- You are authenticated — either via `stigmer auth login` (cloud) or running a
  local server with `stigmer up server`.
