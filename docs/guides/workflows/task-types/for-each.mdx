ForTaskConfig defines the configuration for for_each tasks that iterate over
collections.

## Kind

`for_each`

## YAML Example

```yaml
- process_items:
    for:
      each: item
      in: "${ $context.items }"
      do:
        - classify_item:
            call: llm
            with:
              model: "gpt-4o-mini"
              prompt: "Classify: ${ $item.description }"
```
