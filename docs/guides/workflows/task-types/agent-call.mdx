AgentCallTaskConfig defines the configuration for agent_call tasks that invoke
AI agents.

## Kind

`agent_call`

## YAML Examples

```yaml
- name: triage_ticket
  kind: agent_call
  task_config:
    agent: "support-triage"
    message: "${ .ticket.description }"
    output:
      schema:
        type: object
        required: [severity, category]
        properties:
          severity:
            type: string
            enum: [low, medium, high, critical]
          category:
            type: string
      on_invalid: ON_INVALID_RETRY
      max_retries: 2
  export:
    as: "${ .structured }"
```

```yaml
- name: fix_flaky_test
  kind: agent_call
  task_config:
    agent: "code-reviewer"
    message: "Fix the flaky test in ${ .failing_test }"
    harness: HARNESS_CURSOR
    run_config:
      model_name: "composer-2.5"
      max_cost_usd: 0.50
      # Fast tier: billed at the model's fast rates. Valid only for
      # models with a fast pricing tier; refused at create otherwise.
      # The shorthand spellings "standard"/"fast" are also accepted.
      service_tier: SERVICE_TIER_FAST
```

```yaml
- name: deep_review
  kind: agent_call
  task_config:
    agent: "code-reviewer"
    message: "Review the architecture of ${ .module }"
    harness: HARNESS_CURSOR
    run_config:
      model_name: "claude-haiku-4-5"
      # Thinking mode: the model's extended-reasoning variant, billed
      # at base per-token rates (reasoning tokens count as output).
      # Valid only for models with the thinking capability; refused at
      # create otherwise. The shorthand spellings "disabled"/"enabled"
      # are also accepted.
      thinking_mode: THINKING_MODE_ENABLED
```
