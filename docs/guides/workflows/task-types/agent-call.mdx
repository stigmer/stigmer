AgentCallTaskConfig defines the configuration for agent_call tasks that invoke
AI agents.

## Kind

`agent_call`

## YAML Example

```yaml
- triage_ticket:
    call: agent
    with:
      agent: "support-triage"
      message: "${ .ticket.description }"
      output:
        schema:
          type: object
          required: [severity, category]
          properties:
            severity:
              type: string
              enum: [low, medium, high, critical]
            category:
              type: string
        on_invalid: ON_INVALID_RETRY
        max_retries: 2
    export:
      as: "${ .structured }"
```
