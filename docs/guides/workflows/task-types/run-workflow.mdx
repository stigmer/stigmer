RunTaskConfig defines the configuration for run_workflow tasks that execute
sub-workflows.

The run_workflow kind is not supported yet: a Workflow that contains one is
refused when it is saved, because nothing resolves the child name to a Workflow
the platform can run.

## Kind

`run_workflow`

## YAML Example

```yaml
- name: run_enrichment
  kind: run_workflow
  task_config:
    workflow: "data-enrichment"
    input:
      user_id: "${ $context.user.id }"
      source: "parent_workflow"
  export:
    as: "${ . }"
```
