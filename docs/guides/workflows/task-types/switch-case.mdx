SwitchTaskConfig defines the configuration for switch_case tasks that branch
conditionally.

## Kind

`switch_case`

## YAML Example

```yaml
- name: route_by_severity
  kind: switch_case
  task_config:
    cases:
      - name: critical
        when: "${ $context.triage.severity == 'critical' }"
        then: escalate
      - name: high
        when: "${ $context.triage.severity == 'high' }"
        then: notify_team
      - name: default
        then: log_and_close
```
