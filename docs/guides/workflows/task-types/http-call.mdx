HttpCallTaskConfig defines the configuration for http_call tasks that make HTTP
requests.

## Kind

`http_call`

## YAML Example

```yaml
- name: fetch_data
  kind: http_call
  task_config:
    method: "GET"
    endpoint:
      uri: "https://api.example.com/tickets/${ $context.ticket_id }"
    headers:
      Authorization: "Bearer ${ .secrets.API_TOKEN }"
  export:
    as: "${ . }"
```
