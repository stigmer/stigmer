TransformTaskConfig defines the configuration for transform tasks that perform
deterministic data transformation without LLM calls.

## Kind

`transform`

## YAML Examples

```yaml
- name: build_api_payload
  kind: transform
  task_config:
    engine: TRANSFORM_ENGINE_JQ
    expression:
      "{name: .customer.full_name, severity: .triage.severity, summary:
      .agent_analysis.structured.summary}"
    input: "${ $context }"
  export:
    as: "${ . }"
```

```yaml
- name: render_message
  kind: transform
  task_config:
    engine: TRANSFORM_ENGINE_TEMPLATE
    expression: "Ticket {{ .ticket_id }} classified as {{ .severity }}"
    input: "${ $context.build_api_payload }"
  export:
    as: "${ . }"
```
