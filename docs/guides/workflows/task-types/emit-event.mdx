EmitEventTaskConfig defines the configuration for emit_event tasks that publish
CloudEvents to external consumers, other workflows, audit trails, and metrics
systems.

## Kind

`emit_event`

## YAML Example

```yaml
- notify_classified:
    emit_event:
      event:
        type: "stigmer.workflow.ticket.classified"
        subject: "${ $context.ticket.id }"
        data:
          ticket_id: "${ $context.ticket.id }"
          severity: "${ $context.triage.severity }"
          category: "${ $context.triage.category }"
    export:
      as: "${ . }"
```
