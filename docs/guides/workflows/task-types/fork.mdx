ForkTaskConfig defines the configuration for fork tasks that execute branches in
parallel.

## Kind

`fork`

## YAML Example

```yaml
- parallel_enrichment:
    fork:
      branches:
        - name: fetch_profile
          do:
            - get_profile:
                call: http
                with:
                  method: "GET"
                  endpoint:
                    uri: "https://api.example.com/users/${ $context.user_id }"
        - name: fetch_history
          do:
            - get_history:
                call: http
                with:
                  method: "GET"
                  endpoint:
                    uri: "https://api.example.com/history/${ $context.user_id }"
      compete: false
```
