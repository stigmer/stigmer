Workflows are multi-step automation sequences that go beyond single Agent
interactions. They let you chain together Agent calls, HTTP requests,
conditional logic, and human approval gates into structured processes that run
reliably — even across failures and restarts.

Workflow documentation is **coming soon**. The Workflow engine is being
finalized, and comprehensive documentation will be published once it's
production-ready.

In the meantime, here's what you can expect:

- **Workflow definitions** in YAML using a structured task model
- **Task types** including Agent calls, HTTP calls, variable setting, wait
  conditions, branching, and loops
- **Durable execution** with automatic retry and crash recovery
- **Human approval gates** within multi-step processes
- **Full API access** — create, trigger, monitor, and manage Workflows
  programmatically

If you want to get started with Agent capabilities today, the
[Getting Started](/docs/getting-started/quickstart) guide walks you through
creating your first Agent with domain knowledge and tool access.
