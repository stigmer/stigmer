  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "stigmer.fullname" . }}

  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "stigmer.fullname" . }}
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "stigmer.fullname" . }} 7234:7234 7235:7235
  open http://localhost:7234

Download links and skill transfer URLs are minted for http://localhost:7234 and :7235 (the port-forward above). To serve other machines, add an Ingress (ingress.enabled) or set server.publicUrl and server.artifactPublicUrl.

{{- if not (include "stigmer.runnerEnabled" .) }}

The runner is not running yet. It needs its own API key, and only someone signed in can create one. Until it has one, sessions and workflow runs wait. Sign in to the console, create a key named runner with no expiry (Settings → API Keys, or `stigmer apikey create --name runner --never-expires`), then give it to the runner:

  kubectl -n {{ .Release.Namespace }} create secret generic stigmer-runner-token --from-literal=STIGMER_TOKEN=stk_...
  helm upgrade {{ .Release.Name }} oci://ghcr.io/stigmer/charts/stigmer -n {{ .Release.Namespace }} --reuse-values --set runner.stigmerToken.existingSecret=stigmer-runner-token
{{- end }}
{{- end }}

One trust domain: stdio MCP servers run inside the runner container and can reach its filesystem and network. Whoever reaches Temporal can start work on the runner's queue{{ if and .Values.temporal.enabled .Values.temporal.networkPolicy.enabled }}; the bundled Temporal admits only the stigmer pod (a NetworkPolicy, enforced only by a network plugin that supports it){{ end }}.
