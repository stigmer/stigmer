Create and manage API keys for programmatic access to Stigmer Cloud.

API keys are an alternative to browser-based OAuth authentication. They are
ideal for CI/CD pipelines, automation scripts, and service accounts. Use the
`apikey create` subcommand to generate keys, and the unified verbs
(`stigmer get apikey`, `stigmer list apikey`, `stigmer delete apikey`) for
other operations.

{/* AUTO_USAGE */}

### Common patterns

```bash
# Create a new API key
stigmer apikey create --name "ci-pipeline"

# Create a key that never expires
stigmer apikey create --name "automation" --never-expires

# Look up which key matches a raw token
stigmer apikey fingerprint stk_abc123...

# List all keys (via unified verb)
stigmer list apikey

# Delete a key (via unified verb)
stigmer delete apikey ak_01abc123
```

{/* AUTO_FLAGS */}

### Key expiration

By default, keys expire in 90 days. You can customize this:

| Flag | Behavior |
|------|----------|
| _(default)_ | Expires in 90 days |
| `--never-expires` | Key never expires |
| `--expires-in DURATION` | Custom duration (e.g., `30d`, `6h`, `1y`) |

Duration units: `m` (minutes), `h` (hours), `d` (days), `y` (years).

### Security

The raw API key is displayed **only once** at creation time. Save it
immediately — it cannot be retrieved later. Use `stigmer apikey fingerprint`
to identify which key a token belongs to without exposing it.

## Examples

### Create a key for CI

```bash
stigmer apikey create --name "github-actions"
```

Save the displayed key as a CI secret.

### Create a short-lived key

```bash
stigmer apikey create --name "temp-access" --expires-in 6h
```

### Identify a key from a token

```bash
stigmer apikey fingerprint stk_abc123...
```

Computes a SHA-256 hash and looks up the matching key record.
