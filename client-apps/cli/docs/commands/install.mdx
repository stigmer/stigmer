Install a plugin from a marketplace by name.

`stigmer install` takes the name of a plugin in a marketplace, reads the
plugin's folder from that marketplace's tree, and pushes it to your
organization exactly as `stigmer push plugin <dir>` would push the same folder
from disk. Stigmer materializes the plugin's skills, MCP servers, agent and
workflows as one unit; installing again with a changed plugin upgrades it, and
installing an unchanged one changes nothing.

### Common patterns

```bash
# Install from the official marketplace by name
stigmer install assistant

# Install from a marketplace you added, naming it
stigmer install cursor-plugins/thermos

# Pin the version the marketplace must offer
stigmer install cursor-plugins/thermos@1.0.0

# See what would install, without pushing
stigmer install cursor-plugins/thermos --dry-run

# Install into a specific organization, visible to the whole org
stigmer --org my-org install cursor-plugins/thermos --visibility org
```

### The ref

A ref is `[marketplace/]name[@version]`.

- **`name`** is the plugin's name in the marketplace file, the same characters
  a plugin name allows (lowercase letters, digits, `.` and `-`).
- **`marketplace/`** names one of your configured marketplaces
  (`stigmer marketplace list`). Without it, every configured marketplace is
  searched and the name must be offered by exactly one; when two offer it,
  the command refuses and names both, so the answer never depends on the order
  you added them in.
- **`@version`** asserts the version the plugin's manifest declares. A
  marketplace tree holds one version of each plugin, so the ref either names
  it or is refused with the version on offer.

A path (`./thermos`, `/tmp/plugin`) is not a ref: install a folder with
`stigmer push plugin <dir>`.

### What a marketplace is

A marketplace is a directory tree with a marketplace file at its root: the
convention Cursor (`.cursor-plugin/marketplace.json`), Claude Code
(`.claude-plugin/marketplace.json`) and Codex (`.agents/plugins/marketplace.json`)
publish, and Stigmer's own (`marketplace.json`). `stigmer install` reads all
four. The official marketplace is built in; add others with
`stigmer marketplace add`.

Nothing on the server records which marketplace a plugin came from: a plugin
is identified by its name in your organization, so installing `thermos` from a
second marketplace upgrades the `thermos` you installed from the first.

### Removing

There is no `uninstall`. `stigmer delete plugin <name>` removes the plugin and
everything it installed, the one delete verb across kinds.
