Delete a resource from the Stigmer backend.

`stigmer delete` permanently removes a resource by type and reference. For a run
in progress, delete gracefully cancels the agent. This operation
cannot be undone.

{/* AUTO_USAGE */}

### Common patterns

```bash
# Delete an agent by slug
stigmer delete agent my-agent

# Delete an agent by ID
stigmer delete agent agt_abc123

# Cancel a run in progress
stigmer delete run run_01abc123

# Skip the confirmation prompt
stigmer delete agent my-agent --force
```

### Supported resource types

| Type | Aliases | Behavior |
|------|---------|----------|
| Agent | `agent`, `agt`, `agents` | Permanently deletes the agent definition |
| API Key | `apikey`, `key` | Revokes the key; callers using it are cut off immediately |
| Channel | `channel`, `chn` | Tears the channel down: its chat link stops working, or its Slack workspace or WhatsApp number stops serving the agent |
| Channel App | `channel-app`, `channelapp`, `chapp` | Permanently deletes the app and its stored provider secrets |
| Environment | `environment`, `env`, `environments` | Permanently deletes the environment; refused while an agent, a routine or the organization's default names it, naming each, so remove it from them first |
| Eval Run | `eval-run`, `evr`, `eval-runs` | Deletes the eval run with its tries' conversations, runs and scores; a pending or running eval run is refused, so cancel it first |
| Organization | `organization`, `org`, `organizations` | Deletes the organization at once and everything it owned in the background; its slug is free when that finishes |
| Routine | `routine`, `rtn`, `routines` | Permanently deletes the routine and tears down its schedule |
| Run | `run`, `runs` | Gracefully cancels a run in progress |
| Scoring Rule | `scoring-rule`, `srl`, `scoring-rules` | Switches AI grading off for its agent; scores already recorded stay on their runs |
| Skill | `skill`, `skills` | Permanently deletes the skill |
| Vault | `vault`, `vlt`, `vaults` | Permanently deletes the vault and every value it holds; runs that name it are refused until they name another |

### Confirmation

By default, `stigmer delete` prompts for confirmation before proceeding.
Use `--force` to skip the prompt in scripts and CI pipelines.

```bash
# Interactive confirmation
stigmer delete agent my-agent

# Skip confirmation (use in scripts)
stigmer delete agent my-agent --force
```

## Examples

### Delete an agent

```bash
stigmer delete agent my-agent
```

You are prompted to confirm. The agent and all its versions are permanently
removed.

### Cancel a run in progress

```bash
stigmer delete run run_01abc123
```

The running agent receives a graceful cancellation signal.

### Scripted deletion with JSON output

```bash
stigmer delete agent my-agent --force --json
```
