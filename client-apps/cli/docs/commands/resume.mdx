Resume an existing session by ID, or browse recent sessions interactively.

`stigmer resume` reconnects you to a previous conversation. If the latest
run is still in progress, you re-attach to the live stream. If all
runs have completed, you see the full conversation history and can
send follow-up messages.

{/* AUTO_USAGE */}

### Common patterns

```bash
# Browse recent sessions interactively
stigmer resume

# Resume by session ID
stigmer resume ses_01j9z3k8m2q4r6t8v0w2y4a6c8

# Search sessions by subject
stigmer resume "deploy staging"
```

{/* AUTO_FLAGS */}

### How resuming works

| Scenario | Behavior |
|----------|----------|
| Latest run is in progress | Re-attach to the live output stream |
| All runs complete | Display conversation history, accept new messages |
| Search text provided | Find sessions by subject, show interactive picker |

Session IDs must be provided in full (e.g., `ses_01j9z3k8m2q4r6t8v0w2y4a6c8`). Partial
IDs are not accepted.

### In the session

On a terminal, `stigmer run` and `stigmer resume` open the session and keep it
open for follow-ups. The agent works on the server, so leaving is not stopping:

| Key | What it does |
|-----|--------------|
| Enter | Send the message |
| `\` then Enter, Ctrl+J, Alt+Enter | Start a new line (Shift+Enter too, where the terminal reports it) |
| Up, Down | Earlier messages, kept per directory |
| Esc | Stop the agent's turn; a second Esc while it stops ends it now |
| Ctrl+C | Clear the message; on an empty one, press twice to leave. The agent keeps working, and `stigmer resume <session-id>` comes back |
| Shift+Tab, Ctrl+T | Switch plan and agent mode |
| Ctrl+O | Expand tool calls and thinking |
| `?` | List the keys and commands |

Type `/` for the commands: `/help`, `/mode plan` or `/mode agent`, `/stop`
and `/exit`. Type `@` to mention a file in the session's local folder
(`--workspace <dir>`): it is sent as a reference the agent reads in place.

## Examples

### Browse and select a session

```bash
stigmer resume
```

An interactive picker shows your recent sessions. Select one to continue
the conversation.

### Resume a specific session

```bash
stigmer resume ses_01j9z3k8m2q4r6t8v0w2y4a6c8
```

### Search sessions by subject

```bash
stigmer resume "deploy staging"
```

Finds sessions whose subject matches your query and shows an interactive
picker if multiple match.
