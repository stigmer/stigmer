Assign a tag to a resource version.

`stigmer tag` attaches a named tag to a specific version of a resource,
identified by its content hash. Tags give a stable, human-friendly handle to a
particular version (for example `stable` or `v1`). Agents are the supported
resource type; Skills are tagged when they are pushed.

The hash can be the full 64 characters or any unique prefix of at least 4, such
as the 12-character short hash `stigmer get agent --version-history` prints. A
prefix that matches no version, or several, is refused with the versions it
matched.

### Common patterns

```bash
# Tag an agent version as stable, by the short hash the history prints
stigmer tag agent acme-corp/variance-reporter 3f8a1c0e9b7d stable

# The same, by its full 64-character hash
stigmer tag agent acme-corp/variance-reporter 3f8a1c0e9b7d2a4c6e5f1b3d9a7c0e2f4b6d8a1c3e5f7b9d0a2c4e6f8b1d3a5c stable

# Tag another version as v1
stigmer tag agent acme-corp/variance-reporter 9c2e4a6b8d0f1a3c5e7b9d1f3a5c7e9b0d2f4a6c8e1b3d5f7a9c0e2b4d6f8a1c v1
```

## Examples

### Promote a version to "stable"

```bash
stigmer get agent acme-corp/variance-reporter --version-history   # the HASH column
stigmer tag agent acme-corp/variance-reporter 3f8a1c0e9b7d stable
```

The tag now points at the version with that hash; the history shows it in the
TAG column. Re-tagging moves the tag to a new version.
