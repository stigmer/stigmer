Manage the sources you install plugins from.

A source is a directory tree with a marketplace file at its root, the
convention Cursor, Claude Code and Codex publish and Stigmer reads unchanged.
Stigmer's official catalogue is the one built-in source, published with each
release and curated: every plugin in it is one Stigmer may ship and one whose
servers Stigmer can connect to. `stigmer marketplace` records your own
sources, a repository you or your company publish, under `marketplaces` in
`~/.stigmer/config.yaml`; the server never sees a source, only the plugin
archive [`stigmer install`](./install) pushes from one.

### Common patterns

```bash
# Add your company's catalogue (a public GitHub repository with a marketplace file)
stigmer marketplace add acme/agent-plugins

# Add a repository at a branch or tag, or from its URL
stigmer marketplace add acme/agent-plugins@main
stigmer marketplace add https://github.com/acme/agent-plugins

# Add a catalogue on this machine
stigmer marketplace add ./my-plugins

# Record it under a name of your own
stigmer marketplace add acme/agent-plugins --name acme

# See what is configured, and what one offers
stigmer marketplace list
stigmer marketplace show acme-plugins

# Stop installing from one (plugins already installed stay)
stigmer marketplace remove acme-plugins
```

`acme/agent-plugins` stands for a repository of your own; the official
catalogue already carries the plugins Stigmer can offer from the public
vendor catalogues, so adding one of those mostly re-surfaces what the
catalogue left out.

### Sources

`add` accepts three forms and reads the marketplace once before recording it,
so a source that is not a readable marketplace is refused now rather than on
the first install.

- **A directory** on this machine, stored as an absolute path. An existing
  directory wins over every other reading, so `add plugins` inside a checkout
  means the folder.
- **A public GitHub repository** as `owner/repo`, optionally pinned with
  `@ref` to a branch, tag or commit; the default branch otherwise. The tree is
  fetched as a zipball on every `show` and `install`, never cached.
- **That repository's URL** as a browser shows it,
  `https://github.com/owner/repo` or `.../tree/<ref>`, unwrapped to the same
  record.

A GitHub source is read at the repository root, where the marketplace file
lives in every dialect. Private repositories are not supported.

### Names

The recorded name is the one the marketplace file gives itself (a repository
`acme/agent-plugins` whose file says `"name": "acme-plugins"` is recorded as
`acme-plugins`), unless `--name` says otherwise. It is the prefix in
`stigmer install <name>/<plugin>`. `stigmer` is the built-in source's name and
cannot be added, replaced or removed.
