Print the Stigmer CLI version.

`stigmer version` prints the version of the installed CLI. This is the same
value reported by the global `--version` flag.

{/* AUTO_USAGE */}

## Examples

### Print the version

```bash
stigmer version
```

### Equivalent global flag

```bash
stigmer --version
```
