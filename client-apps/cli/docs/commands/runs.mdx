Manage run lifecycle and observability.

`stigmer runs` controls the lifecycle of agent runs and exposes their logs
and traces. A run is addressed by its ID, `aex_<ulid>`.

The group is plural because `stigmer run` starts a run; `stigmer runs` manages
one that already exists.

The subcommands fall into three areas:

- **Lifecycle** — `cancel` gracefully stops a run in progress at its next safe
  point; `terminate` force-stops it immediately without cleanup (and cannot be
  recovered); `pause` checkpoints a run in progress; `resume` continues a
  paused one from its last checkpoint.
- **Observability** — `logs` views or streams a run's messages; `trace` shows
  the tool-call structure with status and timing.
- **Approval** — `approve` submits a decision for a run waiting on an
  approval for a tool call.

## Examples

### Cancel and terminate

```bash
# Gracefully cancel a run
stigmer runs cancel aex_01abc123

# Force-stop immediately (unrecoverable)
stigmer runs terminate aex_01xyz789 --reason "stuck run"
```

### Pause and resume

```bash
stigmer runs pause aex_01abc123 --reason "investigating issue"
stigmer runs resume aex_01abc123
```

### Stream logs and inspect a trace

```bash
# Stream live messages from a run
stigmer runs logs aex_01abc123 --follow

# Show the tool-call timeline as YAML
stigmer runs trace aex_01abc123 -o yaml
```

### Approve a waiting run

```bash
# Approve a tool call
stigmer runs approve aex_01xyz789 --tool-call tc_abc --action approve
```
