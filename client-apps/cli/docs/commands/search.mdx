Search for resources matching a text query.

`stigmer search` performs a full-text search across resource names,
descriptions, and tags. Results are sorted by relevance score and cover the
resources you can read: your organization's, and, in a child organization, the
ones its parent shares with its child organizations.

{/* AUTO_USAGE */}

### Common patterns

```bash
# Search for agents related to variance reports
stigmer search agents "variance report"

# Output as JSON for scripting
stigmer search agents "data" --output json
```

### Supported resource types

| Type  | Aliases                  |
| ----- | ------------------------ |
| Agent | `agents`, `agent`, `agt` |

### Pagination

Results come one page at a time (20 per page, at most 100 with `--page-size`).
When more follow, the table ends with how many results match and the command
that reads the next page, carrying its `--page-token`:

```bash
stigmer search agents "test" --page-size 50
# ...
# 120 results match.
# See the next page with: stigmer search agents test --page-size 50 --page-token <token>
```

A token continues the search it came from: the same query in the same
organization.

## Examples

### Find agents for a specific task

```bash
stigmer search agents "variance report"
```

### Search within a specific organization

```bash
stigmer search agents "kubernetes" --org acme-corp
```

### Machine-readable output for scripting

```bash
stigmer search agents "deploy" --output json | jq '.[].metadata.name'
```
