Read how an agent's runs are graded. To run test cases on an agent, use
[`stigmer eval run --agent`](/docs/cli/commands/eval).

{/* AUTO_USAGE */}

### Common patterns

```bash
# How the agent's runs were graded over the last 30 days, per version
stigmer agent quality support-desk

# The last week's failed grades, newest first
stigmer agent quality support-desk --days 7 --flagged --limit 50
```

{/* AUTO_FLAGS */}

### How the agent's runs are graded

`stigmer agent quality` counts the grades of the agent's runs in your
organization over the last `--days` days (1 to 90, default 30, UTC): the
platform's run-health checks, the AI judge's rubrics where AI grading is on, and
people's thumbs. It prints the window's totals (the health and judge pass rates
with their counts, each rubric's, the thumbs up and down), then one row per
agent version, named by its tag or its short version hash. When newer checks or
rubrics replaced older ones within the window, only the current ones are
counted, and the output says older ones exist. `--flagged` lists the failed
grades of the runs you can open instead, newest first, with the names of the
failed checks or rubric items. `-o json` and `-o yaml` print the report, or the
flagged grades, as the API returns them.
