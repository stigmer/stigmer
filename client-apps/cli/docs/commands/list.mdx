List all resources of a given type.

`stigmer list` queries the Stigmer backend and displays a table of resources
matching the specified type. Use `stigmer list types` to see all available
resource types.

{/* AUTO_USAGE */}

### Common patterns

```bash
# List all agents
stigmer list agents

# List available resource types
stigmer list types

# List with a result limit
stigmer list agents --limit 10

# List the agents labelled team=finance
stigmer list agents --label team=finance

# Output as JSON for scripting
stigmer list skills --output json
```

### Supported resource types

| Type | Aliases |
|------|---------|
| Resource types | `types`, `type` |
| Agent | `agents`, `agent`, `agt` |
| API Key | `apikeys`, `apikey`, `key` |
| Channel | `channels`, `channel`, `chn` |
| Channel App | `channel-apps`, `channel-app`, `chapp` |
| Environment | `environments`, `environment`, `env` |
| File | `files`, `file` |
| Organization | `organizations`, `organization`, `org` |
| Routine | `routines`, `routine`, `rtn` |
| Run | `runs`, `run` |
| Session | `sessions`, `session`, `ses` |
| Skill | `skills`, `skill` |
| Vault | `vaults`, `vault`, `vlt` |

Both singular and plural forms are accepted.

`stigmer list files` lists the Files you keep for reuse: uploaded with
`stigmer file upload`, the API or the console's Library, and never given to a
conversation. `stigmer list files --session <id>` lists one conversation's
Files instead, what was given to it and what its turns saved, with the place
each output was saved under the outputs folder. `--session` applies to files
only.

### Listing resource types

Use `stigmer list types` to discover which resource types are available.
Filter by verb to find types that support a specific operation:

```bash
# List all resource types
stigmer list types

# List types that support the "run" verb
stigmer list types --verb run
```

## Examples

### List all agents in the current organization

```bash
stigmer list agents
```

### List skills with JSON output

```bash
stigmer list skills --output json | jq '.[].metadata.name'
```

### Read more than the default 50

The CLI reads the server's pages for you, up to `--limit`; `--limit 0` reads
every page:

```bash
stigmer list agents --limit 200
stigmer list agents --limit 0
```

### Filter by label

`--label key=value` keeps only the resources carrying that label. Repeat it
to require several; every pair must match exactly. A selective filter can
take more than one page of reading to fill a page, and the CLI follows the
pages for you:

```bash
stigmer list agents --label team=finance
stigmer list routines -l team=finance -l tier=gold
```
