Download artifacts produced by a run or a session, a file, or an eval's folder
at a version.

`stigmer download run` retrieves the files an agent saved in its outputs folder
during one run, each written at its place in that folder.
`stigmer download session` retrieves what every turn of a conversation saved
there, the newest turn's file winning when two saved the same path; the files
given to the conversation stay out. `stigmer download file` writes one File's
bytes under its filename. `stigmer download eval` retrieves the `evals/` folder
one version of an eval was pushed as.

{/* AUTO_USAGE */}

### Common patterns

```bash
# Download all artifacts from a run
stigmer download run run_01abc123

# Download to a specific directory
stigmer download run run_01abc123 --output-dir ./results/

# Download a specific artifact by name
stigmer download run run_01abc123 --artifact report.pdf

# Download everything a conversation's turns saved
stigmer download session ses_01abc123 -o reports/

# Download one File under its filename
stigmer download file file_01abc123

# Get the eval version tagged stable back as a folder
stigmer download eval support-agent-evals@stable -o ./evals
```

## Examples

### Download all artifacts

```bash
stigmer download run run_01abc123
```

All artifacts are saved to the current directory.

### Download to a specific location

```bash
stigmer download run run_01abc123 -o ./output/
```

### Download a single artifact

```bash
stigmer download run run_01abc123 --artifact generated-agent.yaml
```

### Download a conversation's outputs

```bash
stigmer download session ses_01abc123 -o reports/
stigmer download session ses_01abc123 --artifact reports/q3.md
```

Each output is written at its place under the outputs folder. When two turns
saved the same path, the later turn's file is the one written.

### Download a file

```bash
stigmer download file file_01abc123 -o ./inputs/
```

### Download an eval

```bash
stigmer download eval support-agent-evals
stigmer download eval acme/support-agent-evals@3f1c0e9a7b2d4c6e8f0a1b3c5d7e9f1a2b4c6d8e0f1a3b5c7d9e1f2a4b6c8d0e
```

Without a suffix the current version is downloaded; `@<tag>` or `@<digest>`
names another. The archive is checked against the version's digest and unzipped
into a new or empty directory, `./<name>` unless `-o` names one.
