Configure the LLM provider for agent execution.

`stigmer setup` configures the LLM provider agents use when they run on the
local stack. Local execution runs on Anthropic Claude models, so setup comes
down to providing an Anthropic API key. Run it without flags for an interactive
prompt, or pass `--provider` (with the related flags) for a non-interactive
setup suitable for scripts and CI. Either path writes to your local
configuration, preserving every other setting.

Supported providers: `anthropic`, and `skip` to clear the configuration.

Setup checks the key with Anthropic before it saves it. A key Anthropic
rejects is refused: the interactive prompt says so and asks again (press Enter
to skip), and `--api-key` exits with code 1 and saves nothing. If Anthropic
doesn't answer, the key is saved and setup says it wasn't checked. When
`ANTHROPIC_API_KEY` is exported, setup uses it without asking and says what
Anthropic made of it. The check only lists models, so it costs nothing; a key
with no credit still passes, and the first run says so.

You don't pick a model during setup: the platform model registry selects the
default automatically, so it stays current without CLI updates. To run a
specific model, pass `--model` to [`stigmer run`](./run) — model choice is a
per-run decision, not a setup-time setting.

### Common patterns

```bash
# Interactive setup
stigmer setup

# Non-interactive: configure Anthropic
stigmer setup --provider anthropic --api-key sk-ant-xxx

# The key from your environment, through stdin: it stays out of your shell's
# history and out of a coding agent's transcript
printenv ANTHROPIC_API_KEY | stigmer setup --api-key-stdin

# Clear the LLM configuration
stigmer setup --provider skip
```

## Examples

### Interactive setup

```bash
stigmer setup
```

Prompts for your Anthropic API key. If `ANTHROPIC_API_KEY` is already set in
your environment, it is used without prompting. Press Enter to skip — agents
won't execute until a provider is configured.

### Non-interactive configuration for CI

```bash
stigmer setup --provider anthropic --api-key "$ANTHROPIC_API_KEY"
```

### Apply a new provider to a running stack

```bash
stigmer setup --provider anthropic --api-key sk-ant-xxx
stigmer down && stigmer up
```

The stack must be restarted to pick up a new LLM configuration.
