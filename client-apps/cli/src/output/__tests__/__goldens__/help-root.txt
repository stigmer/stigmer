Usage: stigmer [options] [command]

Command-line interface for Stigmer, the open-source backend for the agents in
your product

Options:
  --version        print the CLI version
  -d, --debug      enable debug output
  --standalone     ignore the config file; use flags and environment only
  --org <slug>     organization, on servers that hold several
  --api-key <key>  API key for authentication (before the command)
  -h, --help       display help for command

Run agents:
  run              run an agent by reference
  resume           resume an existing session by ID
  runs             manage run lifecycle and observability (run IDs: run_)

Your library:
  get              get a resource by type and reference (slug, org/slug, or ID)
  list             list resources of a type (or 'list types' for available
                   types)
  search           search resources by text query (supported types: agent)
  apply            apply resources from files or a plugin directory
  validate         validate resource YAML files or a plugin directory offline
  delete           delete a resource by type and reference (slug, org/slug, or
                   ID)
  tag              assign a tag to a resource version (supported types: agent)
  agent            read how an agent's runs are graded
  routine          operate on routines
  channel          operate on channels: chat links, and switching a channel on
                   or off
  vault            manage the logins and secrets your runs use (values are never
                   shown)
  file             upload files to name in conversations and routines
  connect          connect to external services and discover capabilities

Packages:
  push             push a package to the registry (supported types: skill,
                   plugin, eval)
  install          install a plugin from a source by name:
                   [source/]name[@version]
  marketplace      manage the sources the Marketplace installs from: the
                   official catalogue and the ones you add
  mcp              install an MCP server as a plugin of its own
  eval             run test cases on an agent or a plugin, with and without a
                   plugin, and score them
  download         download a run's or a session's outputs, a file, or an eval's
                   folder at a version (eval <ref>[@<digest|tag>])

Local stack:
  up               start the local Stigmer stack (server, runner, Temporal)
  down             stop the local Stigmer stack
  status           show the status of the local Stigmer stack
  logs             view logs from the local Stigmer stack
  setup            configure the LLM provider and operator identity for local
                   execution
  reset            stop the stack and remove all local state, then restart fresh
  mcp-server       start the MCP server that exposes Stigmer resources to AI
                   coding assistants

Account and access:
  auth             manage authentication with Stigmer Cloud
  apikey           manage API keys for Stigmer Cloud authentication
  service-account  manage the organization's service accounts, the accounts its
                   automation acts as
  provider-key     see which model providers serve the organization, and manage
                   its provider keys (Stigmer Cloud)
  access-history   read and export who gave whom access to what in the
                   organization (owners and admins)
  usage            view token and working-time usage reports

Configuration:
  config           manage CLI configuration
  completion       generate a shell completion script (bash, zsh, fish,
                   powershell)
  version          print the CLI version
  help             display help for command

Examples:
  stigmer up
      start the local stack
  stigmer run variance-reporter --attach ledger.csv --download ./out --until turn -m "Review this quarter's ledger."
      run an agent on a file, and get the shell back with its outputs saved
  stigmer get agent variance-reporter
      see an agent's instructions, skills and tools
