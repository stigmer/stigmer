# T07: Comprehensive HITL Test Rewrite

**Date**: March 27, 2026

## Summary

Rewrote and fixed all HITL approval tests across Go, Java, and Python to match the new architecture from T01-T06. This was the final task in the HITL approval cleanup project — all seven tasks are now complete, and `make check` passes on both stigmer and stigmer-cloud repositories.

## Problem Statement

T01-T06 changed the HITL approval architecture across 139 files (stigmer) and 69 files (stigmer-cloud), but several test files still referenced deleted types, removed fields, and old-architecture invariants. The `make check` command failed on the Go contract test compilation, and additional lint, mypy, and test failures were masked behind it.

### Pain Points

- Go `submit_approval_contract_test.go` referenced `ApprovalLifecycleState`, `InterruptId`, and flat `ToolCalls` — all deleted in T02
- Java `PendingApprovalComputer` (new in T05) had zero test coverage despite its Go counterpart having comprehensive tests
- Python lint/mypy errors in 4 files were masked by the Go compilation failure
- `test_approval_resume.py` tested `ApprovalStateManager` and `InterruptCapture` classes removed in T03
- `test_inline_publish.py` had a pre-existing mock gap where `sb.get_tool_call()` never returned prepared fixtures

## Solution

Systematic five-phase approach: audit via `make check`, rewrite Go contract tests, create Java test suite, fix all surfaced failures, verify final green run.

## Implementation Details

### Go Contract Tests (9 tests, replaced 4)

Rewrote `submit_approval_contract_test.go` to verify current architecture contracts:
- `findToolCallInExecution` correctly traverses `messages[].tool_calls` and `sub_agent_executions[].messages[].tool_calls`
- Approval decisions are recorded on `ToolCall` objects inside messages (not flat lists)
- `ComputePendingApprovals` recomputation drops decided entries immediately
- Timestamps are valid RFC3339 and sub-agent approvals are isolated from root tool calls

### Java PendingApprovalComputerTest (15 tests, new)

Created `PendingApprovalComputerTest.java` with JUnit 5 `@Nested` classes mirroring Go `compute_test.go`:
- Empty/null inputs, AI messages without tool calls
- Inclusion criteria: `WAITING_APPROVAL` + `requires_approval` + no `approval_action`
- Exclusion criteria: `RUNNING`, `COMPLETED`, action already set, `requires_approval=false`
- Sub-agent attribution: `from_sub_agent` and `sub_agent_name` fields
- Mixed root + sub-agent scenarios with correct ordering
- Field projection correctness for all `PendingApproval` fields

### Python Fixes (7 files)

- Sorted imports in 4 files (ruff I001)
- Removed unused imports (ruff F401)
- Fixed uppercase local variable (ruff N806)
- Fixed `SubAgentExecution.tool_calls` → iterate `messages[].tool_calls` (mypy attr-defined)
- Fixed `Struct` dict return type with `str()` cast (mypy assignment)
- Deleted obsolete `test_approval_resume.py` (166 lines testing removed classes)
- Fixed `test_inline_publish.py` mock to dynamically resolve tool calls
