# Fix All `make check` Failures Across Stigmer OSS and Stigmer Cloud

**Date**: May 7, 2026

## Summary

Resolved all `make check` failures across both Stigmer OSS and Stigmer Cloud repositories, fixing issues spanning Python linting, TypeScript compilation, Bazel builds, TypeDoc validation, site builds, and Python test environment setup.

## Problem Statement

Both repositories were failing `make check` due to accumulated issues from recent feature development:

### Pain Points

- Python ruff lint errors (unused variables in `chat_model.py`)
- Python mypy type errors (`discover_mcp_server.py`)
- TypeScript syntax errors (stray braces in `execute-cursor.ts`)
- `@types/react` version mismatch between root workspace and site project
- TypeDoc validation warnings treated as errors (missing JSDoc, unresolved cross-package links)
- MDX syntax error (`<7d` interpreted as JSX tag)
- Missing Bazel test target referencing non-existent source file
- Java compilation errors (visibility, constructor, dependency issues)
- Python test environment broken (protobuf v6 missing `descriptor_pb2`, stale proto stubs)

## Solution

Systematic identification and resolution of each failure, working through the dependency chain until both repositories pass their respective checks.

## Implementation Details

### Stigmer OSS Fixes

| Area | Fix |
|------|-----|
| Python lint | Prefixed unused variables with `_` in `chat_model.py` |
| Python mypy | Added `str()` cast in `discover_mcp_server.py` sorted key |
| TypeScript | Removed two stray `}` braces in `execute-cursor.ts` |
| Site types | Upgraded `@types/react` from 19.2.10 → 19.2.14 in site |
| TypeDoc | Added `typedoc.json` with `externalSymbolLinkMappings` for cross-package links |
| TypeDoc | Added JSDoc to `ModelCostEntry`, `UseSessionUsageReturn`, `SetAutoRechargeConfigInput` |
| MDX/docs | Fixed `escapeMdx()` to escape `<` before alphanumeric chars |
| Test env | Fixed `requires-python` bound, added Poetry dev group, updated Makefile to install local stubs |

### Stigmer Cloud Fixes

| Area | Fix |
|------|-----|
| Bazel | Removed dangling `agent_execution_update_usage_handler_test` target |
| Java | Made `BillingSignalResult.CONTINUE` public |
| Java | Updated `BuildUpdateStatusResponseStepTest` to use builder pattern |
| Bazel | Added `spring-security-core` dep to `proxy_scope_authorization_test` |
| Java test | Added null checks to Mockito `argThat` matchers |
| Java test | Used `lenient()` for intentionally-unused stub |
