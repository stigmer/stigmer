# Content Context

Stigmer is an open-source infrastructure platform for AI agents — think "Kubernetes for agents." Docs and sales website both target **platform builders**: developers building products who integrate Stigmer via SDKs (`@stigmer/sdk`, `@stigmer/react`, `@stigmer/theme`) to add agentic capabilities without months of custom engineering. Docs explain **how** (Diataxis: concepts, quickstarts, guides, references). The sales website explains **why** (conversion funnel: awareness → interest → evaluation → action). Both surfaces share canonical terminology from `docs/standards/terminology.json` — proto names are the canonical names (Agent, AgentExecution, McpServer, not "bot," "agent run," "tool connector"). Content is component-based: the component defines the structure, the author fills the slots, and the visual treatment is guaranteed. Every page must move the reader closer to running agents in their platform.
