# Incident postmortem

1. Summary: what happened, for how long, and who was affected.
2. Timeline in UTC, from the first signal to full recovery.
3. Root cause and contributing factors, blameless.
4. What went well and what did not.
5. Follow-up actions, each with an owner and a date.
