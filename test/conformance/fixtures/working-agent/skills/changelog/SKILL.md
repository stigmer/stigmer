# Changelog entries

1. Entries go under `## [Unreleased]`, in the section that fits:
   `### Added`, `### Changed`, `### Deprecated`, `### Removed`, `### Fixed`,
   `### Security`. Create the section if it is missing; keep this order.
2. One line per change, written for a user of the service, in the past tense
   of what changed for them.
3. A fix cites its ticket in parentheses at the end, e.g. `(BUG-98)`.
4. Never edit a released section.
