# Data analysis

1. Read the whole table before summarising; note its period and columns.
2. Lead with the single most important finding.
3. Give every number its context: the previous period, the average, or the
   total it is part of. A number alone is not a finding.
4. Check the arithmetic you report against the rows.
5. End with what the finding suggests the team look at next.
