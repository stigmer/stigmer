# Returns policy

## Standard returns

Items can be returned within 30 days of delivery if they are unused and in
their original packaging. The customer pays return shipping, and the refund
goes to the original payment method within 5 business days of the return
arriving.

## Defective items

An item that arrives defective or stops working can be returned within 90
days of delivery. Return shipping is free, and the customer chooses a refund
or a replacement.

## Final sale

Clearance items are final sale and cannot be returned, unless they are
defective.

## How to start a return

The customer opens a return from the support portal with the order number.
For a defective item, a photo or short description of the defect is
required.
