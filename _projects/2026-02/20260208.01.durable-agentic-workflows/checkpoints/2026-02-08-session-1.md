## Decisions Made

### Pattern Selection: Pattern 2 Over Pattern 1

**Decision**: Implement Pattern 2 (signal delivery to user-created LISTEN task workflows) instead of Pattern 1 (automatic workflow creation from external events).

**Rationale**:
- Pattern 1 requires webhook ingress infrastructure that doesn't exist yet
- Pattern 1 is a broader platform feature beyond MVP scope
- Pattern 2 solves the immediate race condition problem
- Pattern 1 can be layered on top of Pattern 2 in the future

### Phase Validation Strategy

**Decision**: Only PENDING and IN_PROGRESS workflow executions can receive signals.

**Rationale**:
- Terminal phases (COMPLETED, FAILED, CANCELLED, TERMINATED) should not accept signals
- Clear error semantics: `FAILED_PRECONDITION` for invalid phase
- Prevents accidental signal delivery to finished workflows
- Aligns with Temporal's lifecycle model

### No `EXECUTION_WAITING_FOR_APPROVAL` Phase

**Discovery**: The enum `EXECUTION_WAITING_FOR_APPROVAL` was assumed to exist but was not present in the generated proto enums.

**Resolution**: Used only `EXECUTION_PENDING` and `EXECUTION_IN_PROGRESS` for signalable phases, which correctly covers all non-terminal states.

## Learnings

### Polyglot Proto Stub Generation

**Discovery**: `stigmer-cloud` uses a local directory reference (`../../stigmer/apis`) in `buf.gen.java.yaml`, allowing immediate stub regeneration without pushing to BSR.

**Benefit**: Faster development iteration - no need to coordinate BSR pushes during active proto changes.

### Java Handler Registration

**Pattern**: Using `@RequestRoute` annotation on handler class provides automatic gRPC registration via `WorkflowExecutionGrpcAutoController`.

**Benefit**: No manual controller wiring needed - reduces boilerplate and registration errors.

### Proto Struct to Map Conversion

**Challenge**: Temporal expects native Java/Go types, but proto payload is `google.protobuf.Struct`.

**Solution**: 
- Go: Automatic conversion via protobuf marshaling
- Java: Custom utility methods `convertProtoStructToMap` and `convertProtoValue`
