## Decisions Made

- **10MB size limit**: Discovered server's actual `MaxRecvMsgSize` is 10MB (not the 4MB stated in proto comments). Size guard uses the real 10MB limit.
- **Symlinks skipped**: Simpler and safer than following symlinks. Each skipped symlink triggers a warning via `cliprint.PrintWarning`.
- **No temp files**: Refactored `uploadFile` → `uploadBytes` so directory zip bytes go directly to gRPC without disk round-trip.
- **Two-file split**: Zip logic in `run_attachments_zip.go` (107 lines), orchestration in `run_attachments.go` (197 lines) — both well within the 250-line guideline.
- **CLI output**: Single info line summarizing zip stats (`"Zipping directory: inputs/ (5 files, 12.3 KB -> 4.2 KB compressed)"`) plus the standard `"Uploaded inputs.zip"` success line from `uploadBytes`.

## Key Code Changes

## Learnings

- The `filepath.WalkDir` callback receives `fs.DirEntry` whose `Type()` method is based on `Lstat`, so symlinks are properly detected without following them. This is important for the skip-symlink strategy.
- `filepath.Base(".")` returns `"."` — must resolve to absolute path first via `filepath.Abs()` to get the real directory name. Handled in `processDirectory()`.
