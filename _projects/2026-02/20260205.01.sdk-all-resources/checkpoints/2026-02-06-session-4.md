## Decisions Made

### 1. Single Source of Truth Architecture
**Decision**: Make `Args *WorkflowArgs` the ONLY source for Document, Tasks, EnvSpec, Description

**Rationale**: 
- Eliminates dual-state anti-pattern identified during architectural review
- Consistent with Agent/MCPServer pattern
- User (Principal Software Architect role) explicitly rejected keeping both SDK Document/Tasks alongside Args.Document/Args.Tasks
- "Single source of truth" principle is foundational to the platform

**Alternative rejected**: Keeping both SDK fields and Args fields (creates synchronization issues)

### 2. Fail-Fast Task Conversion
**Decision**: Convert SDK Tasks to proto immediately in AddTask(), not lazily in ToProto()

**Rationale**:
- Errors surface at build time (AddTask call) rather than execution time (ToProto call)
- Better developer experience - see errors immediately
- Simplifies ToProto() to pure delegation
- Args.Tasks always contains proto types, never mixed types

**Implementation**: AddTask() panics on conversion errors (fail-fast)

### 3. Transient Builder Pattern for Tasks
**Decision**: SDK Task type is builder only, not stored in Workflow struct

**Rationale**:
- Task only needed to construct proto representation
- TaskFieldRef still works (only needs task name)
- Reduces memory footprint
- Eliminates synchronization between SDK and proto representations

## Learnings

### 1. Dual-State is an Anti-Pattern
Having both SDK structs AND Args structs creates:
- Synchronization burden
- Confusion about source of truth
- Maintenance complexity
- Violation of DDD principles (anemic models)

**Solution**: Type alias + Args as single source

### 2. Fail-Fast Improves DX
Converting at AddTask time vs ToProto time:
- Earlier error detection
- Clearer error messages (knows which task failed)
- Simpler code (no bulk conversion logic)
- Better performance (validates incrementally)

### 3. Architectural Purity Matters
User emphasized "world-class platform" standards:
- No technical debt
- No shortcuts
- Proper DDD/Clean Architecture
- Single source of truth consistently

This guidance led to the architectural refinement that eliminated the dual-state pattern.
