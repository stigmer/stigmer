## Decisions Made

1. **AD-09 v3**: `LocalPathSource` belongs in the proto, not in runner config. The runner-level approach fails for multiple concurrent CLI invocations with different project directories. Deployment-specific validation (cloud rejects local paths) is the correct pattern, matching how `GitRepoSource` rejects SSH URLs.

2. **Principle clarification**: "Invalid states should be unrepresentable" applies to schema-level structural constraints (e.g., `oneof` prevents two sources). Deployment-mode validation is a runtime concern, not a schema concern.

3. **Phase 0 unchanged**: The `WorkspaceBackend` protocol and implementations are already workspace-source-agnostic. No fixes needed.
