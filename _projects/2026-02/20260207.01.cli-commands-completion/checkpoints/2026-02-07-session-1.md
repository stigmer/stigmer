## Decisions Made

### 1. No CLI-Specific Kind Enum
**Decision**: Use `apiresourcekind.ApiResourceKind` proto enum directly instead of creating a CLI-specific kind enum.

**Rationale**: 
- Single source of truth
- Type safety with proto enum values
- Automatic sync with proto changes
- Less code duplication

### 2. Algorithmic Alias Generation
**Decision**: Generate all aliases algorithmically from proto metadata fields (Name, DisplayName, IdPrefix).

**Rationale**:
- Zero manual duplication
- Consistent patterns across all types
- Easy to maintain
- Automatically handles new types

**Example for "McpServer"**:
- From Name: mcpserver, mcp-server, mcp_server, McpServer
- From DisplayName "MCP Server": mcp, MCP
- From IdPrefix: mcp
- Plurals of all: mcpservers, mcp-servers, etc.

### 3. Case-Insensitive Lookup
**Decision**: Normalize all aliases to lowercase for registry lookup.

**Rationale**:
- Better user experience (MCP == mcp == Mcp)
- Consistent with kubectl and other CLIs
- Reduces user confusion
- Implemented via `NormalizeAlias()` helper

### 4. Light YAML Detection
**Decision**: Extract only `kind` and `apiVersion` fields, no full parsing or validation.

**Rationale**:
- Fast performance
- Minimal dependencies
- Sufficient for command routing
- Full validation happens in apply/validate commands

### 5. Multi-Document YAML Support
**Decision**: Support `---` separated YAML documents via `DetectMulti()`.

**Rationale**:
- Kubernetes-style multi-resource files
- Common pattern in infra-as-code
- Enables batch operations
- Minimal complexity addition

## Learnings

### 1. Buffer Reuse Bug in splitYAMLDocuments
**Issue**: Initially used `current.Bytes()` directly without copying, causing all documents to reference the same buffer memory.

**Fix**: Copy bytes explicitly:
```go
doc := make([]byte, current.Len())
copy(doc, current.Bytes())
docs = append(docs, doc)
```

**Lesson**: When accumulating slices from buffers, always copy if the buffer will be reused.

### 2. Proto Metadata Access
**Discovery**: `backend/libs/go/apiresource` already provides `GetKindMeta()` for accessing proto enum options.

**Learning**: Always check for existing utilities before implementing new ones. The backend had exactly what we needed.

### 3. Test Normalization
**Issue**: Initial tests expected exact case matches, but alias generation uses case-insensitive deduplication.

**Fix**: Tests should verify normalized (lowercase) forms match expectations.

**Lesson**: Test behavior should match actual usage patterns, not internal implementation details.

### 4. Alias Deduplication Strategy
**Approach**: Use lowercase normalization for deduplication during generation.

**Result**: Generates ~8-12 aliases per type, all case variations map to same TypeInfo.

**Lesson**: Simple lowercase normalization is sufficient for CLI alias matching.
