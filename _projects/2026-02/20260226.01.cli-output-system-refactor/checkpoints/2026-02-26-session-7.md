## Decisions Made

- **Error handling unified to stderr print**: Changed from `clierr.Handle()` (`os.Exit(1)`) to `fmt.Fprintf(os.Stderr)` for marshal errors in the 6 files that previously used `clierr.Handle`. Rationale: display-layer marshal errors on valid protos are unreachable, and `os.Exit(1)` from a display function is disproportionate.
- **`search/display.go` excluded**: Its YAML/JSON pattern iterates entries into arrays — not the same as single-proto marshaling. Forcing it into `DisplayProto` would over-generalize.
- **Package-level `protoMarshalOptions`**: Single var instead of recreating options in every function call.

## Learnings

- The two-layer API pattern (pure utility + convenience wrapper) works well for display code — testable internals with a fire-and-forget caller interface
- Bazel dep cleanup is important to do inline — leaving stale deps creates confusion about what a package actually depends on
- Checking each package for remaining usages of imports before removing Bazel deps prevents accidental breakage
