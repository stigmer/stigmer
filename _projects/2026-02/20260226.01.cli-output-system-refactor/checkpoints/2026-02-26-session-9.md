## Decisions Made

- **2-file split over 3-file**: Config helpers (~70 lines) stay with command definition because they're only called from `Run`. A separate `server_logs_config.go` would have been too thin.
- **Go generics for slice functions**: Using `[T proto.Message]` avoids forcing callers to convert concrete slices. Precedent in `synthesis/reader.go`.
- **`json.MarshalIndent` over manual array building**: Fixes broken indentation, simpler code. Behavioral change is an improvement.
- **Batch error over per-entry continue**: Simpler. Proto marshaling of valid gRPC responses is unreachable per Phase 4 DD#16.

## Learnings

- The manual JSON array builder in `search/display.go` (`fmt.Println("[")` + comma logic) produced broken indentation — only the first line of each entry was indented within the array. `json.MarshalIndent` over `[]json.RawMessage` is the correct approach for proto-to-JSON arrays.
