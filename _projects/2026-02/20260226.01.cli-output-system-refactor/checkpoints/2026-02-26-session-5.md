## Learnings

- `backend.NewConnection()` returns `*grpc.ClientConn`, not `grpc.ClientConnInterface`. The original code worked around this with a pre-declared interface variable + type assertion for Close(). The cleaner approach: call Close() on the concrete type directly, assign to interface field for the context struct.
