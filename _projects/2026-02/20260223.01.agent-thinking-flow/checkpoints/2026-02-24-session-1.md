## Decisions Made

- **Think tool in graphton, not agent-runner**: It's a fundamental agent reasoning capability (like loop detection), not a domain-specific tool (like publish_artifact). Defining it in graphton means every graphton-based agent gets it automatically.
- **Sub-agent inheritance confirmed**: Investigated deepagents 0.4.0 source. `SubAgentMiddleware` receives `default_tools=tools` from `create_deep_agent()`. Sub-agents inherit top-level tools by default unless they explicitly specify their own.
- **Approval policy explicit entry**: Added `"think": {"requires_approval": False}` to `PLATFORM_TOOL_DEFAULTS` even though the fallback chain would resolve to "no approval" anyway. This documents intent explicitly.
- **Native extended thinking deferred**: Anthropic's `thinking` parameter is available in `langchain-anthropic` 1.3.3 but is not currently used. It will be investigated as a separate future phase. The think tool is complementary (model-agnostic, observable, selective) not a replacement.

## Learnings

- deepagents 0.4.0 is the actual installed version (not 0.4.1 which was excluded due to packaging issues). The `SubAgentMiddleware` in 0.4.0 passes `default_tools=tools` to sub-agents, confirming tool inheritance.
- The graphton library's `.venv` has deepagents 0.2.8 (older version), but agent-runner's `.venv` has 0.4.0. The agent-runner version is what matters for production behavior.
- 11 pre-existing test failures exist in graphton's test suite (MCP loader, summarization, token counter) unrelated to this work.
- 2 pre-existing failures in `test_tool_wrappers.py` (expects 7 tools, gets 10 due to aliases added previously).
