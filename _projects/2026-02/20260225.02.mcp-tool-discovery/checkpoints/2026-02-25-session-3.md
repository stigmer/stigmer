## Decisions Made

- **CLI-side only**: Discovery stays in the CLI, not the server. Server remains lean with no MCP SDK dependency.
- **Synchronous discovery**: Blocks startup until complete so capabilities are immediately available to agents.
- **Shared library in `backend/libs/go/`**: Placed for future reusability even though currently only CLI uses it.
- **Env resolver priority**: shell env > CLI config > skip. User's existing env vars always win.
- **Best-effort per server**: `DiscoverAll` logs warnings for individual failures but doesn't abort the batch.
