## Decisions Made

- **Session-scoped path in `get_sandbox_config()`**: The config method was the right place for this logic (not execute_graphton.py) because it already constructs mode-specific config dicts, and session scoping is a natural extension
- **No directory creation in config**: `FilesystemBackend.__init__()` and intermediate consumers already handle `mkdir(parents=True, exist_ok=True)` — config should not have filesystem side effects
- **Path-traversal validation**: Added defense-in-depth validation on `session_id` (rejects `/`, `\`, `..`) even though session IDs are platform-generated UUIDs
- **Backward compatible**: `session_id=None` preserves exact previous behavior
