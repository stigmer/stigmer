## Decisions Made

1. **`reference_kind` as `ApiResourceKind` enum** — type-safe option on proto fields, not string. Lives in `field_options.proto` alongside existing field options.
2. **`protowire` for reading custom options** — robustly reads field options from unknown bytes without requiring up-to-date generated Go stubs.
3. **Singular package names** — `gen/agent/` not `gen/agents/`, matching the API resource naming.
4. **Simpler struct names** — `AgentInput` not `ApplyAgentInput`; the package provides context.
5. **Inline ResourceIdentity** — generated code emits identity fields directly (Name, Slug, Org, Visibility, Labels, Tags) instead of embedding `domains.ResourceIdentity`. Zero dependency on `internal/domains` from generated code.
6. **Hand-written code outside `gen/`** — `internal/convert/` not `gen/convert/`, since `gen/` should only contain generated code.
7. **Identity field dedup** — generator skips spec fields that collide with identity field names (e.g., McpServerSpec's `tags`).
8. **Oneof handling** — generator produces Go protobuf wrapper types (`McpServerSpec_Stdio`, `McpServerSpec_Http`) for `oneof` fields.
