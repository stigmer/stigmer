## Decisions Made

- **Enum handling**: Full pipeline approach — `proto2schema` extracts `EnumType` FQN, generator uses it for type-safe enum conversion. Not a string-only hack.
- **toProto() error propagation**: All generated `toProto()` methods return `(proto, error)`, even for types that can't currently fail (refs, leaf types). Consistency over minimalism.
- **Struct handling**: `google.protobuf.Struct` maps to `map[string]any` in input types, converted via `structpb.NewStruct()` which can fail — hence the error-returning toProto pattern.
- **UnmarshalJSON removal**: Now dead code since workflows no longer accept raw JSON strings. Removed along with `UnmarshalOptions`.
- **signal.json removal**: `SignalSpec` was incorrectly generated as a top-level resource by proto2schema (matched `--message-suffix Spec`). Removed from workflow schema root.
