## Learnings

### Documentation Patterns

1. **Mermaid Diagrams are Valuable**: Visual representations significantly improve understanding of complex flows
2. **Phase-by-Phase Documentation**: Breaking implementation into phases makes it easier to understand evolution
3. **Real Examples Matter**: Working, copy-paste examples are more valuable than abstract descriptions
4. **Metrics Tell a Story**: Line counts and file counts help understand project scope
5. **Cross-References Over Duplication**: Linking to other docs better than copying content

### Stigmer Documentation Standards

1. **Lowercase-Hyphenated Filenames**: Consistent across all platforms
2. **Clear Categorization**: Architecture vs Implementation vs Guides is intuitive
3. **Mermaid Integration**: Well-supported in markdown viewers
4. **Index Management**: Keeping docs/README.md updated is essential

### Writing Approach

1. **Grounded in Truth**: Writing from actual implementation avoids speculation
2. **Developer Audience**: Writing for 2 AM debugging mindset keeps content practical
3. **Scannable Structure**: Headers, tables, and code blocks make docs easy to navigate
4. **No Duplication**: Cross-referencing maintains single source of truth
