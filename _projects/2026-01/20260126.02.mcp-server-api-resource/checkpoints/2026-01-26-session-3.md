### 2. Fixed Codegen Tool - Major Improvement ✅
Resolved symlink issue by fixing generator to read from namespace directories.

**Problem Identified:**
- `proto2schema` generates schemas in namespaced directories: `schemas/agentic/agent/`
- `stigmer-codegen` expected flat directories: `schemas/agent/`
- Symlinks didn't work because `os.ReadDir().IsDir()` returns false for symlinks

**Solution Implemented:**
- Modified `tools/codegen/generator/main.go`
- Added namespace directory detection logic
- Created `loadResourceDir()` helper function
- Generator now automatically detects and handles both:
  - Namespace directories: `schemas/agentic/agent/`
  - Flat directories: `schemas/agent/` (backward compatibility)

**Impact:**
- No more symlinks or directory copies needed
- Clean separation between proto2schema output and codegen input
- Both tools now work seamlessly together
- Cleaned up 111 duplicate/old schema files

### 3. User Feedback Implemented ✅
Removed version parameter from mcpserverref functions per user request.

**Rationale:**
- McpServer references don't support versioning
- Version field exists in ApiResourceReference but not used for McpServer
- Keeping it simple - only slug for identification

**Before:**
```go
mcpserverref.Platform("github", "v1.0")  // version optional
```

**After:**
```go
mcpserverref.Platform("github")  // clean, simple
```

## Decisions Made

### 1. **No Version Support in McpServerRef**
- Decision: Remove version parameter from all mcpserverref functions
- Rationale: McpServer resources don't use versioning, unlike Skills
- Impact: Simpler API, less confusion

### 2. **Namespace Directory Support in Codegen**
- Decision: Make codegen read from namespace directories directly
- Rationale: Better than symlinks/copies, aligns with proto2schema output
- Impact: Cleaner build process, no manual intervention needed

### 3. **Complete SDK Package Deletion**
- Decision: Delete entire `mcpserver` package (890 lines)
- Rationale: Old inline pattern is obsolete, no backward compatibility needed
- Impact: Clean codebase, forces migration to new pattern

// Detects namespace directories automatically
if isNamespaceDir {
    // Iterate over resource directories within namespace

## Learnings

### 1. Symlinks Don't Work with os.ReadDir().IsDir()
- `entry.IsDir()` returns false for symlinks, even when pointing to directories
- `os.Stat()` is needed to follow symlinks
- Better solution: Fix the tool to read correct paths

### 2. Generated Code Should Not Be Manually Edited
- Initially tried manually updating generated files
- Proper approach: Fix schemas and regenerate
- Delete old schemas before regeneration to avoid conflicts

### 3. SDK Package Deletion is Major Breaking Change
- Deleted 890 lines from mcpserver package
- All examples and tests needed updating
- Worth it for clean architecture
