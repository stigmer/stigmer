## Decisions Made

### API Design

**Two constructor patterns** for flexibility:
```go
// Standard usage with security defaults
matcher, _ := ignore.NewWithDefaults(rootDir)

// Full control
matcher, _ := ignore.New(ignore.Options{
    RootDir:          rootDir,
    RespectGitignore: true,
    IncludeDefaults:  true,
    ExtraIgnore:      []string{"*.tmp"},
    ExtraInclude:     []string{"tests/critical.py"},
})
```

**Diagnostic capability** for debugging:
```go
result := matcher.MatchWithReason(".env", false)
// result.Ignored: true
// result.Reason: ReasonDefaultDeny
// result.Source: "defaults"
// result.Pattern: ".env"
```

### Security-First Approach

Built-in defaults prevent accidental credential leaks:
- Environment files (`.env`, `.env.*`) with exceptions for templates
- Private keys (`*.pem`, `*.key`, `*.p12`, `*.pfx`, `*.keystore`)
- Cloud credentials (`credentials.json`, `service-account*.json`, AWS config)
- Package auth files (`.npmrc`, `.pypirc`, `.docker/config.json`)

### Pattern Precedence

Implemented clear precedence model (lowest to highest priority):
1. Built-in defaults (security patterns)
2. `.gitignore` (if RespectGitignore: true)
3. `.stigmerignore` (Stigmer-specific overrides)
4. CLI --ignore patterns
5. CLI --include patterns (highest priority)

Last matching pattern wins, enabling proper override behavior.

## Learnings

### go-git Integration

The go-git library requires:
- Path as `[]string` (components), not slash-separated string
- `domain` parameter for ParsePattern (nil for root-level)
- Patterns in ascending priority order
- Returns `gitignore.NoMatch`, `gitignore.Exclude`, or `gitignore.Include`

- Dependencies added to go.mod get auto-discovered by gazelle
- Must add to MODULE.bazel `use_repo()` for visibility
- Use `# keep` comment to prevent `bazel mod tidy` from removing
- Indirect dependencies reported as warning but still work
