## Learnings

### Directory Skipping Trade-off
The directory-level skipping optimization has an important limitation:
- **Pro**: Massive performance gain (skip 10,000+ files in node_modules/ instantly)
- **Con**: Files in skipped directories can't be re-included with negation patterns
- **Mitigation**: Use more specific patterns if you need selective inclusion

### Test Coverage Insights
Integration tests revealed excellent coverage:
- Security defaults work as intended (60+ patterns protecting credentials)
- Precedence system works correctly (CLI → .stigmerignore → .gitignore → defaults)
- Edge cases handled gracefully (Unicode, symlinks, invalid patterns)
- Real-world scenarios validate practical usage
