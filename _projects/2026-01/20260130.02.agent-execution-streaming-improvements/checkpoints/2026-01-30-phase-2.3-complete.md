## Key Decisions Made

### 1. Flat Fields vs Recursive Structure
**Decision**: Add `tool_calls` and `messages` directly to SubAgentExecution (Option A)  
**Rationale**:
- Simpler to implement and query
- Consistent with existing patterns (`AgentMessage` has nested `tool_calls`)
- Avoids infinite recursion risks
- Sufficient for observability needs

### 2. Namespace Discovery Strategy
**Decision**: Lazy registration on first child event  
**Rationale**:
- LangGraph namespace contains sub-agent run_id
- Can't predict namespace format ahead of time
- Discovery via pattern matching on first event is reliable
- Graceful fallback to main agent if namespace unknown

### 3. Timing Tracking Separation
**Decision**: Separate timing dicts for main vs sub-agent messages  
**Rationale**:
- Main agent uses `_message_start_times[index]`
- Sub-agents use `_sub_agent_message_start_times[(sub_agent_id, index)]`
- Prevents index collisions between contexts
- Enables independent lifecycle tracking

### 4. Task Tool Handling
**Decision**: Don't create regular ToolCall for "task" tool  
**Rationale**:
- Task tool is internal mechanism, not user-visible tool
- Creating ToolCall would duplicate with SubAgentExecution
- Clean separation: task = SubAgentExecution, tools = ToolCall

## Technical Highlights

### Namespace-Based Routing
```python
def _get_execution_context(self, namespace: str) -> Tuple[Any, Optional[SubAgentExecution]]:
    """Route events to correct context based on namespace."""
    if not namespace:
        return self.current_status, None
    
    sub_agent_id = self._namespace_to_sub_agent_id.get(namespace)
    if sub_agent_id and sub_agent_id in self._active_sub_agents:
        sub_agent = self._active_sub_agents[sub_agent_id]
        return sub_agent, sub_agent
    
    return self.current_status, None
```

### Dynamic Namespace Discovery
```python
def _register_sub_agent_namespace(self, namespace: str) -> None:
    """Discover and register namespace -> sub-agent mapping."""
    if not namespace or namespace in self._namespace_to_sub_agent_id:
        return
    
    for sub_agent_id in self._active_sub_agents:
        if sub_agent_id in namespace:  # Pattern match
            self._namespace_to_sub_agent_id[namespace] = sub_agent_id
            break
```

## Learnings

### 1. LangGraph Namespace Format
- Root events: empty namespace `""`
- Sub-agent events: `"node_id:run_id"` format
- Pattern matching on run_id is reliable for discovery
- Namespace structure enables hierarchical routing

### 2. Proto Backward Compatibility
- `repeated` fields default to empty lists
- No breaking changes for existing clients
- Clients can ignore new fields if not used
- Proto3 defaults (empty list) work perfectly as "unset"

### 3. Test-First Pays Off
- Wrote comprehensive tests before implementation
- Tests guided design decisions (e.g., cleanup on completion)
- Edge cases discovered early (unknown namespace, multiple sub-agents)
- High confidence in correctness (302 tests passing)

### 4. Structured Logging is Essential
- `[SUBAGENT]` prefix makes debugging trivial
- Namespace logging shows routing decisions
- Duration tracking provides performance insights
- Production observability designed in from start
