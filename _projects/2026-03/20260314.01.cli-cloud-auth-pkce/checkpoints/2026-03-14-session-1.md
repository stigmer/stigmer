## Decisions Made

- **Skip custom PKCE package**: `golang.org/x/oauth2` v0.34.0 already provides `GenerateVerifier()`, `S256ChallengeOption()`, and `VerifierOption()`. No reason to duplicate.
- **Flat package structure**: Used `internal/cli/auth/` with well-named files (`config.go`, `login.go`, `whoami.go`) instead of nested sub-packages. Aligns with OSS CLI coding guidelines.
- **Hardcoded Auth0 endpoints**: Auth0 endpoints are stable and well-known. Avoids extra `go-oidc` dependency and network call at login time.
- **Standalone gRPC connection for WhoAmI**: `FetchIdentity()` creates its own temp gRPC connection with explicit bearer token auth. Keeps Task 1 independent of Task 3 (backend.Client auth wiring).

## Learnings

- The OSS CLI uses `clioutput` (structured renderer with format flags) while cloud CLI uses `cliprint` (simpler table printing). Pattern matters for consistency.
- `clierr.Handle(err)` calls `os.Exit(1)` — `return` after it is unreachable but kept for readability (established codebase convention).
- `golang.org/x/oauth2` was already an indirect dependency at v0.34.0. Promoting it to direct required only a `go mod tidy`.
