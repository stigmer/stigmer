## Decisions Made

- **404 handling pattern**: NOT_FOUND errors are mapped to `null` resource without raising an error, using `isNotFound()` from `@stigmer/sdk`. This makes "not found" a valid state rather than an error state. Consumers distinguish not-found from loading via: `resource === null && !isLoading && !error`.
- **Hook signature**: All hooks take `org: string | null, slug: string | null` as separate parameters (not a `ResourceRef` object). This keeps the API simple for the most common use case (route params) while supporting skip-fetch via `null`.
- **Pattern alignment**: Followed the exact `useDefaultAgent`/`useAgentInstance` pattern — `useState` + `useEffect` with `cancelled` ref for cleanup, `fetchKey` counter for `refetch()`.
