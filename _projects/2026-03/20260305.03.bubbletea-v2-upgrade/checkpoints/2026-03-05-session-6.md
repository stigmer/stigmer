## Decisions Made

- **`filepath` import NOT unused**: Audit flagged `render_compact.go` filepath import as unused, but verification showed 6 active call sites. Cancelled that cleanup item.
- **Keep `promptApprovalViaKeyReader`**: Rather than remove, documented its test-only reachability. Removal would require test infrastructure overhaul.
- **`statusPending` removed**: Zero value of `phaseStatus` is now meaningless (iota starts at 1 for `statusActive`), which is correct because new phases are always set via `SetPhase` (which sets `statusActive`) or `CompletePhase` (which sets `statusComplete`).
