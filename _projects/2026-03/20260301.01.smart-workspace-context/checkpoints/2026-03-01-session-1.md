## Decisions Made

- **Exclude `build` from skip list**: Go projects use `build/` for legitimate source code (Dockerfiles, CI scripts). Skipping it universally would hide real code.

- **T04 is a safety net, not the long-term solution**: The hardcoded list is a minimal fallback for non-git and incomplete-gitignore workspaces. T02 (.gitignore awareness via `pathspec` or `git ls-files`) will be the comprehensive solution.

- **Line-range filtering in tool-wrapper layer**: Keeps the `FilesystemBackend` and `DaytonaBackend` interfaces unchanged. The backend reads the full file; `_apply_line_range()` slices lines and prepends a position header.

- **Two skip-dir constants stay separate**: `_SKIP_DIR_NAMES` (graphton library) and `_TREE_SKIP_DIRS` (agent-runner service) remain independent but aligned. Cross-reference comments signal the coupling.
