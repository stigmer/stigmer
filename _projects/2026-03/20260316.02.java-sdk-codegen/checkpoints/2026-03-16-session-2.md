## Decisions Made

- **BlockingStub**: Chose `BlockingStub` over `BlockingV2Stub` — unchecked `StatusRuntimeException` aligns with our unchecked `StigmerException` pattern and avoids forcing `throws` declarations
- **Unchecked Exception**: `StigmerException extends RuntimeException` — follows AWS SDK v2 and Google Cloud Client Libraries pattern
- **Generic Stream**: Single `StigmerStream<T>` class instead of per-resource stream types — cleaner, leverages Java generics
- **ProtoConvert utility**: Separate utility class for `Map<String, Object>` to `Struct` conversion instead of inlining
- **Package-private constructors**: Resource client constructors are package-private; only `GeneratedClient` instantiates them
- **Package-private toProto**: `toProto()` is package-private since both client and input live in the same `gen` package

## Learnings

- Java protobuf map fields use `putAllXxx()` not `setXxx()` — easy to miss when translating from Go patterns
- Case ordering in Go switch statements matters — `string || bytes` before `string && enumType` makes the enum case unreachable
- Java protobuf handles oneof transparently via regular setters — no wrapper types needed (unlike Go protobuf)
- `java.lang.*` types don't need imports — import set should filter these out
