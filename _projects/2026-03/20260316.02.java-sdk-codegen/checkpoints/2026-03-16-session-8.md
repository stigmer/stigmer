## Decisions Made

- **Release profile (`-P release`)**: Keeps signing/publishing plugins out of development builds
- **Stubs published as separate artifact**: Matches Python (`stigmer-protos`) and TypeScript (`@stigmer/protos`) patterns
- **Local stubs install in SDK job**: Avoids race condition with Maven Central propagation delay
- **`ai.stigmer` namespace**: Verified via DNS TXT record after migrating DNS from GoDaddy to Cloudflare
- **GPG key without passphrase**: Simplifies CI; key stored as GitHub Secret

## Learnings

- Maven Central's `central-publishing-maven-plugin` (0.9.0) replaces the deprecated `nexus-staging-maven-plugin`
- `actions/setup-java@v4` handles GPG key import and `settings.xml` credential wiring automatically
- `maven-source-plugin` should use `jar-no-fork` (not `jar`) to avoid re-executing the lifecycle
- DNS TXT verification keys from Maven Central are short alphanumeric strings, not long UUIDs
