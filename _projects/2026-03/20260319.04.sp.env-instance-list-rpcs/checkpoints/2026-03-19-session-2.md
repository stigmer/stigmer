## Decisions Made

1. **Secret redaction in lists**: Created `RedactSecrets` inner class rather than reusing `RedactSecretValues` step. The existing step operates on `ContextBase<?, Environment>` (single resource context), which is incompatible with `CustomOperationContextV2<ListEnvironmentsRequest, EnvironmentList>`. The inner class references `RedactSecretValues.REDACTED_MARKER` to avoid duplicating the constant.

2. **Label key dot escaping**: Label keys like `stigmer.ai/personal` contain dots that MongoDB interprets as path separators. Applied `key.replace(".", "\\.")` following the established pattern in `AgentRepo.findDefault()`.

3. **Pagination**: PageInfo (num, size) with defaults of page size 20 and max 100. Sort by `status.audit.specAudit.createdAt` DESC. Response uses `total_count` (from `Page.getTotalElements()`) not `total_pages`.

4. **Handler pattern**: Followed `SessionListHandler` pattern exactly — inner static `@Component` classes for `QueryAuthorizedIds` and `LoadFromRepo`, with `Context.Key<List<String>>` for passing authorized IDs between steps.
