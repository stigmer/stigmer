## Decisions Made

1. **CSS Grid + Flexbox layout** -- Grid for vertical stacking (48px header + body), Flexbox for horizontal panels (sidebar + main + context). Cleaner and more maintainable than the old fixed-position + margin-offset approach, especially with three panels.

2. **Sidebar: toggle visibility, not icon rail** -- The old sidebar collapsed to a 60px icon rail with navigation icons. In the session-first UX, sidebar holds "New Session" + session titles. Sessions don't have meaningful icons, so toggle visibility (like Claude/ChatGPT) is the right pattern. Jakob's Law: users already have this muscle memory from chat UIs.

3. **Header: 48px (down from 56px)** -- Maximizes content area for the conversation thread. Matches contemporary chat UI headers.

4. **ThemePresetSelector deferred** -- The old header had dark/light toggle AND preset selector. Two theme controls in the header violates Hick's Law. Only dark/light toggle for now; presets move to a future settings page.

5. **Context panel: closed by default, toggle hidden in T01.4** -- No content until T01.6. Showing a toggle for an empty panel violates Nielsen's "Visibility of System Status." Panel state is session-scoped (not persisted to localStorage).

6. **Sub-components recovered from git** -- OrgSwitcher, ThemeToggle, UserMenu were clean components deleted in T01.3. Recovered from `10513ce1^` and placed as-is. Lower risk than rewriting.

7. **`@base-ui/react` Button lacks `asChild`** -- Discovered during build that the Button component (using `@base-ui/react`) doesn't support `asChild` like Radix. Used `buttonVariants` + `cn` to style the `<Link>` directly instead.

8. **No embeddable components in T01.4** -- All components are Console-specific application scaffolding. Embeddable surface starts at T01.6 (execution metadata) and T01.7 (session list).

## Learnings

- `@base-ui/react`'s Button primitive does not support Radix-style `asChild` composition. For rendering links styled as buttons, use `buttonVariants` from CVA directly on the `<Link>` element.
- Inline `top` style on a static-positioned element is inert, but activates when `position: fixed` is applied via responsive Tailwind classes (`max-lg:fixed`). This is a clean way to handle conditional fixed positioning without JS viewport checks.
- `motion-reduce:transition-none` respects `prefers-reduced-motion` for all panel transitions.
