## Decisions Made

- **Embed credentials in binary (Option 1)**: Adopted the gh CLI pattern. The client_secret for a localhost-only OAuth App has limited attack surface. Env vars always take precedence for enterprise overrides.
- **Device Flow disabled**: The current implementation uses web application flow only. Device Flow can be enabled later if CLI-to-GitHub auth is needed.
- **Separate OAuth Apps for Local vs Cloud**: Different callback URLs require separate apps. Local app credentials are embedded in the binary; Cloud app credentials are managed as deployment secrets.
