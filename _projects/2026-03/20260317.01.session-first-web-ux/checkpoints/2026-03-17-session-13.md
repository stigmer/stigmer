## Decisions Made

- **No path restrictions**: Industry standard for local tools. Security from `127.0.0.1` binding + OS permissions.
- **Plain `fetch` for local utility**: Not a domain resource, no proto/gRPC needed.
- **`FolderBrowser` in SDK**: Reusable by platform builders, follows `GitHubRepoPicker` pattern.
- **CWD as default start**: Better than home — users launch `stigmer` near their projects.
- **`enableFolderBrowser` opt-in**: Default `false` preserves backward compatibility.

## Learnings

- Browser security sandbox prevents `window.showDirectoryPicker()` from exposing actual filesystem paths — it only gives sandboxed handles. Backend endpoint is the only option for getting real paths.
- `http.ServeMux` wrapping is transparent to callers since `NewSPAHandler()` already returns `http.Handler`.
