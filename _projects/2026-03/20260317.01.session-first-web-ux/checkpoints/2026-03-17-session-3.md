## Decisions Made
- **Platform-level default agent**: The default assistant is a global singleton in the `stigmer` org with `visibility_public`, not a per-org resource. This was a key design shift from the initial assumption of org-scoped defaults.
- **Label queries as first-class store methods**: Go `store.Store` got explicit `FindByLabel`/`FindAllByLabel` rather than extending `FindByField`, because label keys contain dots (`stigmer.ai/default-agent`) that conflict with the existing dot-notation field path parsing.
- **Session ownership follows the caller**: When using a cross-org public agent, sessions are created in the caller's org (not the agent's org). This is architecturally significant for multi-tenancy.
- **Default instance stays shared**: The default agent instance remains in the `stigmer` org as a shared resource. No per-org instance duplication.
- **Cloud seedpack gap accepted**: Cloud mode doesn't bootstrap seedpack, so the resolution will fail gracefully with a clear error if the default agent isn't provisioned.
