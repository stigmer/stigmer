## Decisions Made

- **Headerless layout**: Removed the 48px header entirely. Sidebar owns all navigation and controls — brand identity, org context, recents, and user/settings. Main content gets full viewport height. This matches the Claude Cowork pattern and maximizes content area.
- **Appearance as submenu**: Theme switching (Light/Dark/System) moved from a standalone three-button widget into an "Appearance" submenu inside the user dropdown, matching Cursor's interaction pattern. Reduced surface area — one less always-visible control.
- **`border-foreground/10` over theme tokens**: The `--stgm-sidebar-border` token resolves to `oklch(0.922 0 0)` in light mode — nearly identical to the sidebar background (`oklch(0.985 0 0)`). Using `border-foreground/10` (10% opacity of the foreground color) guarantees visibility in both light and dark themes without modifying the theme token system.
- **DropdownMenu for OrgSwitcher**: Native `<select>` had limited clickable area and inconsistent interaction with the rest of the UI. Replaced with DropdownMenu + RadioGroup for consistent behavior — entire row is clickable, active org shown with checkmark, same hover/focus patterns as UserMenu.
- **Desktop-collapsible sidebar**: Previously, sidebar was always visible on desktop (lg:w-70). Now it collapses on all screen sizes. A floating PanelLeft button appears when collapsed. Sidebar's internal toggle button calls `sidebar.close()`.
- **Logo removed**: The "S" badge + "Stigmer" text was removed from the sidebar top in favor of the org context (OrgSwitcher) which is more actionable. Brand identity can be expressed through the favicon and page title.

## Learnings

- The `--stgm-sidebar-border` token in the default theme has near-zero contrast against the sidebar background in light mode. Using foreground with alpha is a reliable cross-theme border strategy when dedicated border tokens lack sufficient contrast.
- Native `<select>` elements with `appearance-none` and icon overlays create inconsistent clickable areas across browsers. DropdownMenu is always preferable for custom-styled selection UIs.
- Moving controls from a header into the sidebar bottom creates a natural reading flow: navigation at top, content in middle, meta-controls at bottom. This is the pattern used by Claude, Cursor, and Linear.
