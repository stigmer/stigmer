## Decisions Made

1. **`platform` bounded context** — GitHub OAuth goes under `apis/ai/stigmer/platform/github/v1/`, establishing a new context for platform-level utilities.
2. **Hand-written TypeScript client** — The codegen only handles CRUD resources. Non-resource services (Search, GitHub) are hand-written, like `SearchClient`.
3. **localStorage for tokens** — Key `stigmer:github:token`. Persists across refreshes. Not stored in any backend database.
4. **sessionStorage for CSRF state** — OAuth state parameter stored in sessionStorage (cleared on tab close).
5. **SPA handler `.html` fallback** — Added before dynamic route resolution to serve Next.js static export pages like `/auth/github/callback`.
6. **GitHub App registration deferred** — Implementation is code-complete but requires manual GitHub App registration to function end-to-end.
