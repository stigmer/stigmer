## Learnings

- **MagicMock defeats `getattr` defaults**: `getattr(MagicMock(), "attr", None)` returns a MagicMock, not `None`, because MagicMock auto-creates attributes on access. This is a common footgun when production code uses defensive `getattr` patterns. The fix is to explicitly set the attribute to `None` on the mock.
- **Root cause analysis pays off**: What appeared to be 5+ separate failure categories (is_streaming, token_count, generation_duration_ms, usage metrics, internal field assertions) all traced back to a single root cause (MagicMock auto-attribute defeating cache token extraction). Investigating the `TypeError` at line 1278 before fixing individual tests saved significant time.
- **Task file estimates can be inaccurate**: The task file listed "12 tests in TestUsageMetrics" but the actual scope was 10 tests across 4 classes. Always run the test suite first to establish the true baseline.
