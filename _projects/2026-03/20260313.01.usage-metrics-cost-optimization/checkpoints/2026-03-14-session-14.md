## Decisions Made

- **Both `"read"` and `"read_file"` in filter set**: The canonical name is `"read"` (covers 99%+ of calls), but the `"read_file"` alias exists and could theoretically fire — including both ensures completeness with zero risk.
- **`completed_at` stamped on all exit paths**: Even for pause (which may resume later), stamping `completed_at` as the pause time is correct — resumed executions get a fresh activity invocation with their own `started_at`. Session-level aggregation sums across executions.
- **Same two-line pattern everywhere**: Reused the exact `if not completed_at` + `finalize_usage()` pattern from the happy path for consistency and auditability.

## Key Code Changes

- `test_status_builder.py`: 6 new tests in `TestReadOnlyToolFiltering` and `TestFinalizeUsage` classes

## Learnings

- Tool name aliasing requires the filter mechanism to track both canonical and alias names — the event stream reports whichever name the LLM called
- Production observation (the 22,142-line `data.yaml`) was the most effective way to discover the filtering bug — the code looked correct in isolation
