## Decisions Made

- **5-minute ephemeral TTL pricing**: Anthropic offers two cache creation prices (5-min at 1.25x input, 1-hour at 2.0x input). We store 5-minute pricing as default since that's what `cache_control: {"type": "ephemeral"}` uses, which is the standard pattern Phase 4 will implement.
- **Explicit per-model prices over derived multipliers**: Each model entry stores its own `cache_creation_price_per_million` and `cache_read_price_per_million` values rather than deriving from provider rules. Self-documenting and allows for model-specific pricing exceptions.
- **Unit alignment with proto**: Renamed Python fields to match proto `ModelUsage` field names exactly. `ModelMetadata.input_price_per_million` maps to `ModelUsage.input_price_per_million` — zero conversion, zero bugs.

## Learnings

- Anthropic has two cache creation price tiers (5-minute and 1-hour TTL) with different write costs. The T01 plan only assumed one tier. The 5-minute ephemeral tier is the standard for agentic use cases.
- OpenAI prompt caching is automatic (no client-side opt-in) with 50% discount on cached tokens. No cache creation premium.
- The `input_cost_per_1k` naming was a footgun — the actual values matched per-million pricing perfectly. Fixing this now prevents conversion bugs in Phase 3.
