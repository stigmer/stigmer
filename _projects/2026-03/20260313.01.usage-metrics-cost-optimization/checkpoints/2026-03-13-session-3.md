## Decisions Made

- **UsageTracker extraction over inline growth**: Rather than adding cost logic to the 3,200-line StatusBuilder, extracted a dedicated class. StatusBuilder delegates via `self._usage_tracker`.
- **Scope-based isolation**: Single tracker serves all scopes (main + sub-agents) keyed by string, replacing 4 parallel dict structures.
- **Pricing stamped at call time**: `record_llm_call()` resolves pricing and computes cost immediately. `build_usage_metrics()` is a pure aggregation.
- **LangChain `input_tokens` = total input**: After investigation, confirmed `input_tokens` includes cached portions. Regular input computed as `input_tokens - cache_creation - cache_read`.
- **Proto import migration**: Fixed production files to unblock Phase 3 tests. Deferred remaining test import fixes as a separate cleanup task to keep Phase 3 scope clean.

## Learnings

- LangChain standardizes cache token fields across providers via `input_token_details`, but `input_tokens` semantics (total vs non-cached) required source code verification — documentation was ambiguous
- Proto file splits (Phase 1) silently break Python imports when stubs are regenerated — the generated `_pb2.py` modules don't re-export from the parent
- Summarization LLM calls via LangMem are completely opaque without a callback handler — there's no return value or logging of token usage
