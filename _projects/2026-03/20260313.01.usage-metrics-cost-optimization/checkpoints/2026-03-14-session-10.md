## Decisions Made

- **Compact panel display**: Model and Cost lines added to EXECUTION COMPLETE panel, not a separate usage section. Detailed breakdowns reserved for `stigmer usage session`.
- **Core Commands group**: `usage` placed alongside `run` and `resume` — it's a primary workflow command.
- **Renamed output helpers**: `writeReportJSON`/`writeReportYAML` instead of `renderJSON`/`renderYAML` to avoid collision with the streaming JSON renderer in `run_stream_json.go`.
- **No new packages**: All code in the existing `root` package. Extraction is trivial if needed later.

## Key Code Changes

- `usage_format.go`: 12 pure helpers — formatCost (sub-cent precision < $1), formatCacheHitRate, formatModelLabel, formatDurationBreakdown, formatCostLine, formatDate, formatDateRange, formatShare, formatMillis, formatTokensCompact, writeReportJSON, writeReportYAML
- `run_display_summary.go`: Model line before Tokens, Cost line after Tokens; session exit line shows `(duration · $cost)`
- `usage.go`: Parent command, no Run func, groups session/agent/org
- `usage_session.go`: Single session-id arg, model breakdown table + execution table
- `usage_agent.go`: Agent-id arg + optional --from/--to, summary stats + model + session tables
- `usage_org.go`: Required --from/--to + optional --org, summary + model + top agents + daily trend tables

## Learnings

- The `root` package already has a `renderJSON` function in `run_stream_json.go` with a very different signature (streaming context). Naming needs care in a large flat package.
- Bazel build has a pre-existing failure (`com_github_pmezard_go_difflib` missing) unrelated to our changes. `go build` and `go test` work fine directly.
