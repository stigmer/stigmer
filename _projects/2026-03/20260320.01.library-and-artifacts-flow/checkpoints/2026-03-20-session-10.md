## Decisions Made

- **Console composition over SDK wrapper**: Chose not to build an `AgentListView` SDK component. The plan routing table referenced it, but the task breakdown specified direct composition. Building a pre-composed wrapper now would be speculative — the SDK building blocks (`useAgentList`, `ResourceListView`) are already available for platform builders who want full control. A zero-config wrapper can be extracted later with real usage to guide API design.
- **No row click for Phase 1**: Rows are informational only. Detail pages are Phase 5 scope. `onItemClick` is intentionally not provided.
- **No custom row renderer for Phase 1**: `SearchResult` lacks agent-specific metadata (version, MCP/skill dependency counts). Default `DefaultResourceRow` is sufficient and already renders the correct icon via `KindIcon`.
