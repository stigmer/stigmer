## Decisions Made

- **Console placement (not SDK)**: URL generation is tied to Console routes; system-agent mapping is a Console UX decision. Platform builders use SDK hooks directly with their own routing.
- **`src/utils/` over `src/lib/`**: `.gitignore` has a `lib/` pattern (Python build artifact) that silently ignores any `lib/` directory at any depth. Relocated to `src/utils/` — works naturally, no gitignore modification needed.

## Key Code Changes

## Learnings

- The repo `.gitignore` has broad patterns from Python tooling (`lib/`, `lib64/`, `eggs/`, etc.) that can collide with common TypeScript directory conventions. Always verify new directories against `.gitignore` before committing.
