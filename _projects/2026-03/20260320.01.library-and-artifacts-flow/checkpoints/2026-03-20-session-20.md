## Decisions Made

- **DD-008: Modal-only Apply (review-before-apply)**: The Apply/Push CTA was removed from ArtifactCard and lives exclusively in ArtifactPreviewModal. Rationale:
  1. Eliminates applied-state sync problem — card and modal had independent useApplyResource hooks with no shared state, creating a UX desync where the card would show "Apply" after the user already applied via modal
  2. Enforces review-before-apply — applying a resource is consequential (creates/overwrites), user should see YAML content first
  3. Simplifies the card — fewer hooks (dropped useApplyResource, useState, useCallback), fewer props (dropped isTerminal, onApplied)
  4. Progressive disclosure — summary in card, action in modal (Hick's Law)
  5. Better SDK component — platform builders embedding ArtifactCard get a simpler, more predictable component

## Learnings

- When two components (card and modal) both manage the same action independently, state sync is inevitable — better to assign the action to one component only
- The "self-contained component" pattern from ApprovalCard works well for single-instance components but breaks down when the same artifact appears in both a card and a modal simultaneously
