## Decisions Made

- **Domain-specific over generic**: Built `ScopeToggle` as a focused domain component rather than a generic `SegmentedControl<T>`. Rationale: no concrete second use case, premature abstraction adds API surface, extraction is straightforward later if needed.
- **Hardcoded labels "Org" / "All"**: Domain vocabulary terms from the ubiquitous language. Optional `orgLabel`/`allLabel` props can be added as a non-breaking change if platform builders need customization.
- **WAI-ARIA Radio Group pattern**: Chosen over `role="tablist"` (implies tab panels) and `aria-pressed` toggle buttons (implies independent toggles). Radio group is the correct semantic for mutually exclusive choices in a compact control.
