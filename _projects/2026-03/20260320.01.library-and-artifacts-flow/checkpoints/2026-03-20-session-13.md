## Decisions Made

- **Backend proxy for content reading**: Artifact content is fetched via `getArtifactContent` RPC (server reads from R2), not via direct browser fetch to R2 URLs. This eliminates CORS dependency for SDK consumers. Direct R2 pre-signed URLs remain available for file downloads.
- **Layered hook decomposition**: Instead of a single "God hook", artifacts are accessed through three composable layers: `useExecutionArtifacts` (derivation from execution) → `useArtifactContent` (single artifact fetch) → `useDetectStigmerResource` (YAML detection, T02.2).
- **No client-side size guard**: The hook calls the server unconditionally — size enforcement is the server's responsibility (`max_bytes` with 512KB default). Callers use `isTextArtifact()` and artifact size to decide whether to invoke.
- **Error as string**: `useArtifactContent` returns `error: string | null` to match `useResourceList` pattern.
