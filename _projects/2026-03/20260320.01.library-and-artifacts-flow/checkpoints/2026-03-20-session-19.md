## Decisions Made

- **Native `<dialog>` over `@base-ui/react/dialog`**: `@base-ui/react` is an optional peer dep of `@stigmer/react`. SDK components cannot require it. Native `<dialog>` gives built-in focus trap, top-layer rendering, Escape handling, and zero z-index conflicts with host apps.
- **CSS-only YAML highlighting**: Regex-based line parser wraps tokens in `<span>` with semantic classes (`text-primary` for keys, `text-muted-foreground italic` for comments). Covers 90% of YAML readability at negligible bundle cost.
- **Deterministic skeleton widths**: Predefined width array replaces `Math.random()` to avoid hydration mismatches.
- **Self-contained apply state**: Modal manages its own `useApplyResource` instance. `onApplied` callback enables parent orchestration. `ArtifactsWidget` (T02.6) will coordinate applied state between card and modal.

## Learnings

- Native `<dialog>` handles backdrop clicks via `::backdrop` pseudo-element but the spec doesn't provide a built-in backdrop click handler. For this component, Escape + close button was sufficient — no need for backdrop click dismissal.
- `highlightYaml` approach scales well for YAML-specific highlighting but would not generalize to other languages. Acceptable trade-off since YAML is the only format Stigmer resource definitions use.
