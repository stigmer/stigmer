## Decisions Made

- **Reuse, don't reinvent**: Inner tools render with existing compact renderers; the inline renderer adds `GutterWrap` instead of building parallel sub-agent renderers. This maintains rendering consistency and avoids a second-class sub-agent experience.
- **Task tool events suppressed**: Backend emits redundant ToolRunning/ToolCompleted for the "task" tool alongside SubAgentStarted/Completed lifecycle events. We suppress the tool events and use lifecycle events which carry richer data (Description, ToolCount, Status).
- **Sub-agent AI on stderr, non-streaming**: Sub-agent reasoning is intermediate processing, not the final response. AIStreamStart/Delta suppressed; full content emitted on AIStreamEnd/AIMessage with gutter prefix to stderr. This preserves `stdout = main agent data` contract.
- **Read grouping preserved in sub-agent context**: `pendingReads` tagged with `subAgentID`. Flush logic applies `GutterWrap` when the ID is non-empty. Grouping threshold (3+) works identically to top-level.
- **Always expanded in inline mode**: Collapse/expand requires raw terminal cursor control (Phases 3-4). Phase 2.5 builds the gutter structure that a future collapse/expand layer operates on.
- **Flush reads before task suppression**: Top-level reads might be buffered when task tool running event arrives. Both task tool interceptions call `flushPendingReads()` before returning to avoid orphaning reads.
- **`BulletGreen` / `LabelBold` thin wrappers**: Exposed for the inline renderer's sub-agent lifecycle handlers which construct headers from SubAgentStartedEvent, not ToolCallInfo. Avoids leaking lipgloss types across package boundaries.

## Learnings

- Lipgloss strips ANSI codes in non-TTY test environments. Tests should assert content/structure, not styling presence. All existing tests follow this pattern.
- The `pendingRead` wrapper is a minimal but important structural change — tagging reads with sub-agent context enables gutter-wrapping on flush without changing the buffering invariant (all pending reads share the same agent context).
