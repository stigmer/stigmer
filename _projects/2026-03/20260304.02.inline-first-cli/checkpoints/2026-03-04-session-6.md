## Design Decisions

- **No exit code**: `ToolCallInfo` has no `ExitCode` field. Parsing from result strings is fragile (coupled to backend text format). Claude Code reference doesn't show exit codes. User confirmed Option A: status via structure (output = success, `✗` = failed).
- **Command truncation (60 chars)**: Shell commands can be very long. Header truncation keeps output scannable; full command is visible from the AI message in scrollback.
- **`firstLine` helper**: Defensive sanitization for commands with embedded newlines. Prevents multi-line headers.
- **Smart cutoff**: Show all when count <= maxShellOutputLines + 1 (avoids "+1 more lines" footer). Same pattern as read groups.
- **No inline renderer changes**: `renderToolRunning` and `renderToolCompleted` already route through `RenderCompactRunning` and `RenderCompact`. Shell gets compact format automatically by registering in `hasCompactRenderer`.
