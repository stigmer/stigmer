## Decisions Made

- **Type-assert over interface change**: `promptForDecision` type-asserts to `*InlinePrompter` for `PromptWithLineCount` instead of widening the `Prompter` interface. Falls back gracefully with lineCount=0 (no collapse).
- **renderToolWaitingApproval becomes silent**: Saves state only, all visual output deferred to `handleApproval` which needs full line counting for cursor collapse.
- **Selective suppression**: Write/edit/create/delete completions suppressed (summary shown in collapsed result). Shell completions kept (output arrives only via completion event until Phase 3.4 streaming).
- **Pre-switch interception ordering**: Approval suppression → read grouping → task tool suppression → main switch.
- **render_approval.go at 328 lines**: Assessed as acceptable — functions are thematically cohesive (all approval rendering). Further splitting would over-engineer.

## Learnings

- Go's flat test package structure means all `*_test.go` files in a directory share a namespace. Helper types like `mockPrompter` and `stripANSI` need unique names when split across files.
- Send-only channels (`chan<-`) in struct fields can't be read from in tests — tests must retain a reference to the bidirectional channel for reading.
- Pre-existing test failures (from Phases 2.1, 2.5 behavior changes) were already committed but tests not updated — noted as out of scope.
