## Decisions Made

- **TUI alt-screen removed entirely** — Git history preserves it. The shared event system (`events.go`, `followup.go`) remains as the contract between stream producers and rendering consumers.
- **`RenderResultWithPreview` kept** — Confirmed alive in `run_display_stream.go` (workflow rendering path), correcting the plan's assumption that it was TUI-only.
- **`display.GetTerminalWidth()` not migrated** — Both callers write to stdout, and the `MinTermWidth` clamp has different semantics than `termctl.Width`. Internal use by `tablerender.go` would require a new cross-package dependency.
- **Switch pattern: inline as default** — `default:` branch now routes to inline, `case OutputJSON:` is explicit. Matches `resolveOutputMode` behavior.

## Learnings

- `OutputInteractive` was first in the iota, so removing it shifted `OutputInline` from 1 to 0 and `OutputJSON` from 2 to 1. This is safe because the constants are only compared by name, never serialized.
- `followup.go` contained both shared types (`FollowUpFn`, `FollowUpResult`) and TUI-specific `Model` methods. Required careful extraction rather than whole-file deletion.
- 3 pre-existing inline renderer test failures confirmed via `git stash` isolation — identical before and after changes.
