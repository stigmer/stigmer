## Decisions Made

- **`IsSupported` does NOT check `NO_COLOR`**: Cursor control is UX (collapse content after approval), not color decoration. The NO_COLOR spec targets color codes specifically. Users who disable color still benefit from cursor-controlled content management. Only checks TTY + TERM!=dumb.
- **Free functions over struct**: Stateless, DI-compliant. Every function takes `io.Writer` or pure parameters. A convenience struct can be added later if Phase 3.2-3.3 call sites become noisy.
- **New package, not an extension**: `display/` is stdout-hardcoded formatting. `spinner/` has private helpers. `termctl` has a distinct concern (cursor control for content erasure) and deserves its own package.
- **`EraseLines` atomic writes**: Single `Write` call for the full ANSI sequence prevents interleaving.
- **`DisplayRows` delegates to `charmbracelet/x/ansi`**: Already a dependency, handles CSI + OSC 8 + Unicode correctly.

## Learnings

- ANSI spec treats `\033[0A` as "move up 1" (parameter 0 defaults to 1). Must guard `MoveUp` with n<=0 check to prevent accidental displacement.
- Trailing newline in `DisplayRows` does not add a row — it merely advances the cursor. Important for accurate line counting in Phase 3.3's collapse flow.
