## Decisions Made

- **Internal package via path alias** (not npm workspace, not published) — segregates responsibilities without over-engineering. The `packages/` directory is physically separate from `src/` (app code), making the boundary visible in the file tree.
- **Barrel-only imports** — consumers import from `@docs-kit`, never from `@docs-kit/components/...`. This keeps the internal structure refactorable.
- **Fumadocs re-exports through docs-kit** — centralizes all doc component registration into one import source, reducing scatter in `page.tsx`.
- **Server components by default** — only `Mermaid` has `"use client"` (needs browser APIs for mermaid.js).
