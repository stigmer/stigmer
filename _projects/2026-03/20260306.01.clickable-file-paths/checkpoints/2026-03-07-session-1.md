## Decisions Made

- **Keep `file://` URIs**: Rejected editor-specific URI schemes as they introduce new dependencies and require users to install specific tools. Generic `file://` is the right abstraction.
- **Resolution priority order**: `.stigmer/` prefix > workspace roots > sandbox root. This ensures local paths (resolved via workspace roots) take priority over sandbox symlinks.
- **No editor detection in CLI**: The terminal/OS determines which app opens `file://` URIs. This is consistent with how other tools (Claude Code) handle it.
