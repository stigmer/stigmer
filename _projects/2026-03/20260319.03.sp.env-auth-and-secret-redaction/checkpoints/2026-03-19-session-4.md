## Decisions Made

- **Java authorization**: Standard `commonSteps.authorize` handles `field_path = "environment_id"` natively via `ApiRequestAuthorizationResourceIdExtractor`. No post-load authorization pattern needed (unlike `GetByReference`).
- **React hook returns string only**: `revealedValue: string | null` rather than full `EnvironmentValue` proto. Simpler DX for the primary "reveal button" use case.
- **Auto-clear default 30s**: Security vs usability tradeoff. Long enough to copy a connection string, short enough to limit exposure window.
- **Go handler follows session controller pattern**: Custom steps in `steps/` subdirectory, imported as `envsteps`, same pipeline architecture as `sessionsteps.FilterByAgentInstanceStep`.

## Learnings

- `ApiRequestAuthorizationResourceIdExtractor` supports arbitrary `field_path` values — any RPC can use custom field paths for authorization without writing custom auth steps
- Go pipeline steps need the `*pipeline.RequestContext[T]` type parameter to match the pipeline's input type — generic type constraints ensure compile-time safety
- `CustomOperationContextV2.getResponse()` returns `this.response == null ? this.target : this.response` — either `setTarget` or `setResponse` works for setting the gRPC response
