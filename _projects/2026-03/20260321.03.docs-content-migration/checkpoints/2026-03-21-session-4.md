## Decisions Made

- **Standard layout over custom**: The information architecture document envisioned a custom layout for the docs landing page, but we stayed within the standard Fumadocs `PageRoot`/`PageArticle` layout. The content matters more than layout complexity at this stage, and the standard layout provides sidebar, search, and theming for free.
- **Inline SVGs over icon library**: No new npm dependencies — all five language icons are inline SVGs. This keeps the bundle small and avoids external dependency management.
- **Server component**: The `LanguageIcons` component has no client-side state or effects, so it remains a server component (no `'use client'` directive). This means zero JavaScript shipped to the client for the icons.
- **Cards without links**: Section cards omit `href` to avoid 404s since no section content exists yet. Cards will gain links as content is added in Phase 3+.
