## Learnings

- Fumadocs `PageArticle` renders with `id="nd-page"`, `DocsBody` renders with `class="prose"`. These are stable selectors for scoping CSS.
- `next-themes` was already in the lockfile as a transitive dep of `fumadocs-ui`, but needs to be a direct dependency for the Mermaid component's `useTheme()` import.
- The `remarkMdxMermaid` plugin from `fumadocs-core/mdx-plugins` handles the conversion of ` ```mermaid` code blocks to `<Mermaid chart="...">` automatically.
