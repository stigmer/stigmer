## Decisions Made

- **Single type, not split**: Considered splitting `ApiResourceReference` into separate authoring (relative) and system (absolute) types. Decided single type is correct — the relative/absolute distinction is a wire-format convention, not a domain invariant. Same pattern as `version` field (empty = "resolve to latest").

- **Removed `min_len = 1`**: Redundant with the non-empty branch of the pattern regex. Cleaner to have a single validation expression.
