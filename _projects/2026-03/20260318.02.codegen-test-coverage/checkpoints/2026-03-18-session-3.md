## Learnings

- `isScalarSlice` doesn't verify the `[]` prefix — bare scalar type names like `"string"` also return true due to `TrimPrefix` approach
- Both `genContext.singularize` and mcp's `singularize` strip trailing "s" from words like "Bus" → "Bu" (known limitation of simple heuristic, guarded against `"ss"` but not single-char-before-s)
- `protoTypeToGoImportPath` requires at least 4 dot-separated parts (3 package segments + 1 type name)
