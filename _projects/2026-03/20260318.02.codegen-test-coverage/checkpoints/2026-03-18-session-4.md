## Decisions Made

- **Separate test file**: Created `conversion_test.go` rather than adding to the existing 1,359-line `main_test.go` — maintains clean separation between pure-function tests and code-generation output tests
- **Substring assertions over golden files**: Tests verify key patterns in generated output (e.g., specific function calls, JSON keys, type names) rather than exact output — more resilient to formatting changes
- **Import assertions on ctx.imports**: Import paths are tracked as side-effects on `genContext.imports`, not written to the buffer output — tests check the imports map directly

## Learnings

- Import paths are side-effects on `genContext.imports`, not part of the buffer output — initial test for shared map-message type failed because it checked the buffer for the import path
- When `genContext.packageName` matches the shared types package ("types"), the `types.` prefix is suppressed — this prevents self-referential imports
- The roundtrip symmetry test is structural, not runtime — it confirms that ToProto writes `data["key"]` and FromProto reads `fields["key"]` with the same key and field name, without actually executing the generated code
