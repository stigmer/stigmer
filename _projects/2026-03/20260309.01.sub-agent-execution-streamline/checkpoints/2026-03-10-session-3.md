## Decisions Made

- **Pause handler (Decision Point 1)**: Option B — leave sub-agents as IN_PROGRESS on parent pause (CancelledError). The CancelledError handler is actually a PAUSE, not a cancellation. Sub-agents may resume, so IN_PROGRESS is the accurate state. Resume-path reconstruction of routing state is deferred to a future PR.
- **Drop vs. misattribute (Decision Point 2)**: Option A — keep current behavior where unresolvable multi-segment namespaces fall through to main agent context with a warning. Changing to "drop" would require refactoring all callers of `_get_execution_context`. Concurrent sub-agents are rare in practice.
- **`force_next_update` on sub-agent end**: Discovered this was missing (present on `_handle_sub_agent_start` but not `_handle_sub_agent_end`). Added it — sub-agent completion is a significant status change that should trigger an immediate push.
