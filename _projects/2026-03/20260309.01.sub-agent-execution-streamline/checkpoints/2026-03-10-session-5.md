## Learnings

- `_handle_sub_agent_start` is sync but `_handle_tool_start_event` does `await` on it — the sync work completes before the `await None` TypeError is caught by `process_event`'s error handler. The sub-agent IS created despite the logged error. This is a pre-existing quirk, not a bug introduced by PR5.
- Namespace-to-sub-agent mapping is exact string match in `_get_execution_context`, not prefix-based. Tests must use the same namespace string for lookup as was registered.
