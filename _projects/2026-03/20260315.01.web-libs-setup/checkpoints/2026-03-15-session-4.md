## Decisions Made

- **Dropped StigmerExecutionContext**: Components already use props (2-3 levels deep). Context would be overengineering. Props are explicit, testable, and the tree is cohesive enough.
- **Service factory pattern**: `createExecutionService(transport)` is a pure factory. `useExecutionService()` is a thin hook wrapper. The `any` casts for protobuf-es codegen issues stay encapsulated.
- **Vendored shadcn**: 4 small components copied as `internal/ui/`. Self-contained library. `@base-ui/react` and `class-variance-authority` as peer deps.
- **Session services stay in console**: Session browsing is a console feature, not an embeddable library concern. Only execution CRUD/subscription moved.
- **Temporary duplication**: Helpers and hooks exist in both library and console. Console's old versions use singleton transport. Library's new versions use IoC. T05 removes the console copies.
