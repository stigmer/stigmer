## Decisions Made

1. **Directory naming**: `domain/react-ui/` not `domain/execution/` — directory matches package name following Planton convention. The `execution/` concept becomes `src/execution/` submodule in T04.

2. **npm `"*"` not `workspace:*`**: Stigmer uses npm, not yarn. The `workspace:*` protocol is yarn/pnpm-specific. Followed existing convention (`@stigmer/protos` uses `"*"`).

3. **ESLint flat config**: Added `@/` restriction as a targeted override in the existing `eslint.config.mjs` rather than creating a separate `.eslintrc.yml` (Planton's approach). One linting system.

4. **`strict: true` in tsconfig.base.json**: Deviated from Planton's `strict: false`. Stigmer's quality bar demands strict TypeScript from the start.

5. **No build artifacts in base config**: Omitted `declaration`, `declarationMap`, `sourceMap` — these are T06 (publishing) concerns. Source-only consumption via `transpilePackages`.
