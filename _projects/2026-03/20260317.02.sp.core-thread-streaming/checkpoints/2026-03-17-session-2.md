## Decisions Made

1. **`phase` as derived state via `useMemo`** — Computed from `execution?.status?.phase`. Eliminates impossible state where `phase` and `execution` disagree. Confirmed with user during planning.
2. **`isStreaming` and `isConnecting` as stored state** — These track lifecycle events (stream start/end) not derivable from `execution` alone. Event-driven transitions require explicit state management.
3. **`reconnect()` via `connectKey` counter** — Consistent with `refetch()` pattern in `useSessionExecutions`. Works in any lifecycle state.
4. **State clearing on executionId change** — Unlike data hooks that keep stale data, the streaming hook clears to `null` when switching IDs. Stale data from a different execution would be actively misleading.
5. **`TERMINAL_PHASES` not exported** — Internal constant. Extract to shared utility if/when multiple hooks need it.
6. **AbortError suppression via `controller.signal.aborted` check** — Standard pattern to distinguish intentional cancellation (unmount, id change) from real stream failures.
