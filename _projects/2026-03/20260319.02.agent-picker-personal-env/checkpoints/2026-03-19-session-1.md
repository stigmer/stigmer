## Decisions Made

- **Two-profile hook layering** (DD-005): Layer 1 building-block hooks for platform builders, Layer 2 orchestration hooks for direct users. Both layers exported from `@stigmer/react`.
- **Personal resource identification** (DD-002): Deterministic naming (`personal` slug for env, `{agent-slug}-personal` for instance) + labels for semantic queries.
- **Single-select picker** (DD-003): AgentPicker is single-select (unlike multi-select SkillPicker/McpServerPicker) — agents are mutually exclusive per session.
- **Frontend orchestration** (DD-004): Multi-step provisioning lives in application layer (hooks), not backend. Backend APIs stay single-responsibility.
- **Execution order**: Phase 1 -> Phase 3 -> Phase 2 -> Phase 4 (backend security filter ships before personal environments accumulate secrets).

## Learnings

- The `useResourceSearch` shared hook is well-designed — adding a new resource search hook is purely mechanical (< 45 lines).
- Type aliases (rather than direct re-exports) are the established pattern, preserving extension flexibility.
