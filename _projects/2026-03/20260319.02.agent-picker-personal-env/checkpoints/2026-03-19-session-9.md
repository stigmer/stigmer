## Decisions Made

- Agent chip renders first in the chip row (before workspace, MCP, skill) because agent selection has the highest impact on session behavior — consistent with its first position in the toolbar.
- Count badge shows `0` or `1` for the single-select agent trigger. Consistent with the multi-select pickers' count badge pattern, even though it's slightly redundant for single-select. Consistency wins over micro-optimization.
- Popover stays open after single-select (ContextPopover is uncontrolled). Acceptable for Phase 1. Phase 2 T02.4 will make the popover controlled to support the picker-to-env-form transition.

## Learnings

- The SessionComposer integration was clean because the existing ContextPopover + picker pattern is well-established. Adding a fourth picker (Agent) required no changes to ContextPopover or ContextChip — just extending the type union and adding the new trigger/chip.
