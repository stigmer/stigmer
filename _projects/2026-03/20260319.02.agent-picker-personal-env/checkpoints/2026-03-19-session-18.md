## Decisions Made

- **Codegen, not hand-edit**: User correctly flagged that generated TS SDK files should not be edited directly — fix applied at the codegen source (`sdk_client_ts.go`) and regenerated
- **Non-deterministic slugs**: Personal resources use random suffixes (`generateSlugSuffix()` → 8 hex chars from `crypto.randomUUID()`) to avoid `ALREADY_EXISTS` collisions in multi-user orgs
- **Label-based lookup as sole mechanism**: Slug is unique but opaque; all personal resource lookup uses FGA-scoped label-based list queries
- **Shared builder function over hook composition**: `buildPersonalInstanceInput()` is a pure function (not a hook) to avoid React rules-of-hooks complications with dynamic `agentId`
