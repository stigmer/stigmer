## Decisions Made

- **Inline per-variable save** over batch editing: maps directly to `updateVariables`/`removeVariables` RPCs, matches GitHub Actions / Vercel / Netlify UX conventions (Jakob's Law)
- **Self-contained `EnvironmentVariableEditor`**: takes `environmentId`, handles its own data fetching and mutations. Platform builders get drop-in embeddability without glue code
- **Settings entry in UserMenu dropdown** (not sidebar): user preference, follows standard avatar-menu convention for settings
- **Personal environment auto-created on settings visit**: consistent with the agent setup flow, no manual "create" step for users
- **`excludeLabels` pattern** on `EnvironmentListPanel`: filters personal environment from the shared list without modifying the backend query
- **SDK-first mandate followed**: all 3 components built in `@stigmer/react` first, then consumed as thin wrappers in the Console

## Learnings

- `useRevealSecretValue` works per-row because each VariableRow component gets its own hook instance with independent reveal state and auto-clear timer
- The `stigmer.environment.get(id)` method is available for fetching by ID (not just `getByReference`), which suits the editor's self-contained pattern
- `useUpdateEnvironmentVariables` returns the full updated `Environment` proto, enabling instant local state update without a separate refetch
