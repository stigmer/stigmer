## Decisions Made

- **Design tokens**: The task plan referenced `--stgm-*` tokens, but `site/src/app/globals.css` uses unprefixed semantic tokens (`--background`, `--primary`, `--accent`). Standards documents reference the correct names. This affects Phase 2 theming.
- **Standards exclusion**: `docs/standards/` is excluded from Fumadocs content sourcing. It holds governance documents and templates, not rendered documentation pages.
- **Terminology scope**: 23 canonical terms with prohibited aliases. Each term has an `exceptions` field for contexts where the prohibited form is acceptable (e.g., "org" in CLI flags, "token" for LLM tokens, "server" in `stigmer server start`).
- **Heading case**: New documents use sentence case; existing `what-is-*.md` files retain title case until migrated.
- **Reminders as separate concern**: Created `_reminders/` parallel to `_roles/` rather than mixing reminders into cursor rules. Reminders are manually dragged into conversations; cursor rules auto-inject.
