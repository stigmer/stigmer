## Learnings

- Fumadocs MDX files outside the `site/` module cannot use `import` for components living in `site/node_modules/`. The correct pattern is to inject components via the `components` prop on the MDX renderer in `page.tsx`.
- The custom terminology linter can produce false positives for phrases like "running Agent" (flagged as "running agent" → "AgentInstance"). Rewording to "working Agent" avoids the issue cleanly.
- Table separator rows in MDX must use `| --- |` (with spaces), not `|---|`, to pass markdownlint's `MD060` rule with the "expanded" style setting.
