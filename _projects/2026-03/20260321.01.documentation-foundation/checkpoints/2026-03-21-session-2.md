## Decisions Made

- **Node.js 20 LTS required for builds** — Node.js 23 causes silent webpack worker crashes with Next.js 15.3.9 (exits code 0 but never completes compilation). All CI/CD and local builds must use Node 20.
- **Turbopack disabled** — Can't resolve external files (`../docs/` outside `site/`). Using webpack instead. Removed `--turbopack` from `dev` script.
- **fumadocs-mdx v12 over v11** — v11's `files` API was a function, incompatible with `fumadocs-core@15` which expected an array. v12 aligns the API. Required Next.js >=15.3.
- **`PageRoot` toc prop wrapping** — `fumadocs-ui` `PageRoot` expects `toc={{ toc: array }}`, not `toc={array}` directly.
- **`RootProvider` scoped to `/docs` only** — Marketing page is completely isolated from fumadocs context.

## Learnings

- Node.js 23 + Next.js 15.3.9 webpack build silently fails — the process exits 0 with no "Compiled successfully" output. The trace file shows compilation starts but never finishes. This took significant debugging time.
- fumadocs-mdx versioning is tightly coupled to Next.js versions. v12 requires Next.js >=15.3, v11 only works with fumadocs-core@14 (not v15).
- `fumadocs-ui` v15 bundles its own `fumadocs-core@15` internally, so having a different top-level version creates dual-runtime conflicts.

## Open Questions

- Should we pin Node.js version in `.nvmrc` or `package.json` engines field?
- The `@types/react-syntax-highlighter` type mismatch will persist until the package updates for React 19. Consider removing it in favor of fumadocs-ui's built-in code highlighting.
