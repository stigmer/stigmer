## Decisions Made

- **Native checkboxes over custom**: `<input type="checkbox">` with `accent-primary size-3` — inherently accessible, matches `EnvironmentVariableEditor` pattern. No custom ARIA machinery needed.
- **Approval lookup via Map**: `useMemo(() => new Map(toolApprovals.map(...)))` for O(1) per-row instead of O(n) array scan per tool.
- **No hardcoded width**: Component fills container — parent controls width. Maximally flexible for embedding by platform builders and composition inside `McpServerConfigPanel`.
- **Clean empty state**: "Tools have not been discovered yet. All tools will be enabled by default." No CLI hint — platform builders embedding in their own products don't need Stigmer CLI references.
- **Approval badge**: `bg-warning/15 text-warning` with shield SVG icon + `title` tooltip showing the approval message template. Follows `ToolCallItem` badge pattern.
- **`useId()` for SSR-safe IDs**: Prevents collisions when multiple `McpToolSelector` instances coexist.
