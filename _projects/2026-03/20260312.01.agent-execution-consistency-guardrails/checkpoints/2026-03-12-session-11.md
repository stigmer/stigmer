## Learnings

- Protobuf fields are never `None` in Python — they default to zero values. Guards like `if status.field is None` are always unreachable.
- The `git stash` command during test verification can interfere with Cursor's in-memory file editing — need to be cautious when mixing shell git operations with tool-based edits.
