## Decisions Made

- **Proto enum naming**: User directed lowercase values (`graph_start`, `mid_execution`) instead of standard `SCREAMING_SNAKE_CASE` with prefix. Trade-off acknowledged (non-idiomatic, potential collisions) but accepted for readability.
- **Graphton proto boundary**: Explicitly decided to keep graphton free of proto imports. String constants in `summarization_callback.py` mirror proto enum names. StatusBuilder uses `SummarizationSource.Value()` to derive mapping from enum, eliminating manual string-to-enum dicts.
- **Compaction notification style**: Dimmed system line committed directly to scrollback (not transient), using existing `kindSystemMessage` and `systemMsgStyle`.
- **Count-based dedup**: `seenSummarizationCount` int tracks how many events have been processed, avoiding duplicate emissions on re-delivery.
