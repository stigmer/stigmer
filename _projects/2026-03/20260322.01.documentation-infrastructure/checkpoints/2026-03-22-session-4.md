## Decisions Made

- **Vale graceful degradation in hooks**: Vale runs only if installed. If not, a warning is printed but the commit is not blocked. Prettier always runs via lint-staged. CI will catch Vale issues when T08/T14 lands.
- **Husky v9 `prepare` script**: Uses the modern Husky v9 convention where `"prepare": "husky"` in `package.json` auto-installs hooks on `npm install`.
- **lint-staged for Prettier only**: Vale is handled separately in the pre-commit shell script (not lint-staged) because Vale is a system binary, not an npm package.
- **Vocabulary expansion**: Added platform-common terms (repo, dev, config, CLIs, frontmatter) to Vale accept list to avoid false positives in meta-documentation.

## Learnings

- Vale lints table cell contents, so a "Don't write this" column with intentional bad examples triggers violations. Restructured to describe rules positively instead of showing negative examples.
- The `alex` package flags "mental model" as ableist language. Replaced with "core concepts."
- `Google.Colons` flags capitalization after colons in bold labels. Restructuring to avoid the colon-after-bold pattern avoids the false positive.
