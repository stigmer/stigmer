- **`full: true` frontmatter** hides the right-hand TOC panel — routing pages don't need one.
- **4 navigation cards chosen by user intent:** Getting Started (try it), Core Concepts (understand it), Integrate into Your Platform (embed it), Deploy (ship it). SDKs, Architecture, CLI, and Reference intentionally left off — they're reachable from the primary paths.
- **Fumadocs built-in components** — No custom React components needed. `<Cards>` and `<Card>` are already registered via `defaultMdxComponents` in `site/src/components/mdx.tsx`.

## Learnings

- Fumadocs' `full: true` frontmatter prop is passed through to `DocsPage` and hides the TOC panel cleanly — no layout changes needed.
- Auto-generated CLI command MDX files (under `docs/cli/commands/`) contain bare angle brackets and curly braces that MDX parses as JSX. These cause 500 errors on the entire docs section since Fumadocs compiles all MDX files when building the page tree. These are pre-existing issues that need to be addressed in the CLI docs generator.
