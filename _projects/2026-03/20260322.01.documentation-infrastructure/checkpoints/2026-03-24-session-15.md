## Key Code Changes

### `seedpack/BUILD.bazel`
Gazelle could not merge `embedsrcs = ["stigmer.yaml"] + glob([...])` because it doesn't support the `list + glob()` pattern. Extracted the embedded files into a `filegroup` target (`seedpack_embed`) and referenced it from `embedsrcs`, which Gazelle can merge cleanly.

## Decisions Made

- Used `filegroup` pattern for Gazelle compatibility rather than a `# gazelle:resolve` directive, because it's the standard Bazel approach and keeps the BUILD file self-documenting.
- Bumped all Go modules to the Bazel-resolved versions rather than pinning Bazel to the lower versions, since the higher versions are what transitive dependencies require anyway.

## Learnings

- Gazelle cannot merge `list + glob()` expressions in Bazel BUILD files; it requires either a plain list or a plain `glob()` or a `filegroup` reference.
- `bazel run @rules_go//go:go -- get` doesn't work for `go.work`-based repos because it can't find a `go.mod` in the repo root. Must use `go get` directly in each module directory.
- `test/e2e` is in `go.work` but needs explicit `replace` directives for local modules that are transitive deps (the go.work file handles resolution during `go build` but `go mod tidy` validates each module independently).
