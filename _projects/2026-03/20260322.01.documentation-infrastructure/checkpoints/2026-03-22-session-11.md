# Session Notes: 2026-03-22, Session 11

## Accomplishments

- Fixed MDX build errors that prevented the docs site from rendering CLI command reference pages
- Added `escapeMDX` function to `gen-cli-docs` generator to handle three classes of MDX-unsafe characters:
  1. Bare `<placeholder>` tokens (e.g., `<id>`, `<agent-ref>`) — wrapped in backticks for inline-code rendering
  2. Remaining bare `<` characters (e.g., bash `<(` process substitution) — backslash-escaped
  3. Curly braces `{` `}` (e.g., JSON examples in prose) — backslash-escaped
- Regenerated all 20 command pages + index
- Verified zero MDX parse errors across the entire CLI reference section

## Decisions Made

- **Backticks for `<placeholder>` tokens**: Chose to wrap `<word>` patterns in backticks rather than using `\<` escaping, because backtick rendering provides better visual distinction (inline code style) for CLI placeholders
- **Backslash escaping for non-placeholder characters**: Used `\<`, `\{`, `\}` for remaining unsafe characters since these are prose artifacts (not CLI placeholders) and backslash escaping is invisible to the reader
- **Character-by-character state tracking**: The `escapeMDX` function tracks backtick code spans to avoid double-escaping characters already inside backticks from the first pass
