## Decisions Made

- **Remark plugin over `pre` override**: Chose to intercept mermaid blocks at the remark (MDAST) phase rather than overriding Fumadocs' `pre` component. This is cleaner because mermaid blocks never reach Shiki for syntax highlighting, avoiding the need to extract raw text from Shiki's highlighted HTML output
- **Client-side over build-time rendering**: Chose client-side Mermaid.js rendering over build-time `rehype-mermaid` (which requires Playwright/mermaid-cli). The site uses `output: "export"` (static) and diagrams are small enough that client-side render time is imperceptible. Can migrate to build-time later if needed
- **Vale Quotes rules disabled globally**: `Google.Quotes` and `Microsoft.Quotes` (punctuation inside quotes) produce false positives on every MDX component that uses string array props (`items={["A", "B"]}`). Disabled globally since the pattern is pervasive in MDX
- **Force-add for `site/src/lib/remark-mermaid.ts`**: The `lib/` pattern in `.gitignore` (Python build artifacts) accidentally catches `site/src/lib/`. Existing files there are already tracked. Used `git add -f` for the new file
