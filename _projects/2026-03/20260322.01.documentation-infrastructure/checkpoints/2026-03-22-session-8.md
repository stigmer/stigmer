## Learnings

- Fumadocs `DocsPage` has a `breadcrumb` prop that accepts `BreadcrumbOptions` from `fumadocs-core/breadcrumb`
- `includeRoot` accepts either `boolean` or `{ url: string }` — the object form makes the root item a clickable link
- `includePage` adds the current page name at the end of the trail (default is false)
- The root breadcrumb name comes from the page tree root's `name` field (defaults to "Docs")
