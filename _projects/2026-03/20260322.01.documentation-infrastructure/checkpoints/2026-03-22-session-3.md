## Decisions Made

- **Fumadocs v15 over v16**: v16 requires Next.js 16 and React 19.2+. Chose v15
  which is fully compatible with Next.js 15.x and Tailwind 4.
- **Next.js 15.3.9**: Upgraded from 15.1.3 for better Fumadocs compatibility.
  Avoided 15.5.x which was initially attempted but contributed to build instability.
- **Node.js 22 required**: Node.js 23 has a confirmed webpack
  `PackFileCacheStrategy` bug that silently aborts builds with exit code 0.
  Pinned via `.nvmrc`.
- **Webpack over Turbopack for dev**: `fumadocs-mdx` uses `?collection=docs`
  query-string imports that Turbopack cannot resolve. Removed `--turbopack` flag.
- **Scoped RootProvider**: Placed in `app/docs/layout.tsx` (not root layout) so
  Fumadocs contexts (theme, search) only apply to `/docs/*` routes. Marketing
  pages are unaffected.
- **Static Orama search**: Used `force-static` export mode since `output: 'export'`
  disallows dynamic API routes. Pre-built 295KB JSON index served as static file.
- **`~source` path alias**: Chose `~source` over `@/.source` to avoid potential
  conflicts with the existing `@/*` wildcard alias.
- **Logo**: Used `logo-square.svg` with explicit `width`/`height` attributes for
  Fumadocs nav, as Tailwind size utilities weren't constraining the SVG properly
  in Fumadocs' nav slot.

## Learnings

- Node.js 23 has a confirmed bug with Next.js webpack builds — the build silently
  exits with code 0 without producing output. The `[webpack.cache.PackFileCacheStrategy]
  Caching failed for pack: Error: Unable to snapshot resolve dependencies` warning
  is the key symptom. Always use Node.js 22 LTS.
- Turbopack does not support the `?collection=docs` query-string import syntax used
  internally by `fumadocs-mdx`. Webpack handles it via the `createMDX()` loader config.
- Fumadocs v15 exports `DocsBody`, `DocsDescription`, `DocsPage`, `DocsTitle` from
  `fumadocs-ui/page`, not `fumadocs-ui/layouts/docs/page`.
- Fumadocs CSS variables (`--color-fd-*`) must be overridden in a `.dark, :root`
  selector to apply in both forced-dark and system themes.
- `source.config.ts` `defineDocs` uses `docs.files` and `meta.files` arrays for
  glob patterns including exclusions (`!_archive/**`).
