## Decisions Made

- **Prompt builder owns agent-facing text** (not provisioner): `_git_writeback_guidance()` lives in `execute_graphton.py`, not in `git.py`'s `_build_description()`. This keeps provisioning focused on metadata and the prompt builder responsible for all LLM-facing copy.

- **Unconditional append pattern**: The function returns `""` when credentials are absent, so callers append without conditional checks — cleaner than wrapping every call site in `if`.

- **Per-entry granularity**: In multi-workspace sessions, only the git entries with `git_credentials_configured=True` get the write-back section. This handles mixed scenarios (e.g., one repo with token, one public repo without).
