# Vocabulary guide

The Vocabulary Guide was created as a permanent repo artifact at
[`docs/vocabulary.md`](../../../../docs/vocabulary.md).

It is the single source of truth for all Stigmer terminology — definitions,
user-facing alternatives, context-specific usage rules, capitalization, API
field names, and good/bad examples.

All other files that previously contained terminology sections
(`docs/STYLE.md`, `_roles/002_document_writer.md`, `glossary.ts`) now reference
the vocabulary guide instead of maintaining their own copies.

**Created**: 2026-03-31, Phase 1 deliverable 2 of the content strategy project.
