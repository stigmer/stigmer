## Learnings

- Figma's native design variables (`get_variable_defs`) returned empty — the designer didn't use them. Used `get_design_context` on specific nodes instead to extract colors and fonts from React+Tailwind code snippets.
- Fumadocs `--color-fd-*` variables need explicit overrides in both `.light` and `.dark` selectors when the root palette changes significantly.
- Tailwind v4 `@theme inline` requires explicit `font-family` entries for custom CSS variable fonts to be available as utility classes.
- When forcing dark mode for marketing pages but allowing light/dark for docs, the approach is: set `className="dark"` on `<html>` in root layout, then let Fumadocs `RootProvider` override it for docs routes.
