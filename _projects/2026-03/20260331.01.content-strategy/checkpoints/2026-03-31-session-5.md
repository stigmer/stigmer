## Decisions Made

1. **No industry overlap with demo story**: The demo story covers e-commerce (primary), property management, and logistics (variant sketches). All 5 use case library industries are new. This avoids content duplication and maintenance burden.

2. **Platform-builder lens throughout**: Every use case is framed as a SaaS founder adding AI agents as a product feature (not an internal tool), consistent with the positioning document's primary audience.

3. **Added "the pattern" section**: Not in the original T01 spec. Defines three abstract conditions (per-tenant knowledge, system actions, risk-graduated decisions) that make any platform a Stigmer candidate. This ensures readers in unlisted industries can still self-identify.

4. **Proof interactions included**: Each use case has a 2-3 line concrete agent dialogue, borrowed from the demo story's micro-pattern. Keeps the use cases grounded rather than abstract.

5. **Sales-site vocabulary enforced**: Vocabulary contract identical to demo story. Technical terms appear only in the coverage matrix headers (pillar names from the positioning document).
