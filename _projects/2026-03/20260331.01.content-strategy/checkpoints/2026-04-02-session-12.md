## Learnings

- Node 23 silently fails `next build` — it exits with code 0 after webpack compilation starts but never generates pages. Node 22 is required.
- Yarn 4's `file:` protocol creates copies (not symlinks) for packages with their own `node_modules`. After modifying SDK source, `YARN_ENABLE_IMMUTABLE_INSTALLS=false yarn install` is needed to refresh the copy.
- `ScenarioPlayer.onStepChange` fires as a `useEffect` (after render), meaning refs updated there aren't visible to child hooks that also fire as effects in the same cycle. Pre-built client maps avoid this timing issue entirely.
