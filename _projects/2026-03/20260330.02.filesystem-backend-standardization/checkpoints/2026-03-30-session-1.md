## Decisions Made

- **Delete over refactor**: Removed `__getattr__` forwarding entirely rather than adding an allowlist/blocklist. Aligned with architectural principle. Any future inner backend method that needs access gets an explicit override with path normalization.
- **Deferred multiple backend instance consolidation**: 3 separate `create_sandbox_backend` calls per Daytona execution is wasteful but functionally correct. Consolidation would require changing `create_builtin_subagents` and `transform_sub_agents` signatures -- out of scope for T02.

## Learnings

- `DeepAgentsBackendAdapter.upload_files` and `download_files` had a latent path normalization bug: `hasattr` returned True via `__getattr__`, routing to the inner `DaytonaBackend`'s raw `sandbox.fs` API with non-normalized paths. Sealing `__getattr__` forces the adapter to fall back to normalized `write()` / `read()`.
- The inner `DaytonaBackend` inherits `ls_info`, `edit`, `grep_raw`, `glob_info`, `aexecute`, `aread`, `awrite` from `BaseSandbox` -- all call `self.execute()` on the inner backend, bypassing the wrapper's `cd` preamble.
