## Learnings

- `shlex.quote` on simple paths without special characters (e.g., `/workspace`) returns them bare (no quotes). Test assertions must match this behavior.
- The `TestToolInputStreaming::test_reconcile_clears_result` failure is pre-existing (verified by stashing T04 changes and re-running). The test expects `result == ""` after reconciliation, but the code only clears result when the tool input buffer was empty.
- `humanize_args_for_display` and `create_args_preview` were mirror images of each other's gaps: one had recursion but no sandbox paths, the other had sandbox paths but no recursion. The fix was extracting the common pipeline and applying it consistently.
