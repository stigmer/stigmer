## Decisions Made

1. **T07+T08 merged** — Service factories (T08) and query hooks (T07) are co-dependent; implementing separately would require throwaway code
2. **Domain library packages created now** — Not deferred to Phase 7. Correct import paths from the start.
3. **`useSessionDetail` split** — `useSession(id)` + `useSessionExecutions(sessionId)` for single responsibility
4. **`useInfiniteQuery` for sessions** — Cursor-based "load more" pattern matches the API's `pageToken` contract
5. **`useQuery` for resource lists** — Page-based pagination for agents, skills, MCP servers
6. **`OrgProvider` stays as-is** — Its localStorage + active selection concerns don't map to TanStack Query
7. **`-ui` suffix kept** — All domain packages will get UI components (marketplace, catalog, browser)
8. **`fetchNextPage`/`refetch` wrapped in `useCallback`** — TanStack Query functions have incompatible signatures with `onClick` handlers
