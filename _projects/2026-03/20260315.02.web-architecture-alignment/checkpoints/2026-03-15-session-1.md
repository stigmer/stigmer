## Learnings

1. **Verify each dead code removal individually**: The initial analysis incorrectly flagged `searchAgents` as dead. A batch removal caused a build failure. Always verify imports file-by-file before deleting.
2. **Build artifacts (`dist/`) need explicit ESLint ignores**: Compiled JS in `_libs/domain/react-ui/dist/` triggered ESLint violations. Adding `**/dist/**` to `globalIgnores` resolved this.
3. **Some "dead" exports are intentionally reserved**: Auth stubs, chart CSS variables, and UI variant exports serve as API surface or future-proofing. Don't confuse "currently unused" with "dead."
