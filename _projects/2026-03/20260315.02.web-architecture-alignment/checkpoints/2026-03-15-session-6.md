Implemented the complete three-tier error handling framework for Stigmer Web, from transport-level interceptors through TanStack Query retry configuration to component-level display.

## Decisions Made

1. **Expanded T09 scope** — user agreed to include display infrastructure (toast + error components + retry config) alongside interceptors, since interceptors without display infrastructure are incomplete
2. **Non-blocking toast for server errors** — rejected global error modal pattern (used by Planton), recommended and adopted non-blocking toast instead
3. **No event bus** — TanStack Query's cache-level handlers replace the need for Planton's custom event bus pattern
4. **No `MutationCache.onError`** — components own mutation error display to prevent duplicate toasts
5. **Sonner over custom notification system** — lightweight, accessible, Tailwind-compatible, pairs with shadcn/ui
