## Learnings

- `GetEventLogResponse.latest_sequence` is the highest sequence in the RETURNED PAGE, not a global max. This is a subtle but critical distinction that would have caused the fix to silently fail.
- Temporal local activities in the TS SDK match by activity type name (the object key), not by function name. Implementation swaps are safe as long as the key doesn't change.
