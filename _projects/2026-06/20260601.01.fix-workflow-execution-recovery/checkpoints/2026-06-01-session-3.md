## Decisions Made

- **Explicit flag on workflow input, not auto-detect**: Confirmed by evaluating 4 alternatives (Temporal memo, event-log detection, proto persistence, search attribute). Explicit flag avoids false positives from crash restarts and try/catch retries.
- **`omitempty` on Go bool**: Follows `AutoApproveAll` pattern on agent execution input. Non-recovery paths omit the field cleanly.
- **Java `boolean` primitive (not `Boolean` boxed)**: Consistent with `int executionTarget` on the same record. Always serialized, but TS handles both `false` and `undefined` identically.
- **Factory method overload (not builder)**: Matches existing `InvokeAgentExecutionWorkflowInput.fromExecution()` 2-overload pattern. 3-arg (default false) delegates to 4-arg.
- **No Temporal version gates**: Field addition with zero-value default is backward-compatible for JSON deserialization. Verified against all 4 compatibility paths.
