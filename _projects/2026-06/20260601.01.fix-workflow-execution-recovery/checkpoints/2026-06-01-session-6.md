## Decisions Made

- **Extract-and-override over inline stream-branch fix**: Evaluated three approaches. Chose extracting the cascade into `classifyFromSources` + post-classification override in `synthesizeError`. Matches existing helper extraction pattern (`matchesAny`, `classifyText`). The override is a principled cross-cutting statement, not a branch-specific patch.
- **Override scoped to `unknown` only**: Specific diagnoses (auth, rate-limit, network, model) represent real root causes and should not be overridden by the resumed-handle heuristic. Only `unknown` — meaning no source could identify the error — triggers the upgrade to `agent-stale`.
- **Unconditional session persistence in recovery path**: The guard `resolution.isNew || !blueprint.sessionSpec.harnessStateId` was stale because `resolution` is `const` and reflects the pre-recovery state. Removed the guard entirely rather than deriving a corrected check — the poisoned-handle recovery path exists specifically to replace a dead agent.
- **Extracted `SynthesizeErrorOpts` interface**: The parameter type was duplicated between `synthesizeError` and `classifyFromSources`. Extracted to a named interface for DRY compliance.
