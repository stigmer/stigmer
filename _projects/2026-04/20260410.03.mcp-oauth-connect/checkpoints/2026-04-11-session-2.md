## Decisions Made

- **Encryption extraction scope**: Kept `EnvironmentSecretService` as a thin delegate (no existing caller changes needed) rather than replacing it entirely — minimizes blast radius
- **Cloudflare transport**: Kept as stdio — `@cloudflare/mcp-server-cloudflare` is a local CLI tool for managing Cloudflare infra, no hosted remote endpoint found
- **Vendor OAuth seedpack deferred**: Slack, Stripe, Figma, Salesforce auth blocks require org-specific `oauth_app_ref` which can't be in seedpack templates — deferred to T03/T04
- **Delete guard query path**: Uses `spec.auth.oauthAppRef` (camelCase in MongoDB BSON from protobuf JSON serialization) for the referential integrity check

## Learnings

- All 9 DCR+PKCE servers now have hosted HTTP endpoints (Sentry, Neon, Tavily, Supabase confirmed via web research; GitLab, Linear, Atlassian, Notion were already HTTP)
- Cloudflare's MCP server is infrastructure management, not a hosted service — different from Cloudflare's platform for building MCP servers
- The IdentityProvider handler pattern is highly reusable — OAuthApp handlers are structurally identical with domain-specific steps (encrypt/redact instead of SSO/issuer validation)
