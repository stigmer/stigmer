## Decisions Made

1. **`redirect_uri` dropped from OAuthAppSpec**: Stigmer is a platform for platform builders. The OAuth callback URL is a property of the Stigmer deployment (server config), not something configured per OAuthApp. Asking platform builders to echo back Stigmer's own callback URL would be redundant and error-prone.

2. **OAuthApp always org-private**: No `supports_public` visibility, no `updateVisibility` RPC. OAuthApp holds `client_secret`, which must never be exposed beyond the owning organization. Follows the same pattern as IdentityProvider.

3. **`userinfo_url` added to OAuthAppSpec (field 7)**: Optional OIDC userinfo endpoint for vendors that support it. Allows Stigmer to fetch display name/avatar for the connected account after token acquisition.
