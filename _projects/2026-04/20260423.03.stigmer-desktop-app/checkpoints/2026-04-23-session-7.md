## Learnings

1. `tauri-plugin-single-instance` must be the first plugin registered — ordering matters
2. `onOpenUrl` requires single-instance plugin with `deep-link` feature on Windows/Linux
3. `getCurrent()` reads CLI args on Windows/Linux, app delegate on macOS — abstraction is seamless
4. Proto message types require `create(Schema, { ... })` — plain objects rejected by TypeScript
5. `URL` constructor parses `stigmer://launch-runner` with `launch-runner` as hostname, not pathname
