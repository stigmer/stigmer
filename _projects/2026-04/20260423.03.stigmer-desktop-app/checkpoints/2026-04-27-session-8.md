## Decisions Made

- **Only `embed_agentrunner`, not `embed_webconsole`**: Desktop has its own UI — web console embed not needed. Agent-runner embed is required because `stigmer up runner` bootstraps a Python venv from embedded source.
- **Progressive disclosure for error banner**: Primary error extracted via last `"Error: "` marker in stderr; full CLI output in expandable `<details>`. Follows Hick's Law and Nielsen's #9.
- **Build-time guard**: Checks for `source/main.py` after sync to fail fast if embedding silently breaks.

## Learnings

- DD-T07-05 was an incorrect design assumption — the sidecar always needs the agent-runner embed because the CLI bootstraps Python from embedded source, not from the filesystem
- The CLI `climsg` package writes all progress messages to stderr, which is why the Tauri sidecar's grace-period stderr collection returns a concatenated wall of text on error
