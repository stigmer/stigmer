## Learnings

- Tauri 2's `CommandChild` doesn't implement `Send` natively; accessing `ProcessManager` state from async spawn requires going through `AppHandle.state()` inside the task rather than capturing a reference before spawn
- CLI's `stigmer up runner` has no `--runtime` flag (Docker support is Phase 3 T03) — the T01 plan's `start_runner(name, runtime, token)` signature was aspirational
- `~/.stigmer/runners/*.json` state files are simple enough to read directly from Rust — no need to spawn a CLI process for listing
