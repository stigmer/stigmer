## Decisions Made

- **Error handling depth**: Showed one practical example per language rather than one language with a cross-reference table, because the error APIs genuinely differ (TS free functions, Go package functions, Python snake_case free functions, Java instance methods on exception)
- **TypeScript `getAccessToken`**: Documented in the Authentication section alongside `apiKey` — a Reference page should cover all configuration options, not just the simplest one
- **Accessor names**: Used correct names from actual SDK source code (Python plural `client.agents`, Java plural `client.agents()`) rather than matching the generated docs which have a codegen bug
- **Configuration tables**: Per-language option tables within SDKTabs rather than one cross-language table, since options differ per SDK (TS has transport, Go has WithDialOptions, etc.)
- **Streaming section**: Brief preview with one subscribe example per language, linking to the dedicated streaming guide page — avoids duplicating what will be the streaming guide's content

## Learnings

- Generated SDK docs have a codegen bug: Python and Java accessor names use singular (`client.session`) but the actual SDK source uses plural (`client.sessions`). The quickstart uses the correct plural names. This is in `sdk_docs.go` and needs a separate fix.
- SDKTabs, Tab, Callout, Cards, Card are all globally available in the Fumadocs MDX setup — no imports needed in MDX files
- The SDKTabs component wraps Fumadocs Tabs with `groupId="sdk-language" persist` for cross-page persistence
