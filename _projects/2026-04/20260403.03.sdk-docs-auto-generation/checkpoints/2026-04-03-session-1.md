## Learnings

1. **Proto comments with JSX-significant characters**: Proto comments can contain curly braces (e.g., `{kind: "identity_account"}` in IAM policy descriptions) and angle brackets (e.g., `<entry_point>` in project descriptions). These break MDX parsing if not escaped. Solution: `docEscapeMDX()` escapes `{`, `}`, `<`, `>` in description text that appears as MDX body content.

2. **TypeSchema has a Description field**: Initially uncertain, but confirmed that `TypeSchema` struct includes a `Description` field populated from proto comments. This enables type-level descriptions for nested types.

3. **Fumadocs hot reload**: The dev server picks up new MDX files automatically without restart. Changes to generated files are reflected after a few seconds.

4. **SDKTabs persistence**: The `persist` prop on `SDKTabs` means selecting a language tab on one method switches all tabs on the page simultaneously -- great UX for SDK reference.
