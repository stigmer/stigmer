## Learnings

- The `store.UpdateResource` method returns errors from the `modify` callback directly (line 521 in sqlite/store.go). This means domain errors like `FAILED_PRECONDITION` propagate correctly without wrapping.
- The generic pipeline framework works well for standard CRUD but the heartbeat handler needed a different approach because the input type (`AgentRunnerHeartbeatInput`) is fundamentally different from the resource type (`AgentRunner`).
