## Learnings

- `RequestCallerIdentity` does NOT carry email/name — only identityAccountId, idpId, and raw accessToken. Need to decode the JWT for those claims.
- `platformClientId` is null for Auth0 browser users — acceptable for StigmerJwtIssuer.
- Pre-existing `SessionUpdateSandboxIdHandler.java` blocks all Java compilation in stigmer-cloud.
- `RunnerGrpcAutoController` annotation processor handles new RPCs automatically — no manual wiring needed.
