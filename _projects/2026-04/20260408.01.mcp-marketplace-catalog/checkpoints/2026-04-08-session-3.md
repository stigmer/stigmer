## Decisions Made

| Decision | Rationale |
|----------|-----------|
| Use `spec.http` for Linear and Atlassian | Agent-runner already supports `streamable_http`. No stdio packages exist for these servers. Exercises the full platform capability. |
| Use `crystaldba/postgres-mcp` for PostgreSQL | 2.4k stars, MIT, `DATABASE_URI` env var fits env_spec perfectly, restricted mode with pglast SQL injection protections. The archived `@modelcontextprotocol/server-postgres` has a known SQL injection vulnerability. |
| Use `uvx` for Python MCP servers | Agent-runner Dockerfile explicitly installs `uv`/`uvx`. Proto allows any executable as `command`. |
| Use npm package for GitLab (not HTTP) | Published by GitLab PBC, not deprecated. HTTP alternative requires Premium/Ultimate + Duo — too restrictive for marketplace. |
| Accept community package for MySQL | `@benborla29/mcp-server-mysql` has 1.4k stars, read-only by default. No official MySQL MCP server exists. |
| Name Atlassian entry `atlassian` not `jira` | Official endpoint at `mcp.atlassian.com` covers Jira + Confluence + Compass, not just Jira. |
| Use Bearer auth for Atlassian (not Basic) | Basic auth requires base64 encoding of email:token which doesn't fit `${VAR}` placeholder model. Bearer with service account API key is a single secret value. |
| Add `default_tool_approvals` for MongoDB, GitLab, SQLite | Tool names verified from official vendor/upstream documentation. Catastrophic operations (drop-database, file overwrites) warrant approval policies. |

## Learnings

- Many popular MCP servers are now HTTP-only remote services (Linear, Atlassian, GitHub Copilot). The ecosystem is moving toward hosted endpoints with OAuth/Bearer auth, not just local subprocess servers.
- The reference MCP servers from `modelcontextprotocol/servers` are being archived. PostgreSQL, GitLab, and SQLite sources have been moved to `servers-archived`. npm packages still work but are unmaintained.
- `crystaldba/postgres-mcp` is a much better PostgreSQL option than the reference server: env var config, restricted mode, SQL injection protections via pglast AST parsing.
- The agent-runner Dockerfile already installs `uv`/`uvx` alongside `npx` and `go`, making Python MCP servers fully supported without any infrastructure changes.
- Bearer auth with `${VAR}` in HTTP headers maps cleanly to `env_spec`. Basic auth (email:token base64 encoding) does not — prefer Bearer for marketplace entries.
