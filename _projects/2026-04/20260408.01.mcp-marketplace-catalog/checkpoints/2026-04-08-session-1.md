## Learnings

- The agent-runner (`config_transformer.py`) passes `stdio.args` as-is — no `${VAR}` interpolation. Servers that take core config as positional CLI args (PostgreSQL connection URL, Filesystem paths) can't be parameterized per user through the McpServer YAML.
- `spec.tags` and `metadata.tags` are independent fields. Only `metadata.tags` is indexed for search (FTS5). The existing `mcp-server-stigmer.yaml` only uses `spec.tags`, so its tags aren't searchable.
- `@modelcontextprotocol/server-github` is deprecated — development moved to `github/github-mcp-server`. The npm package still works.

## Open Questions
