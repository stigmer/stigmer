## Decisions Made

- **Fidelity**: Representative/schematic — not pixel-accurate to the real
  console. Clean illustration that communicates the navigation flow. Low
  maintenance.
- **Animation**: Pulse/highlight effects on nav items and buttons. No animated
  mouse cursor. Works with `prefers-reduced-motion`.
- **Orchestration**: Reuse existing `ScenarioPlayer<T>` with a discriminated
  union `GuidedTourStep` type. No new playback engine needed.
- **Content transitions**: `framer-motion` keyed on view category
  (`"dashboard"` / `"skills"` / `"composer"`), so message snapshots don't
  trigger unnecessary fades.
- **Placement**: All docs-only. No SDK changes. No Console dependencies.

## Learnings

- The `ScenarioPlayer` generic type parameter pattern is very flexible — works
  for both simple `AgentExecution` snapshots and rich discriminated unions
- `MessageThread` synthesizes a human bubble from `spec.message`, so the first
  human message must be excluded from `status.messages` to avoid duplication
  (the `snapshot()` pattern)
- Content key grouping prevents unnecessary fade transitions — only fire when
  the view category changes, not on every step
