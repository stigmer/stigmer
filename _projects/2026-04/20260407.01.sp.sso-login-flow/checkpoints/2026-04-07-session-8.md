## Decisions Made

- **URL as prop, not computed inside SDK**: The SSO login URL structure (`/login?org=...`) is Console routing knowledge. The SDK component accepts a pre-computed URL, keeping it agnostic to the consumer's routing. Platform builders pass their own URL or omit the prop entirely.
- **No shared CopyableField extraction**: The clipboard copy pattern is repeated in 6+ SDK components. Extracting a shared primitive is worthwhile but deferred — doing it here would expand scope and touch unrelated files. The new helper is private to the file, consistent with existing `Field` and `FieldInput` helpers.
- **View mode only**: The SSO login URL is derived from the org slug (not editable on this panel), so it only appears in view mode.

## Learnings

- The clipboard copy pattern (navigator.clipboard + fallback + copied state + timeout) is repeated in 6 SDK components with slight variations. A shared `CopyableField` or `useCopyToClipboard` hook would reduce duplication. Good candidate for a future cleanup pass.
