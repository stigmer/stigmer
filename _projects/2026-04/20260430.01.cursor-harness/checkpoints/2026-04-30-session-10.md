## Decisions Made

- **Kustomize secret placement**: Task spec suggested `_kustomize/overlays/prod/`. Examination of existing LLM proxy keys showed they live in `_kustomize/base/service.yaml`. Followed the established pattern for consistency.
- **HTTP/1.1 over HTTP/2**: Explicitly forced `HttpClient.Version.HTTP_1_1` to leverage Cursor's SSE fallback, matching their recommendation for enterprise proxy environments.
- **Permissive header forwarding**: Unlike `LlmProxyController` (which only forwards `Content-Type`), the Cursor proxy forwards all request headers except hop-by-hop and auth-related ones. This ensures compatibility with Cursor's gRPC-Connect and SSE protocols.
- **Hardcoded host allowlist**: `api2.cursor.sh`, `api.cursor.com`, `api.cursor.sh` as exact matches rather than subdomain patterns. Tighter security at the server boundary; expand only when Cursor adds new domains.
