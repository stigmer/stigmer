## Decisions Made

- **String literals on props, proto enums inside hooks**: `HarnessOption = "native" | "cursor"` on component props; `toProtoHarness()`/`fromProtoHarness()` convert at the hook boundary. Platform builders never import proto enums.
- **Per-harness model persistence**: localStorage keys `stigmer:session:model` (native) and `stigmer:session:model:cursor` (cursor). Switching harness restores the per-harness preference. Legacy key (`stigmer:session:model`) doubles as the native key for backward compatibility.
- **HarnessSelector as segmented control**: `role="radiogroup"` with `role="radio"` children, arrow-key navigation, premium indicator on Cursor segment.
- **Harness hidden on session page**: Follow-up composer receives harness for model filtering but does NOT show the selector (immutable after first execution). `useSessionPageFlow` derives harness read-only from `session.spec.harness`.
- **Auto-reset model on harness switch**: `SessionComposer` detects when the current model is invalid for the new harness and resets to the harness default.

- The TS SDK's `SessionInput` already supported `harness?: Harness` — the React hook layer was the only gap. Proto-first design paid off.
