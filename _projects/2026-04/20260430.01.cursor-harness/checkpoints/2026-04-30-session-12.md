## Bug Discovery

**ApprovalAction enum misuse** in `src/hitl/approval-state.ts` and `src/activity/execute-cursor.ts`:
- Source uses `ApprovalAction.APPROVAL_ACTION_APPROVE` (full proto field name)
- Generated TypeScript enum uses `ApprovalAction.APPROVE` (short name)
- The full names evaluate to `undefined`, causing all comparisons to silently fail
- Impact: HITL approval/rejection logic does not work as intended
- Status: Documented in test comments; source fix deferred to next session

## Learnings
- Vitest in `happy-dom` env does not auto-cleanup after each test (unlike Jest) — explicit `afterEach(cleanup)` is required for component tests
- `@stigmer/protos` exports `.ts` files but source code imports with `.js` suffix (Node ESM convention) — `resolve.alias` in vitest config bridges this gap
- The fetch interceptor's module-level capture of `globalThis.fetch` requires careful test setup ordering
