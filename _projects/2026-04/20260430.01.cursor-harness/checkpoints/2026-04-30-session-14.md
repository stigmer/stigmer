# Session Notes: April 30, 2026 — Session 14

## Accomplishments

- Implemented the Unified Model Selector (Cursor-Style) plan end-to-end

- All 228 tests pass across 21 test files, zero linter errors

## Decisions Made

- **Flat list over hierarchy**: Adopted Cursor's proven model picker pattern — no tabs, no grouping, no two-level hierarchy. Each model row has a subtle engine tag ("Stigmer" / "Cursor") plus cost tier indicator.
- **Curated defaults (10 models)**: 2 Stigmer (Sonnet 4.6, Opus 4.6) + 8 Cursor (Auto, Composer 2, GPT-5.5, Codex 5.3, Sonnet 4.6, Opus 4.7, Opus 4.6). Rest discoverable via "Show All" or search.
- **Compound keys**: `"${harness}/${modelId}"` used internally because the same model name can appear under both engines (e.g. `claude-4.6-sonnet` on cursor vs `claude-sonnet-4.6` on native).
- **Implicit harness resolution**: Selecting a model fires `onHarnessResolved` to update the session harness automatically. No separate harness control needed in the UI.
- **`openai` native stays disabled**: Only Cursor-served OpenAI models are exposed. Native OpenAI models remain in `DISABLED_PROVIDERS`.
- **`composer-1` omitted**: Legacy model from `model-pricing.ts` not added to UI catalog — `composer-1.5` supersedes it.

## Key Code Changes

- **`registry.ts`**: Added `harness: HarnessOption` and `featured: boolean` to `ModelInfo`. Expanded `Provider` with `"google"` and `"xai"`. Removed `"cursor"` from `DISABLED_PROVIDERS`. Added `modelKey()` / `parseModelKey()`. Populated 16 Cursor-harness models.
- **`useModelRegistry.ts`**: Added unified mode (no harness filter). Returns `featured` subset and `getByKey` for compound key lookup. Backward-compatible.
- **`ModelSelector.tsx`**: Complete rewrite from `@base-ui/react` Select to Popover + custom list. Search, curated defaults, "Show All", keyboard nav, ARIA.
- **`ComposerToolbar.tsx`**: HarnessSelector suppressed when model selector is visible. ModelSelector runs in unified mode.
- **`SessionComposer.tsx`**: Removed harness-switch model reset effect. Added compound key resolution for submit.
- **`HarnessSelector.tsx`**: Marked `@deprecated`, kept for backward compat.
- **`useModelRegistry.test.tsx`**: Rewritten — 24 tests covering unified/native/cursor modes, featured, compound keys.

## Learnings

- The `model-pricing.ts` file in cursor-runner is the authoritative source for Cursor API model IDs. These IDs use a different naming convention than native models (e.g. `claude-4.6-sonnet` vs `claude-sonnet-4.6`).
- `useNewSessionFlow` required no changes — it continues to use `useModelRegistry({ harness })` in single-harness mode, which the updated hook handles via backward compatibility.
