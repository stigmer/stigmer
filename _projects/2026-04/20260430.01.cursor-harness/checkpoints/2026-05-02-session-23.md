- React `useState` initializer closures capture variables at definition time. When the dependency (localStorage key) changes, only an explicit effect can re-sync.
- The "sporadic" nature of Issue 2 is explained by render-cycle timing during session navigation — brief window where `conv.session` is null maps to "native" harness before correct data arrives.
