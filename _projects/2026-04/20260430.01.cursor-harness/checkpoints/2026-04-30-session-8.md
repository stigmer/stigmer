## Decisions Made

- **Session delete restricted to operators**: Protects billing audit trail. `can_delete_session = 26` permission on `platform:stigmer`. Regular users cannot delete sessions.
- **Cursor agent cleanup deferred**: No `Agent.archive` call on session delete. Cursor agents expire naturally. Revisit when SDK lifecycle is better understood.
- **Resume failure = fail loud**: No silent fallback to new agent. Execution fails with actionable error directing user to start a new session.

## Learnings

- Go and Java use fundamentally different Temporal activity registration patterns. Go requires explicit method-level registration; Java uses interface-based stubs where any method on a registered activity is accessible. This asymmetry caused the Go registration bug.
- Proto annotation-based authorization (`RpcAuthorizationConfig`) is only enforced in the Cloud edition. OSS has no interceptor, so annotation changes are a no-op there.
