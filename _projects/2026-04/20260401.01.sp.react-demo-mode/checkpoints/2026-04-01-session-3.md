## Decisions Made

- **`file:` protocol over npm workspaces**: The site uses yarn 4.5.1 standalone.
  Adding it to npm workspaces broke the `next build` — webpack's client compiler
  exits prematurely on Node 23 due to an event-loop drain bug. Using `file:`
  protocol deps with yarn keeps the site's build toolchain intact while still
  resolving `@stigmer/*` packages to workspace source.

- **`transpilePackages` for TypeScript source**: Since `file:` protocol links to
  raw `.ts` source (not compiled dist), Next.js needs `transpilePackages` in
  `next.config.ts` to run the SWC TypeScript loader on `@stigmer/*` packages.

- **Node 22 LTS required for builds**: Node.js v23.1.0 has a bug where the
  webpack client compiler's event loop drains before compilation finishes,
  causing `next build` to exit with code 0 but produce no client bundles or
  static export. The server compiler completes (~8s) but the client compiler
  dies immediately after starting. Pinned `engines` to `^20.11.0 || ^22.0.0`.

- **`tailwind-merge` bumped to `^3.0.0`**: Required to satisfy
  `@stigmer/theme`'s peer dependency.

- **`noop` over `console.log`**: Replaced `console.log("[demo] submitted:", ...)`
  with a `noop` function in DemoSessionComposer to avoid ESLint `no-console`
  warnings in the production build.

## Learnings

- **Node 23 webpack bug**: The `next build` process forks a build worker for
  webpack compilation. On Node 23, the client compiler's event loop drains
  immediately after starting, causing the process to exit with code 0 before
  producing client bundles. The `DEBUG=next:*` flag was critical for diagnosing
  this — it showed the server compiler completing but the client compiler dying
  on start. This is NOT triggered by our changes; it reproduces on the clean
  main branch.

- **npm workspaces vs yarn standalone**: The site was designed for yarn 4
  standalone operation. Adding it to npm workspaces changes module resolution
  (hoisting behavior) and breaks the build even further. The `file:` protocol
  approach is the cleanest bridge — yarn creates portal links that resolve to
  workspace source, and `transpilePackages` handles the TypeScript compilation.

- **`@source` directive**: Tailwind CSS v4 needs explicit `@source` directives
  to scan files outside the project's own source tree. Without it, Tailwind
  won't generate utility classes used by `@stigmer/react` components.
