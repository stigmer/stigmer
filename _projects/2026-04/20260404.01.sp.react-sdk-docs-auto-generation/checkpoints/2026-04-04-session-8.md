## Patterns Applied

- **`className` fields**: "Additional CSS class names for the root container." (consistent across all components)
- **Mutation returns**: `create`/`update`/`delete` → Promise resolves with resource; `isCreating`/`isUpdating`/`isDeleting` for loading; `error`/`clearError` pair
- **Query returns**: `data` (or domain-specific field) + `isLoading` + `error` + `refetch`
- **Props interfaces**: `/** Props for {@link ComponentName}. */`
- **Return interfaces**: `/** Return value of {@link useHookName}. */`
- **Options interfaces**: `/** Options for {@link useHookName}. */`
- **Type aliases to shared interfaces**: Summary pointing to the underlying shared definition
- **`disabled` fields**: "When `true`, all inputs and buttons are disabled." or "When `true`, the selector is disabled."
