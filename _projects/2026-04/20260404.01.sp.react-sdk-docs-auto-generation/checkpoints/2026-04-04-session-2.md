## Learnings

- The documentation gap is surgical: functions are at 98.8%, interfaces at 13.2%. The overall 57.6% is entirely an interface problem.
- Props Interfaces (1.8%) and Return Interfaces (0.0%) are the biggest categories to fix, but the fix is mechanical — one-line formulaic summaries.
- The codebase already has gold standard examples (`useExecutionStream`, `useSessionConversation`) that serve as templates for the guidelines.
- TypeDoc function comments live on `signatures[0].comment`, not on the declaration itself. `@param` docs are on `signatures[0].parameters[i].comment`, not as `blockTags`.
- 48 interfaces have <50% field-level coverage, with 37 at 0%. Most follow the standard `{ data, isLoading, error, refetch }` pattern.
