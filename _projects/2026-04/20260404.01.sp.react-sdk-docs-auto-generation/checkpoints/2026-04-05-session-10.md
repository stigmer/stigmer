## Decisions Made

- **Audit scope**: Only publicly exported hooks/components (via `sdk/react/src/index.ts`) need `@example`. Internal hooks (`search/useResourceSearch`, `internal/useScrollShadows`) and non-exported composer subcomponents (`ComposerToolbar`, `ConfigureMenu`, `ContextChip`) were excluded.
- **Multi-example pattern**: Hooks with skip/null behavior get a second `@example` showing the skip pattern (e.g., `useSession(sessionId ?? null)`).
- **Type example selectivity**: Only 4 of the plan's ~5-10 candidates warranted examples — types that are consumed across multiple hooks/components and where the shape isn't obvious from the field table alone.
- **useArtifactContent**: Already had inline code blocks in its description, but these are not `@example` tags. Added proper `@example` tags to ensure the generator extracts and renders them.

## Learnings

- The plan estimated 12 hooks and ~31 components missing examples. Actual gap was 11 hooks and 8 components — the original T02 audit counted non-public exports and used a different methodology.
- `useArtifactContent` had rich inline code in its description but no formal `@example` tag — inline fenced blocks in description text don't get extracted by the generator's example extraction pipeline.
- The `search/` hooks (`useResourceSearch`, `useResourceList`, `useResourceCount`) are internal base implementations consumed by domain-specific hooks — they're not re-exported from the public barrel.
