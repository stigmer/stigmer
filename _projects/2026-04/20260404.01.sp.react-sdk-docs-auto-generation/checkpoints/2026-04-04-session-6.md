## Learnings

- `McpAccess` proto uses `mcpServer: string` (just a slug), not a full `ApiResourceReference` — different from `McpServerUsage` which uses `mcpServerRef: ApiResourceReference`
- `ToolCall.args` is a proto `Struct` (mapped to `JsonObject` in TS), not a string — pass object directly, not JSON.stringify
- `ExecutionPhase` enum doesn't have `EXECUTION_RUNNING` — it's `EXECUTION_IN_PROGRESS`
- `ToolCall` proto has no `durationMs` field — duration is computed from `startedAt` / `completedAt`
