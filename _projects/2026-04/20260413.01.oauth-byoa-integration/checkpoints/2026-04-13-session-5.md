## Decisions Made

1. **Inline confirmation over modal**: Disconnect uses inline replacement pattern (like `RevokeConfirmation`), not a `<dialog>` modal. Rationale: proportionate to reversible action, avoids portal/z-index issues for SDK embedders, spatial locality (Fitts's Law).
2. **Enhanced inline error strip over full `ErrorMessage` component**: ConnectBar error strip uses `getUserMessage()` + `isRetryableError()` from `@stigmer/sdk` with compact "Try again" / "Dismiss" buttons. Rationale: maintains compact density of ConnectBar; the backend (T03) already cleaned up error messages.
3. **Helper functions for health mapping**: Extracted `healthPillProps()` and `inlineHealthProps()` instead of deepening ternary nesting in JSX. Cleaner, easier to extend when T07 adds BYOA states.
4. **All new props are optional**: `McpServerOAuthSignInProps` gains 5 optional fields. Existing consumers (`McpServerPicker`) work without changes.
