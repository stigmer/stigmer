## Learnings

- stigmer-cloud uses `directory: ../../stigmer/apis` as the buf input (local sibling path), so proto changes propagate immediately without buf.build publishing
- `make codegen` in stigmer also triggers Gazelle BUILD.bazel regeneration as a side effect, touching many unrelated BUILD.bazel files
- `buf lint` and `buf format` run as part of `make codegen` via the `apis build` target
