## Decisions Made

- **ManagementSidebar lives in `client-apps/web`**: It's Console-specific (fails the "platform builder" test). Platform builders don't need Stigmer's admin navigation shell.
- **Shared internal lib deferred**: The demo views in `site/` are deliberately simplified schematic illustrations, not functional navigation. Creating a shared lib to unify them with real Console components would require abstracting routing, auth, and org context — premature abstraction with no second consumer.
- **`/settings` redirects to `/settings/members`**: Members is the first nav item and the most common settings destination.
- **Sidebar state shared across zones**: `useSidebarOpen()` localStorage state persists across agent/management zone transitions — collapsing the sidebar in one zone keeps it collapsed in the other.
