## Decisions Made

- **Auto-close via pathname effect, not per-link onClick**: A single `useEffect` keyed on `pathname` in AppShell covers all navigation from both sidebars. No per-link wiring needed; future links get the behavior for free.
- **Intentional exhaustive-deps suppression**: `sidebar` is excluded from the dependency array to prevent the effect from re-firing when the sidebar opens/closes (which would immediately close the sidebar after the user opens it on mobile).
- **Breakpoint constant co-located with sidebar state**: `LG_BREAKPOINT` lives in `use-layout-state.tsx` alongside `useSidebarOpen()`, keeping layout concerns together.
- **Session Sidebar pushState gap acknowledged but deferred**: Session clicks use `window.history.pushState` (not Next.js `<Link>`), so `usePathname()` doesn't detect them. This is an existing separate concern — ManagementSidebar uses `<Link>` exclusively so the fix works fully there.
