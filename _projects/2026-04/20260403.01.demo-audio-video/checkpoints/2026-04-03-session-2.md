## Decisions Made

- **`edge-tts-universal` over `edge-tts`**: The npm package `edge-tts` refers to an older, less-maintained package. `edge-tts-universal` is the modern TypeScript rewrite with zero dependencies and comprehensive word-boundary metadata.
- **Separate cache file**: `.narration-cache.json` stores hashes and durations separately from `manifest.json`. This keeps the runtime manifest matching the `NarrationManifest` contract exactly without build-time metadata leaking in.
- **Duck-typed step discovery**: The script finds the steps array by looking for an export that's an array of objects with `delayMs`, rather than requiring a specific export name. This works with all 10 scenario files.
- **`mod.default` interop**: Dynamic `import()` via `tsx` places named exports under `mod.default` due to CJS/ESM interop. The script uses `mod.default ?? mod` to handle both cases.

## Learnings

- Edge TTS word-boundary metadata uses 100-nanosecond units for offset and duration (divide by 10,000 to get milliseconds)
- The `EdgeTTS` simple API returns `{ audio: Blob, subtitle: SubtitleEntry[] }` where subtitle entries have `{ offset, duration, text }`
- Edge TTS generates ~28KB for a short sentence (~4 seconds of audio) at 48kbps mono MP3
- Cached re-runs complete in ~2 seconds vs ~8 seconds for fresh generation
