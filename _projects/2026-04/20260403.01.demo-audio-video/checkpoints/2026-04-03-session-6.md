## Decisions Made

- **No `-s` flag for serve**: SPA mode falls back all 404s to index.html; clean URLs work without it
- **Direct auto-play for export**: Bypass IntersectionObserver in video export mode since headless browsers are unreliable
- **Dual format discovery**: Handle both .html files and subdirectories for scenario discovery (Next.js static export behavior)
- **Pipeline-only Remotion migration**: Follow-up project will only replace the recording pipeline, not modify demo components

## Learnings

- Node 23 silently breaks Next.js static export (exits 0, no out/ directory)
- Playwright VP8 recording degrades dark UI content; screenshots from same instance are crisp
- IntersectionObserver may not fire in headless Chromium for elements visible at page load
- `serve -s` and clean URL resolution are different behaviors — SPA fallback is not what we need for multi-page static sites
