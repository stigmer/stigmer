## Decisions Made

- **Single proto field over client-side merging**: Adding `cross_org_public` to `SearchRequest` keeps the query atomic and preserves server-side pagination, versus making two separate API calls and merging client-side
- **Unified `buildScopeFilter`**: In the Go backend, merged the previously separate `buildOrgFilter` and `buildVisibilityFilter` methods into a single `buildScopeFilter` because org and visibility now interact via `cross_org_public`
- **Semantic: "All" always scopes to active org**: React hooks always pass the active org's ID in the `org` field — "All" toggles `crossOrgPublic: true` to include public resources from other orgs, not an empty `org` field
- **Cross-org private grants excluded from "All"**: Confirmed with user that private resources from other orgs should never appear in the "All" library listing even if the user has explicit FGA access

## Learnings

- Codegen binary (`tools/generator`) must be rebuilt after modifying Go codegen templates — the generated output comes from the binary, not the source files directly
- The `sdk/go/gen/*` public API files and `sdk/go/internal/gen/*` internal files are separate codegen targets; changes to `ListParams` only affect the `internal/gen/` path
