## Decisions Made

- **UNSPECIFIED = approved**: Backwards-compatible default so existing OAuthApps without the field work exactly as before
- **Inline enrichment over separate fetch**: Backend resolves OAuthApp ref and copies approval fields onto McpServerAuth at query time, avoiding an extra API call from the frontend
- **Manual override preserved**: Even when vendor approval is pending, users can still connect via manual token entry
- **Proto placement**: `VendorApprovalStatus` enum lives in `OAuthAppSpec` (source of truth), surfaced on `McpServerAuth` as read-only enrichment
