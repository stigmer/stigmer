## Decisions Made

1. **Official first-party servers over archived references**: The `modelcontextprotocol/servers` monorepo archived most reference servers (PostgreSQL, SQLite, GitLab, Brave Search, Slack, Google Drive, Google Maps, Puppeteer, Sentry) as of May 2025. Replaced with vendor-maintained alternatives where available (Brave, Sentry, Slack, GitLab, Google Maps, Atlassian all have official servers now).

2. **Dropped 6 servers from original plan**:
   - Docker MCP Gateway: Cannot run without Docker engine (it's a CLI plugin, not npm/pypi)
   - Google Drive: No quality replacement (community options have 3 stars)
   - Puppeteer: Redundant with Playwright (30K stars, Microsoft official)
   - LinkedIn, Zendesk, Shopify: Already dropped in planning (TOS risk, low quality, 404 repo)

3. **No Docker as transport**: Platform does not support Docker as a stdio command. Go-based servers use `go run` (same pattern as `mcp-server-stigmer.yaml`).

4. **Tags in spec.tags**: Marketplace discovery tags placed in `spec.tags` (proto field 3, designed for marketplace categorization) rather than `metadata.tags`. Updated CONTRIBUTING.md template to reflect this.

5. **PostgreSQL via uvx**: Used `postgres-mcp` from CrystalDBA (110K monthly PyPI downloads) instead of archived `@modelcontextprotocol/server-postgres`.

6. **SQLite via npm community**: Used `mcp-sqlite` from jparkerweb (93 stars, actively maintained) instead of archived reference implementation.

## Learnings

- The MCP ecosystem has matured significantly since the planning phase. Many vendors (Brave, Sentry, Slack, GitLab, Google Maps, Atlassian, Figma, Linear, Notion) now offer hosted MCP servers at their own domains, using Streamable HTTP + OAuth. This is the direction the ecosystem is moving.
- The `modelcontextprotocol/servers` monorepo (83K stars) now serves primarily as a reference implementation home for a small set of utility servers (Fetch, Filesystem, Git, Memory, Sequential Thinking). Product-specific servers have migrated to vendor repos.
- AWS has 66+ MCP servers in `awslabs/mcp`. We picked 3 broadly useful ones (Documentation, CDK, Lambda). More can be added as needed.
- Some servers (Neon, Supabase, Twilio) pass auth credentials as positional CLI arguments rather than environment variables. The proto's `${VAR_NAME}` substitution in `StdioServerConfig.args` handles this correctly.
