## Decisions Made

- **TimeSource as context** — Keeps scenario components untouched; engine components self-detect Remotion mode
- **91% fill over 100%** — User reviewed both, preferred subtle dark framing for visual balance
- **CSS variable for AppShell height** — `var(--demo-shell-height, 380px)` allows video compositions to override without touching the default docs value
- **Zoom compensation in Cursor** — `(eRect - cRect) / zoom` where `zoom = cRect.width / container.offsetWidth` — robust to any CSS zoom factor, not hardcoded to 2×

## Learnings

- **CSS zoom and getBoundingClientRect** — `getBoundingClientRect()` returns viewport coordinates (post-zoom), but `position: absolute` inside a zoomed parent uses pre-zoom CSS coordinates. Must divide by effective zoom.
- **Remotion + Framer Motion** — Remotion patches `requestAnimationFrame` and `performance.now()`, so Framer Motion spring animations work across frames. The blocker was `setTimeout` delays in `Cursor.tsx`, not Framer Motion itself.
- **Remotion effect cascading** — Remotion does wait for React state updates to settle across multiple `useEffect` → `setState` → re-render cycles before taking the screenshot.
