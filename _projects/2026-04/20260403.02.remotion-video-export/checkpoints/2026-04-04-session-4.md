## Decisions Made

- **VideoExportContext stays**: It provides `hideControls` and `initialMuted` to ScenarioPlayer, which Remotion's DemoVideo.tsx still uses. Not Playwright-specific.
- **`isVideoExport` guard stays**: The IntersectionObserver effect checks both `timeSource` and `isVideoExport`. With Remotion, `timeSource` already short-circuits, but keeping `isVideoExport` provides defense-in-depth.
- **`playbackComplete` variable stays**: Still used as a guard in the timer effect. Only the `data-playback-complete` DOM attribute (read by Playwright's `waitForSelector`) was removed.
- **Export route pages fully removed**: The `app/demos/export/` directory contained layout, page, and ExportShell — all existed solely for Playwright to navigate to. Remotion bundles its own React app.

## Learnings

- The cleanup was straightforward because the Playwright and Remotion pipelines share only `VideoExportContext` — the rest of their code paths are fully independent. Good architectural separation from Phases 2-3.
- The `__exportTimeline` and auto-play effects in ScenarioPlayer were properly guarded with `if (timeSource || ...) return;`, which made them dead code in the Remotion path. This shows the TimeSource design was forward-looking.
