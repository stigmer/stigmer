## Decisions Made

- **Go CLI integration deferred**: The existing Go rendering layer is ~37K lines of well-tested code. Building the SDK package first, evaluating Go CLI integration later (user agreed with this phased approach).
- **`customTransport` on SDK**: Added to `StigmerConfig` rather than creating a separate Node client class — cleaner, non-breaking, benefits all Node.js consumers.
- **`dom` in Ink tsconfig**: Added `"dom"` to Ink's tsconfig lib because `@stigmer/react`'s barrel re-exports DOM components. The Ink package itself uses no DOM APIs — this is a workspace resolution artifact.
- **marked@^15 + marked-terminal@7.3.0**: marked@18 was incompatible with marked-terminal's peer dep (`<16`). Pinned to marked@^15.
- **Ink 7**: Used latest Ink 7.0.0 (requires React >=19.2.0) — compatible with our React ^19 peer dep.
- **Auth on custom transport**: Caller is responsible for auth interceptors when using `customTransport`. The Ink package's `createNodeTransport` wires auth automatically.
