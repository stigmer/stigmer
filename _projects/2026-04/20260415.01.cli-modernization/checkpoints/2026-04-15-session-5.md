## Decisions Made

- **gRPC-web over Connect protocol**: The Stigmer API server expects gRPC-web, not the Connect protocol. The web SDK also defaults to gRPC-web. Using `createGrpcWebTransport` from `@connectrpc/connect-node` ensures protocol parity.
- **Rename `src/bin/` to `src/cli/`**: Avoids collision with root `.gitignore`'s `bin/` pattern. Cleaner than adding a negation rule, and `cli/` is a more standard convention for TypeScript CLI entry points.
- **Synthetic stdin for non-TTY**: Passing a custom `Readable` stream to Ink's `render()` when stdin isn't a TTY. Ink's internal App component treats custom stdin's `setRawMode` as a no-op.
- **Debug mode for non-TTY**: In non-interactive mode, Ink only writes the final frame at unmount. Setting `debug: !isTTY` outputs each render frame separately.

## Learnings

- Unit tests can pass with the wrong transport protocol because mocked transports bypass ConnectRPC wire format. E2E against a real backend is essential.
- Ink 7's raw mode error ONLY throws when `stdin === process.stdin` — custom stdin gets a no-op.
- The root `.gitignore` `bin/` pattern silently excludes nested `bin/` directories in SDK packages. Renaming is cleaner than negation patterns.
