## Decisions Made

- **No deprecation alias for `discover`**: Clean break. Pre-1.0 CLI — dead code is worse than a breaking change
- **Remove ALL well-known env auto-injection**: Not just from connect, but from agent run, workflow run, and draft too. Two credential channels: OAuth (managed by platform) or manual (shell env / `--env`)
- **Web-console-assisted OAuth**: CLI opens the web console's MCP server page, user clicks "Connect with OAuth", CLI polls `getOAuthGrantStatus`. No proto changes, no frontend changes.
- **Console URL resolution**: `STIGMER_CONSOLE_URL` env var > local `localhost:8234` > cloud `app.stigmer.ai`
- **Polling**: 5-minute timeout, 3-second intervals (matches auth login precedent)
- **`--env` escape hatch**: explicit env overrides bypass the OAuth check entirely
