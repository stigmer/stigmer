## Decisions Made

- **Single generated reference page** instead of multi-page: Ink has 15 exports vs React's 100+; splitting would create sparse pages. Better reader experience with one scannable page organized by category sections.
- **Re-exports link, not re-document**: `createNodeClient`, `createNodeTransport`, `NodeClientConfig` are re-exported from `@stigmer/sdk/node`. Integration guide explains usage; generated reference links to SDK Overview.
- **Strategic example coverage**: Added `@example` only to user-facing entry points (`InkStigmerProvider`, `SessionApp`, `SessionView`, `renderMarkdown`). Leaf components used internally by composed views don't need standalone examples.
- **Shared typedoc-types**: Generator re-exports TypeDoc JSON types from React generator rather than duplicating them.
