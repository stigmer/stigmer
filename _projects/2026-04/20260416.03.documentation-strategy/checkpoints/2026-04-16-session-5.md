## Learnings

- The `tsdoc:check` gate immediately caught real issues (8 TypeDoc warnings in React SDK) that the freshness checks would never surface — freshness only checks that committed files match regenerated output, not that the TypeDoc config is complete
- The CI trigger gap for `sdk/react/**` was a subtle issue: the freshness check existed in the pipeline but never ran for React SDK changes because the trigger paths didn't include it
- Running `make check` end-to-end as the final validation step is essential — it catches pre-existing issues across the full toolchain that individual pipeline tests miss
