## Decisions Made

1. **Login page placement**: `auth/login/` rather than `domain/_shared/auth/` — the domain README lists `auth/` as a top-level sibling for OIDC/session infrastructure
2. **GitHub callback placement**: `auth/github/` — keeps OAuth helpers co-located with the view
3. **Token granularity**: Collapsed 5 `bg-muted/*` opacity levels into 2 tokens (`muted-faint` for /20-/30, `muted-subtle` for /40-/60), and 4 `border-border/*` levels into 1 (`border-muted`)

5. **SDK bridge gap**: Wired all missing tokens into `sdk/react/src/styles.css` — sidebar tokens, backdrop, primary-hover, all *-subtle variants
