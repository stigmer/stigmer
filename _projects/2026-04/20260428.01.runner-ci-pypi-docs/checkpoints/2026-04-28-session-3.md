## Decisions Made

- **graphton published separately** — not bundled. It's a substantial library (~35 modules) with its own dependency tree. Publishing separately follows the protos→SDK pattern.
- **Hatchling over Poetry** — PEP 621 native, matches the Python SDK, cleaner for library distribution.
- **Docker uses pip + requirements.txt** — eliminated Poetry as a Docker build dependency. The existing `requirements.txt` was already maintained for the CLI embedding pipeline.
- **Thin main.py wrapper** — preserves Docker `CMD [python, main.py]` without changes while the real entry point is `stigmer_runner.__main__:main`.
