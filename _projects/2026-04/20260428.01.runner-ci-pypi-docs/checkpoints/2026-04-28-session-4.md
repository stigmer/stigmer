## Learnings

- The Python agent-runner (`worker.py`) only connects to Temporal and executes activities. It does NOT register the runner, send heartbeats, or handle server commands. All of that is in the Go CLI (`start.go`, `runner_stream.go`, `runner_stream_commands.go`).
- The `ghcr.io/stigmer/agent-runner` Docker image is the CLI default but no current CI workflow pushes it. The Planton service hub has `disablePipelines: true`.
- The CLI hardcodes the cloud Temporal address (`stigmer-prod-temporal-frontend.planton.live:7233`) in `runner_env.go`. There's a TODO comment about having the backend return this at registration.
- Vale linter requires backtick-quoting for technical terms like `Tauri`, `subprocess`, `venv`, `systemd`.
