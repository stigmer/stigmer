## Decisions Made
- **Separate `RunnerSendCommandInput` oneof** rather than embedding `RunnerCommandRequest`: keeps external API clean, decouples from stream protocol internals
- **`can_view` permission** for sendCommand: if you can see the runner, you can send read-only commands
- **Local-first routing in Cloud**: check `isConnectedLocally()` before falling back to Redis coordinator
- **`OperationHandlerV2` directly** (not CRUD pipeline) for Java handler: matches precedent set by `RunnerConnectHandler` for non-CRUD operations
- **Phase gate before stream check**: returns specific `FAILED_PRECONDITION` errors (stopped/pending/failed) instead of generic "not connected"
