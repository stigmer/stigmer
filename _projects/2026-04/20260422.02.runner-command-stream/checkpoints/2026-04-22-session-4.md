## Decisions Made

- **Exported `CommandStream` interface**: Originally planned as unexported `commandStream`, but the standalone runner (in a different package) needs to pass the SDK stream as a factory return value. Exported the interface to `CommandStream` so both packages can use the same `RunnerStreamClient`.
- **Separate WaitGroup for stream**: The daemon already has a WaitGroup for the health monitor. Rather than mixing concerns, the stream gets its own `streamWg` — cancelled before children stop (so STOPPED heartbeat is sent while the server is still up).
- **PermitWithoutStream: true for daemon SDK client**: The daemon's SDK client is created specifically for the persistent stream, so keepalive pings should flow even before the stream is established (handles reconnection windows).
- **current_executions = 0**: Deferred file-based IPC with Python agent-runner per T01 plan. The heartbeat reports 0 for now.

## Learnings

- Bazel CLI builds fail with `@com_github_stigmer_stigmer_sdk_go` — the SDK Go module is resolved via `go.mod` replace directives, not Bazel. CLI packages are built with `go build`, not `bazel build`. The stigmer-server packages use Bazel successfully because they reference `apis/stubs/` directly.
