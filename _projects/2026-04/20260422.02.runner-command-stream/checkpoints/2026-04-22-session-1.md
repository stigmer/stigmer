## Learnings

- The `stigmer-codegen` tool does not handle bidi streaming RPCs. This is the first bidi stream in the proto set. The tool generated a unary-style call for `Connect`. Manual fix applied to the generated file; the codegen tool needs a future patch.
- The `grpc.BidiStreamingServer[T, U]` generic type (Go 1.21+ gRPC) is now used in the generated interface — the server handler signature is `Connect(grpc.BidiStreamingServer[RunnerStreamClientMessage, RunnerStreamServerMessage]) error`.
