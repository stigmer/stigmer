## Decisions Made

1. **CSS `zoom` over `transform: scale()`** — consistent with DemoVideo.tsx, transparent to Cursor.tsx, changes layout geometry naturally
2. **Canonical 896x380** — matches max-w-4xl and DEMO_SHELL_HEIGHT, zoom = 1 at desktop (visually identical)
3. **Min zoom 0.5** — prevents demos from becoming unusably small; real mobile story deferred to DemoScope product design
4. **containerRef prop API** — simpler than render-prop; scenarios keep their own refs, DemoViewport applies them to the inner div
5. **Detail demos excluded** — no interaction bug, different rendering needs, compatible API if needed later
6. **Video-export passthrough** — DemoViewport checks isVideoExport and renders a simple wrapper, deferring to DemoVideo.tsx

## Learnings

- CSS `zoom` on a parent correctly adjusts `getBoundingClientRect()` for all descendants — the Cursor.tsx zoom correction `cRect.width / container.offsetWidth` handles nested zoom levels (DemoViewport zoom + DEMO_CONTENT_ZOOM) transparently
- `scrollIntoView()` operates in layout space within the scroll parent, unaffected by ancestor zoom
- The fixed viewport approach completely eliminates the scroll-position-stale-on-resize problem, making T02 unnecessary
