## Decisions Made
- **Explicit naming over auto-suffix**: decided against auto-naming second runners to `hostname-2`. Users must provide `--name` for additional runners. Rationale: auto-suffix creates hard-to-reference runners and encourages accidental proliferation.
- **Runner names are slugs**: `--name` value serves triple duty as local state key, server-side slug, and display name. Max 63 chars, lowercase alphanumeric + hyphens. Slug validation lives in the runner package for now, extractable later.
- **Local-only runner listing**: `stigmer list runners` reads `~/.stigmer/runners/*.json` files, no backend connection. Server-side listing deferred to web UI (T08-T09).
- **Reaping is proactive, not passive**: stale state files are removed during startup and listing, not just filtered out.

## Learnings
- The `display.Table` abstraction with `WithAdaptive()` handles terminal width gracefully — no need for custom formatting.
- PID-based stale detection works well for local runners. For remote/cloud runners, heartbeat-based staleness (already in the proto) is the right model.
