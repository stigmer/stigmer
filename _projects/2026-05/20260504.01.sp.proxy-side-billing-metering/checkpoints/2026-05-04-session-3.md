## Decisions Made

- **requested_model**: Decided to add now (not defer). Parsing request body JSON in the proxy to extract the model field gives full audit trail.
- **finish_reason**: Both providers. OpenAI tracked across events (separate chunk from usage). Anthropic trivial (same event as output tokens).
- **ProxyUsageReporter vs gRPC handler**: Reporter uses domain services directly (bypasses gRPC pipeline + FGA). The proxy IS the trusted operator — no authorization needed for in-process billing.
- **No TeeInputStream class**: Inline buffer loop is clearer for a single call site. Avoids abstraction overhead.
- **Error handling**: All usage/billing in try-catch. Never propagate exceptions to the streaming response.
