## Decisions Made

- Response rules are redundant when an agent has custom instructions — Cursor already has built-in response rules, and the agent's instructions provide behavioral guidance
- Single-dir workspace context is redundant with the SDK's `local: { cwd }` parameter — the model discovers its workspace organically through tool use
- Skills, sub-agents, and instructions MUST remain in continuation prompts — a fresh agent (after eviction) has zero prior context and genuinely needs these for identity
- Continuation contract (158 tokens) is kept intact — critical behavioral guardrails for fresh agents
- MCP surface optimization deferred — Cursor SDK has no `enabledTools` / `allowedTools` / lazy loading; only lever is include/exclude entire servers

## Learnings

- With typical content, the continuation prompt is only ~923 tokens — well under the 8k ceiling. The real cost explosion happens with long agent instructions (multi-page), not framework sections
- The Cursor SDK `McpServerConfig` type has no tool-level filtering — only connection parameters
- The `tools` field in `SDKSystemMessage` is output-only (agent reports available tools), not an input parameter
