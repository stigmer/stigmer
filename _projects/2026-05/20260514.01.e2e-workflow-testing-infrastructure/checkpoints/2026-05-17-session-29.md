## Key Decisions

1. **Temporal SDK interceptors over manual spans** — Both Python and TypeScript SDKs have first-party OTel interceptors that handle W3C traceparent propagation automatically; no need to manually inject/extract trace context
2. **Lazy imports (Python)** — OTel packages imported inside `init_tracing()` to avoid loading when tracing is disabled
3. **Dynamic import (TypeScript)** — Used `await import()` for ESM compatibility; `require()` would fail in the ESM module
4. **Activity-level spans only** — Application-level spans (LLM calls, MCP tool invocations) deferred to future work; Temporal activity spans fill the distributed trace gap
