## Decisions Made

| Decision | Choice | Rationale |
|---|---|---|
| Authorization bypass level | Replace `IamPolicyGrpcRepo` impl | Single bottleneck — covers all 50+ handlers without modification |
| List operation handling | MongoDB-backed `listAuthorizedResourceIds` | Returns all document IDs so list handlers work correctly |
| Collection name mapping | `ApiResourceKind.name()` = MongoDB collection name | Convention verified across all repos |
| OpenFGA Testcontainer | Not needed | Permit-all bypass is standard; OpenFGA can be added later for IAM-specific tests |
| VendorOAuthReconciler | No action needed | Vendor credentials not configured in test mode → FGA write path never reached |

## Learnings

1. `IamPolicyGrpcRepo` is the single funnel for ALL authorization — pipeline steps, direct handler calls, policy CRUD, impersonation guards
2. MongoDB collection names exactly match `ApiResourceKind.name()` — no separate mapping needed
3. `OpenFgaConfig`/`OpenFgaClientConfig`/`OpenFgaWriter` beans instantiate fine with null config (no NPE at construction) — they just can't be called
4. `VendorOAuthReconciler` is safe because `credentials.isConfigured()` returns false when env vars are missing
