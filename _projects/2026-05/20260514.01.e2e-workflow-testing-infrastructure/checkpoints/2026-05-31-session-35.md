## Decisions Made

- **Runtime fix over docs-only**: Single quotes are the de facto standard in seedpack, docs, and user workflows — normalize at evaluation time rather than forcing authors to escape double quotes
- **Lexer over regex**: Naive regex replacement is unsafe; character-by-character state machine handles nested quotes, backslashes, and comments correctly
- **Replay-safe placement**: Normalization runs inside `EvaluateExpressions` local activity — Temporal replays cached results, not re-executed code
- **emit_event gap deferred**: Golden tests provide coverage; lower priority than HITL/switch/expression gaps
