## Decisions Made

| Decision | Choice | Rationale |
|---|---|---|
| Auth bypass | Test Spring profile with `@ConditionalOnProperty` | Follows existing Stripe pattern, zero production risk, simplest harness |
| Service startup | Fat JAR as child process | Simpler networking, faster iteration, no registry dependency |
| Interceptor graceful degradation | `ObjectProvider<MachineAccountJwtProvider>` | Avoids guarding every bean in the in-process channel dependency chain |
| Context builder skip | `InterceptorContextHolder.hasContext()` check | Prevents identity resolution from overwriting test caller identity |

## Learnings

1. Spring Boot's `@ConditionalOnProperty` with `matchIfMissing = true` provides a clean production-safe toggle
2. `InProcessGrpcAutoConfiguration.inProcessChannelAsSystem()` depends on `InProcessMachineAccountTokenInjectorInterceptor` by concrete type — guarding it with a conditional breaks the entire in-process channel chain
3. `GrpcRequestContextBuilderInterceptor` runs at ORDER + 1 after our test interceptor at ORDER - 1, and re-resolves caller identity from SecurityContext — needs explicit skip when context already set
4. MongoDB Testcontainers runs without auth by default; Spring Boot's `spring.data.mongodb.password` binding to `char[]` fails on empty string — use `SPRING_DATA_MONGODB_URI` override
5. The fat JAR is ~139MB; incremental Bazel rebuild takes ~5-15s; cached startup is instant
