## Key Design Decisions

1. **`-skip` over separate quarantine workflow**: Uses Go's native `-skip` flag instead of a parallel CI workflow — no infrastructure duplication
2. **Rerun limit of 2, max-failures of 5**: Prevents masking widespread breakage while catching genuine flakes
3. **`--rerun-fails-run-root-test`**: Critical for table-driven subtests that share `TestMain` setup
4. **Expiry dates on quarantine entries**: Prevents quarantine from becoming a graveyard of ignored tests
5. **Go tool over shell script**: Proper JSON parsing, unit-tested, extensible for future trend tracking
6. **Stress uses `-count=3`**: Balances flake detection effectiveness against CI run time
