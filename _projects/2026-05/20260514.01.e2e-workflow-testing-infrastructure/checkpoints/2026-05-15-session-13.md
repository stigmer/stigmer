## Decisions Made

- **`ByteString` → `byte[]` in `SystemActivities` interface**: Temporal's Jackson-based data converter cannot deserialize protobuf `ByteString`. Changed the activity interface to use `byte[]` with a note in Javadoc. This is the correct approach — `byte[]` is natively handled by Jackson.
- **Planton CLI for secret retrieval in Makefile**: `planton service secrets get-value --org stigmer --group anthropic --name prod.api-key 2>&1` — the CLI writes values to stderr (not stdout), so `2>&1` redirect is required for shell capture.
- **`ensure-service-jar` as dependency**: Both `test-integration` and `test-integration-providers` depend on `ensure-service-jar` which auto-builds if missing, using sibling `stigmer-cloud` checkout.

## Learnings

- Planton CLI writes secret values to **stderr**, not stdout — command substitution needs `2>&1`
- `go test` sets cwd to the package directory, not the repo root — relative paths must account for this
- Temporal's Jackson data converter cannot handle `protobuf.ByteString` — always use `byte[]` for activity parameters
- Anthropic API key access is model-dependent — the test key only has access to Claude 4 models, not Claude 3.5
