## Decisions Made

## Learnings

- The `@cursor/sdk` `CursorAgentPlatformOptions` type is re-exported from an internal package `@anysphere/cursor-sdk-local-runtime/run-store` — import it from `@cursor/sdk` directly
- The SDK caches platform instances by `${workspaceRef}:${stateRoot}` — using a synthetic key ensures no collisions with other SDK users on the same machine
- `getDefaultSdkStateRoot` internally does `md5(workspaceRef)` — our explicit stateRoot bypasses this entirely
- File permission issues with Read/Write tools were worked around using shell commands (macOS extended attributes on cursor-runner files)
