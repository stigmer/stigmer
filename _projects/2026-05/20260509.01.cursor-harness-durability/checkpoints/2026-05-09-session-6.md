## Decisions Made

- **Dedicated RPC over full-document replace**: Eliminates lost-update race condition
- **Full replacement semantics**: Runner builds complete memory each time, server replaces wholesale
- **Activity mirrors RPC**: Gives workflow a local-activity write path for Task 7
- **readSessionContext bundles three fields**: Single DB read for threadId + memory + cursorMode
- **cursorMode as int in DTO**: Avoids Temporal Jackson proto enum deserialization issues
- **Preserved readSessionThreadId**: Backward compat for in-flight workflows
