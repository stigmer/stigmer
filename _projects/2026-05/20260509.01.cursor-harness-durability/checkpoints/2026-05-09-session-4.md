## Decisions Made

- **DD: New file, not extension of prompt-builder.ts**: `prompt-builder.ts` handles "what the agent IS" (blueprint identity). `continuation-prompt.ts` handles "what the agent HAS DONE" (durable memory). Orthogonal concerns → separate modules with shared utility functions.
- **DD: Task 2b delivers pure functions only; Task 3 wires prompt selection**: The mode/resumed/isCloudAgentExpired signals come from Task 3's changes to resolveAgent(). Task 2b stays independently testable and shippable without behavioral changes.
- **DD: Continuation prompt is a COMPLETE prompt, not a supplement**: Fresh agents know nothing. Includes full agent identity (reuses exported helpers from prompt-builder) + all memory sections + user message.
- **DD: HITL memory subset excludes heavy fields**: HITL reinvocation only needs approval context + orientation. `changed_files`, `open_tasks`, and `tool_observations` are excluded to keep the prompt lean for a narrowly-scoped task.
- **DD: Agent rationale = last AI message, truncated to 500 chars**: Heuristic extraction without LLM. The last AI message before denial typically contains the agent's explanation of intent.
- **DD: Git utilities fail silently, never throw**: `getGitBranch` and `getGitHeadSha` return empty strings on any error. HITL diagnostics are best-effort; partial data is acceptable.
- **DD: 8k token budget with progressive truncation**: Priority order is `recent_turns` → `tool_observations` → `durable_summary`. Agent identity and contract sections are never truncated.

## Learnings

- The enum member for user messages is `MessageType.MESSAGE_HUMAN`, not `MESSAGE_USER`. Proto enum naming follows the Go convention of prefixing members with the enum name.
- `toContain` in vitest matches substrings anywhere — assertions for "section not present" must use a more specific pattern (e.g., the section tag + following content line) to avoid false positives from the tag being mentioned within other sections' prose.
- `execSync` in Node.js includes a trailing newline in `stdout.toString()`. Always `.trim()` git output.
