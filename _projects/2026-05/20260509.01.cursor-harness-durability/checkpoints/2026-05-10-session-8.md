## Design Decisions

- **DD-Q1: Skip platform options for cloud agents** — `resolvePlatformOptions` solves a local-only problem (SQLite store keying in Daytona sandboxes). Cloud agent state lives on Cursor's servers. Passing platform options to cloud calls is semantically meaningless. Cloud create/resume functions receive no platform options.
- **DD-Q2: Raw user message for live cloud agents** — Cloud agents natively retain conversation history. Sending continuation prompts to a live cloud agent would duplicate context and risk contradictions. Continuation prompts fire only on the fallback path (cloud agent expired, fresh agent created with Stigmer memory as backup).

## Observations
