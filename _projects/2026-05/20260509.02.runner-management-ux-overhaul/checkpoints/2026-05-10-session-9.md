## Decisions Made

- Scope orphan detection to socket-equipped runners only (T04+ backward compat)

## Key Code Changes

- `state.go`: New `isOrphaned()`, `killOrphanedRunner()`, `killProcess()` helpers; enhanced `isRunnerAlive()` with orphan detection
- `state_test.go`: 9 new tests covering orphan detection, process liveness, and CursorRunnerPID serialization

## Learnings

- The runner is a tri-process system: Go parent (heartbeat + control socket) + Python agent-runner + TypeScript cursor-runner
- When Go parent dies, children survive as orphans but the runner is non-functional (no heartbeat, no socket)
- `isRunnerAlive()` returned true for orphans because it only checked if the PID existed, not whether the runner was functional
- The cursor-runner was never cleaned up by `stopNativeRunner` — only the agent-runner PID was killed
