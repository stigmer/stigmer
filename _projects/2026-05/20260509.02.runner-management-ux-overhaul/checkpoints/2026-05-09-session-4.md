## Decisions Made

- **HTTP over Unix socket (Docker/containerd pattern)**: Go's `net/http` + `net.Listen("unix", ...)` handles this natively. Debuggable via `curl --unix-socket`. No custom framing or gRPC overhead for local IPC.
- **Short, flat socket path (`~/.stigmer/run/runner.sock`)**: Research report proposed deep nested paths that would exceed macOS's 104-byte `sun_path` limit. Flat path is ~35 chars from home dir.
- **Minimal RPC scope (`GET /status`, `POST /stop`)**: Deferred restart, pause/resume, logs, adopt to future phases. Minimal surface validates the pattern without over-engineering.
- **State migration via copy-then-remove**: `MigrateStateLayout()` writes the new file first, only deletes the old file on success. Original untouched on failure.
- **Socket health preferred, PID fallback preserved**: `isRunnerAlive()` tries socket first when `SocketPath` is set, falls back to PID probe for startup races and pre-T04 runners. Fully backward compatible.
- **`stopFn` uses channel, not context cancel**: Control socket's stop handler sends to a buffered channel that `waitForExitOrSignal` selects on, keeping the same SIGTERM-then-SIGKILL escalation path used for OS signals.
- **Desktop/Tauri integration deferred to T05**: T04 is CLI-only to manage complexity and validate the socket pattern before Desktop consumes it.
