## Decisions Made

- **crypto/rand over ULID**: Avoided new dependency. `mach_` + 32 hex chars (128 bits). Self-describing, no dashes, safe everywhere.
- **RunnerConnectionInfo over RunnerSpec**: machine_id is auto-generated host metadata, not user-declared state. Same category as hostname/os/arch.
- **Client+Proto only scope**: Server-side uniqueness enforcement deferred to T07. Local adoption delivers immediate value without backend migration risk.
- **Daemon omits machine_id**: Circular dependency (daemon ← runner). Empty string is harmless; server ignores until T07.
- **Slug stays hostname-derived**: machine_id is for dedup, slug is for humans. Two-layer model preserves backward compat and URL readability.
