## Decisions Made

- **Hand-rolled HTTP over Unix socket** instead of `hyper`/`hyperlocal` — two trivial endpoints (`GET /status`, `POST /stop`) don't justify a heavy dependency. Uses `tokio::net::UnixStream` with raw HTTP/1.1.
- **File-based preferences** (`~/.stigmer/desktop/preferences.json`) instead of `tauri-plugin-store` — two booleans don't warrant a plugin dependency.
- **Callback-based ensure** — `useAutoEnsure` accepts an `onEnsure` callback rather than owning credential logic. Keeps auth context management in the page component.
- **Socket-first, disk-fallback, server-merge** data strategy — socket = truth for local liveness, server = truth for backend awareness.
- **Opacity modifier fix** — replaced `hover:bg-background/60` with `hover:bg-muted-subtle` per `stigmer/no-token-opacity-modifiers` lint rule.
