## Decisions Made

- **Sidecar YAML reuse**: Discovered existing sidecar YAML files at `apis/ai/stigmer/agentic/workflow/v1/tasks/meta/` -- reused them instead of creating duplicates in `tools/codegen/meta/tasks/`
- **No generated index.mdx**: The handwritten `workflow-tasks.mdx` serves as the parent/overview page; the generated per-task pages are sub-pages under it. Avoids conflicting with the directory/file naming in Fumadocs.
- **Proto field names in TypeTable**: Used raw `protoField` (snake_case) in `<TypeTable>` field names rather than camelCase, since task config is YAML-facing and users think in YAML field names
- **Cycle detection**: Added visited-set tracking in `taskDocsCollectEnums` to prevent infinite recursion on self-referential types like `WorkflowTask`
