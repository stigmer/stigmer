## Decisions Made

- **Options over env vars**: `StigmerRunnerOptions` typed interface, not `process.env`. `main.ts` bridges from env to options.
- **Mode is derived**: `proxyEndpoint` presence activates cloud mode. No explicit `mode` field in the public API.
- **OTel excluded from factory**: Global telemetry state is the consumer's responsibility. The Temporal OTel activity interceptor is still wired internally.
- **Fetch interceptor internal**: Factory handles the import ordering constraint. Consumer just passes `proxyEndpoint`.
- **`Config` untouched**: New `StigmerRunnerOptions` maps to existing `Config` via a private function. No internal API breakage.
