- **DD-T05E-DIVERGENCE**: Recommended aligning Cloud archival to match OSS (archive new version, every push).

## Key Discoveries

- OSS `ArchiveCurrentSkillStep` runs AFTER field population (step 8), BEFORE DB persist (step 10) — archives the fully-built NEW skill. Every push, including creates.
- Cloud `ArchiveCurrentVersion` archives the EXISTING/PREVIOUS skill BEFORE writing the new one. Skips first push and same-hash pushes.
- Only Skills have audit archival in either edition. Agents and MCP Servers have none.
- OSS `store.ListAuditHistory()` returns `[][]byte` (serialized protos), sorted by `archived_at DESC, id DESC`
- Cloud `SkillAuditRepo.findAllBySkillId()` returns `List<Skill>` (deserialized from BSON), sorted by `archivedAt DESC`
- Cloud `SkillAuditRepo.findAllBySkillId()` exists but is not referenced from any handler — only from migration docs
