## Decisions Made

- **Toolbar coexists with hover buttons** (not replaces) — matches n8n/Retool convention. Hover for quick surgical actions, toolbar for comprehensive selected-node actions.
- **Shared mutable `pickerAnchorRef`** — one `TaskPickerPopover` instance, anchor swapped before opening. Avoids duplicating popover state/DOM.
- **`canvas-icons.tsx` is internal** — not exported from SDK barrel. Shared between `CanvasContextMenu` and `CanvasTaskNode`.
- **`ToolbarButton` uses `forwardRef`** — required for the toolbar "Add Task After" button to serve as picker anchor.
- **28x28 touch targets on toolbar buttons** — Fitts's Law minimum, larger than the 20x20 hover buttons since toolbar is a primary interaction surface.
