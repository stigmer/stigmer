## Decisions Made

- **Separate hook, not expanding `useGraphHistory`**: Keyboard shortcuts for canvas actions (duplicate, select all, task picker) are a distinct concern from undo/redo history management. SRP dictates a dedicated hook.
- **Capture-phase listener**: Matches `useGraphHistory` pattern — `document.addEventListener("keydown", handler, true)`. Both hooks coexist without conflict since they handle non-overlapping key combos.
- **Text input guard for bare-key shortcuts**: `isTextInput()` checks `tagName` (INPUT/TEXTAREA/SELECT), `isContentEditable`, and `role="textbox"`. Modified shortcuts (Ctrl+D, Ctrl+A) intentionally override browser defaults and skip this guard.
- **N-key anchoring via DOM query**: When a node is selected, the handler sends a sentinel `{ x: 0, y: 0 }` with the `sourceNodeId`. The editor resolves actual screen coordinates via `querySelector('[data-id]')` + `getBoundingClientRect()`. This avoids coupling the hook to React Flow's coordinate system.
- **Platform detection duplicated**: `isMac` is a one-liner in both `CanvasContextMenu.tsx` and `WorkflowCanvasEditor.tsx`. Not extracted to `canvas-constants.ts` to keep that module free of browser API dependencies.

## Learnings

- React Flow renders nodes with `data-id` attributes on the outer DOM element, making it queryable for screen position resolution without needing the React Flow instance API
- `CSS.escape()` is necessary when building attribute selectors with node IDs that may contain special characters
- `navigator.platform` is deprecated but still universally supported; `navigator.userAgentData` is the modern replacement but has limited browser support. The platform regex approach is the pragmatic choice for now.
